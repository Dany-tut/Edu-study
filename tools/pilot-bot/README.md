# Искра · Бот тестирования

Личный Telegram-чат ведёт преподавателя или ученика по карточкам из [Figma](https://www.figma.com/design/y8qQ23hqFJtufp7gGdZTse/?node-id=235-2). Роль, устройство, результаты, отзывы и точка продолжения хранятся в SQLite. Бот использует Telegram Bot API через long polling. Для запуска нужен один постоянно работающий процесс на macOS или Linux с Python 3.10+.

## Подготовка пилота

1. Бот «Искра» уже создан в Telegram: [@IskraPlatformBot](https://t.me/IskraPlatformBot). В BotFather настроены профиль и команды. Команда /role позволяет пройти обе роли в одном личном чате с независимым прогрессом.
2. В окружение процесса передать токен в `ISKRA_PILOT_BOT_TOKEN`. Для кнопок входа задать `ISKRA_PILOT_SITE_URL` с адресом целевого стенда. Токен и персональные приглашения хранить вне репозитория.
3. В каталоге этого файла запустить `python3 bot.py`. В личном чате выполнить `/id` и задать `ISKRA_PILOT_ADMIN_CHAT_ID` для своего аккаунта, затем перезапустить процесс. В BotFather можно добавить команды start, feedback и resume.
4. Подготовить тестовые данные своей группы. Координатор заранее выдаёт персональные приглашения, резервный курс с доступным уроком, отдельную работу для ручной проверки и уже проверенную работу. Дату урока выбрать так, чтобы ДЗ уже открылось. Бот регистрирует ответы участника, проверку состояния в самой Искре выполняют участники.
5. Для индивидуальных ссылок запускать `python3 bot.py --kits /путь/к/kits.local.json`. Ключ верхнего уровня — номер личного чата из /id. Изменение конфигурации применяется после перезапуска. Пример структуры для одного участника:

```json
{
  "123456": {
    "number": "42",
    "build": "SHA тестовой сборки",
    "t05b": "https://test.example/#/join-teacher?token=PERSONAL",
    "u05b": "https://test.example/#/join?token=PERSONAL",
    "lesson": "https://test.example/#/lesson/TEST_LESSON",
    "assignment": "https://test.example/#/homework/TEST_WORK"
  }
}
```

Заполнять ссылки только для роли человека. Любой ключ карточки из cards.json задаёт кнопку «Открыть Искру». Для запасных переходов доступны также group, course и editor. В закрытом пилоте участник открывает общую ссылку Telegram с параметром start. После «Ещё нет» бот выпускает личное приглашение выбранной роли. Ранее подготовленные ссылки из kits имеют приоритет. Настройки выдачи лежат в invites.local.json рядом с SQLite (права 0600): key — постоянный случайный ключ в hex, start — секрет ссылки на вход, cli и workdir — абсолютные пути к авторизованному Supabase CLI и проекту. Сохраняйте key при перезапуске, чтобы повторный запрос выдавал прежнюю ссылку. Код профиля Искры не требуется.

## Работа с отзывами

/start или /resume открывает текущую карточку. /feedback доступен также до окончания анкеты и после завершения. Отзыв может содержать текст, фото, видео, голосовое, кружок и документы. «Готово» сохраняет весь набор. В БД сохраняются Telegram file_id и подписи к вложениям.

Координатор в своём личном чате открывает /reports и затем /report 1, подставляя номер отзыва. Команда отправляет координатору сохранённые сообщения и вложения. Участники получают подтверждение с номером.

SQLite по умолчанию находится в ~/.iskra-pilot/pilot.sqlite3. Для постоянного диска использовать --db. Остановка и перезапуск с тем же файлом сохраняют историю. Записи участника и очередь ответов фиксируются одной транзакцией. При обрыве в момент подтверждения отправки Telegram может получить повторный экземпляр карточки. Повторное нажатие не засчитывает шаг второй раз.

## Проверка

Из этого каталога выполнить `python3 -m unittest -v`. Проверки работают без токена. Перед приглашением группы пройти с реальным ботом на телефоне вход, паузу, возврат, запись кружка и воспроизведение из чата координатора. Снимки для карточек сделаны в тестовой Искре. Мобильные варианты есть для главной и результата ученика, остальные карточки помечают десктопный снимок при выборе телефона.
