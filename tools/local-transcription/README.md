# Расшифровка уроков на Mac

Подключаемый модуль редактора Искры и локального обработчика для Apple Silicon. Нужны Python 3, FFmpeg, Xcode Command Line Tools и место для двух моделей. Первый запуск `./tools/local-transcription/start.command` устанавливает зависимости и загружает модели. Последующая обработка использует локальные веса. Для получения записи по ссылке нужен интернет.

Обработчик слушает 127.0.0.1:18764 и принимает запросы от одного адреса Искры. По умолчанию это https://edu-study-app.vercel.app. Скачайте архив из профиля, распакуйте его и запустите start.command на Mac. Оставьте окно открытым во время обработки. Если браузер спросит разрешение на доступ к локальной сети, разрешите его для сайта Искры. Для разработки задайте ISKRA_APP_ORIGIN=http://127.0.0.1:5187 перед запуском и запустите Vite на этом адресе.

Профиль преподавателя → Модули → Подключить компьютер. Конструктор → курс → урок → Запись → Расшифровка урока. Выберите файл либо вставьте общедоступную ссылку. Проверьте черновик, исправьте реплики и названия глав, добавьте материал в урок. Публикация курса использует обычные правила аудитории и расписания. У опубликованного курса кнопка явно предлагает обновить опубликованный урок.

Исходный файл не отправляется в хранилище курса. Ссылка в уроке должна быть доступна ученикам, иначе можно опубликовать только текст. Модели и программы для просмотра текста ученику не нужны. Подключение действует в конкретном браузере и профиле на этом компьютере. Задание можно вновь открыть из того же урока, пока локальный обработчик работает. После перезапуска незабранные результаты придётся получить заново.

Текст сохраняется вместе с содержимым урока в lessons.content.transcript, главы — в существующих lessons.timecodes. Права и публикация наследуются от урока. Миграции не требуются.


## Обновление
Модуль обновляется сам. Страница сравнивает `GET /version` с версией архива на сайте; если модуль отвечает `update: true`, она вызывает `POST /update`. Модуль скачивает архив сайта через curl (без пометки «из интернета», поэтому macOS не спрашивает разрешения), проверяет отпечаток, раскладывает файлы поверх папки и перезапускает start.command. Во время расшифровки обновление ждёт её конца. Модули до этой версии нужно один раз обновить архивом вручную.

## Восстановление задания
Принятые задания и результаты сохраняются в `~/Library/Application Support/Iskra/transcription/jobs` с доступом только текущего пользователя. Обновление вкладки не отменяет работу. При сетевом сбое скачивание ждёт связь и повторяется; после загрузки видео модели работают локально. При закрытии модуля запустите start.command снова: завершённые этапы пропускаются, прерванный этап выполняется заново. Mac должен быть включён и не спать. Исходное видео и промежуточные файлы удаляются по завершении, результат остаётся для восстановления вкладки. Результаты не публикуются в урок без «Сохранить расшифровку».

Обрыв первоначальной передачи файла до подтверждения «Запись принята» требует выбрать файл снова. Первая загрузка самой веб-страницы без интернета не гарантируется. Ранее скачанный модуль необходимо заменить новым архивом, чтобы использовать сохранение на диск.

Монтаж записи. После распознавания модуль ищет паузы по громкости (silence.py, без ИИ): тихие отрезки и уровень звука для формы волны. В конструкторе в инструментах расшифровки кнопка «Монтаж записи» открывает окно, где паузы вырезают или ускоряют, а реплики раздают голосам. Решения сохраняются вместе с расшифровкой («Сохранить расшифровку»); видео не перекодируется, плеер урока сам пропускает вырезанное и ускоряет тихую работу. Чтобы появились паузы, перезапустите start.command и повторите обработку записи.

## Словарь предмета и дообучение

Страница Искры отправляет с каждым заданием поле `terms` — словарь предмета из
таблицы `transcript_terms` (Админка → «Словарь»): `prompt` — термины,
`replace` — пары «как распозналось → как правильно» («*» — любое окончание).
`recognize.py` режет звук на куски до 30 с по тихим местам и подаёт термины
подсказкой (initial_prompt) в каждый кусок, а пары применяет к готовому тексту.
Без словаря распознавание идёт как раньше.

Уровень Б (основа для дообучения): если учитель включил «Учить распознавание на
моих правках», модуль сохраняет сжатую копию звука записи в `training/audio/`
(хранится 60 дней), а каждая исправленная реплика (`POST /training`) становится
отрывком `training/clips/<предмет>/*.wav` и строкой в `training/manifest.jsonl`
`{audio, text, before, subject, job, start, end, at}`. Это готовый набор
«звук + правильный текст» для дообучения Whisper. Всё лежит только на этом Mac.
