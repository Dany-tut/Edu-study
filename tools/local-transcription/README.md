# Расшифровка уроков на Mac

Подключаемый модуль редактора Искры и локального обработчика для Apple Silicon.

Скачайте приложение «Искра — расшифровка», откройте его один раз и разрешите
фоновую службу в настройках Mac, если система попросит. Затем запускайте
расшифровку из Искры: приложение включает обработчик по запросу, без окна
Терминала. Служба не запускается при входе в Mac и останавливается после
30 минут бездействия.

FFmpeg включён в подписанное приложение. Окружение Python и небольшие
модели разделения голосов устанавливаются при первом подключении. Большие
модели Whisper и Qwen скачиваются только перед первой расшифровкой. Если на
Mac нет Xcode Command Line Tools, расшифровка продолжит работать, но заголовки
слайдов не будут распознаны. Для получения записи по ссылке нужен интернет.


Профиль преподавателя → Модули → Подключить компьютер. Конструктор → курс → урок → Запись → Расшифровка урока. Выберите файл либо вставьте общедоступную ссылку. Проверьте черновик, исправьте реплики и названия глав, добавьте материал в урок. Публикация курса использует обычные правила аудитории и расписания. У опубликованного курса кнопка явно предлагает обновить опубликованный урок.

Исходный файл не отправляется в хранилище курса. Ссылка в уроке должна быть доступна ученикам, иначе можно опубликовать только текст. Модели и программы для просмотра текста ученику не нужны. Подключение действует в конкретном браузере и профиле на этом компьютере. Задание можно вновь открыть из того же урока, пока локальный обработчик работает. После перезапуска незабранные результаты придётся получить заново.

Текст сохраняется вместе с содержимым урока в lessons.content.transcript, главы — в существующих lessons.timecodes. Права и публикация наследуются от урока. Миграции не требуются.


## Обновление
Модуль обновляется сам. Страница сравнивает `GET /version` с версией архива на сайте; если модуль отвечает `update: true`, она вызывает `POST /update`. Модуль скачивает архив сайта через curl (без пометки «из интернета», поэтому macOS не спрашивает разрешения), проверяет отпечаток, раскладывает файлы поверх папки и перезапускает фоновый обработчик. Во время расшифровки обновление ждёт её конца. Модули до этой версии нужно один раз обновить архивом вручную.

## Восстановление задания
Принятые задания и результаты сохраняются в `~/Library/Application Support/Iskra/transcription/jobs` с доступом только текущего пользователя. Обновление вкладки не отменяет работу. При сетевом сбое скачивание ждёт связь и повторяется; после загрузки видео модели работают локально. При закрытии модуля запустите START.command снова: завершённые этапы пропускаются, прерванный этап выполняется заново. Mac должен быть включён и не спать. Исходное видео и промежуточные файлы удаляются по завершении, результат остаётся для восстановления вкладки. Результаты не публикуются в урок без «Сохранить расшифровку».

Обрыв первоначальной передачи файла до подтверждения «Запись принята» требует выбрать файл снова. Первая загрузка самой веб-страницы без интернета не гарантируется. Ранее скачанный модуль необходимо заменить новым архивом, чтобы использовать сохранение на диск.

Монтаж записи. После распознавания модуль ищет паузы по громкости (silence.py, без ИИ): тихие отрезки и уровень звука для формы волны. В конструкторе в инструментах расшифровки кнопка «Монтаж записи» открывает окно, где паузы вырезают или ускоряют, а реплики раздают голосам. Решения сохраняются вместе с расшифровкой («Сохранить расшифровку»); видео не перекодируется, плеер урока сам пропускает вырезанное и ускоряет тихую работу. Чтобы появились паузы, запустите расшифровку записи ещё раз.

## Словарь предмета и дообучение

Страница Искры отправляет с каждым заданием поле `terms` — словарь предмета из
таблицы `transcript_terms` (Админка → «Словарь»): `prompt` — термины,
`replace` — пары «как распозналось → как правильно» («*» — любое окончание).
`recognize.py` режет звук на куски до 30 с по тихим местам и подаёт термины
подсказкой (initial_prompt) в каждый кусок, а пары применяет к готовому тексту.
Без словаря распознавание идёт как раньше.

Уровень Б (основа для дообучения): если учитель включил «Учить распознавание на
моих правках», модуль сохраняет сжатую копию звука записи в `training/audio/`
(хранится 60 дней), а каждая исправленная реплика (`POST /training`) становится
отрывком `training/clips/<предмет>/*.wav` и строкой в `training/manifest.jsonl`
`{audio, text, before, subject, job, start, end, at}`. Это готовый набор
«звук + правильный текст» для дообучения Whisper. Всё лежит только на этом Mac.

## Вложенный FFmpeg (лицензия и источник)

В архиве рядом со скриптами лежит исполняемый `ffmpeg` — статическая сборка для
macOS arm64 (Apple Silicon). Благодаря ему модуль работает на Mac без Homebrew и
без `brew install ffmpeg`. В git бинарник НЕ хранится (раздувал бы репозиторий):
`scripts/buildTranscriptionModule.mjs` при сборке сайта скачивает его по
закреплённому URL с проверкой sha256, кэширует в `node_modules/.cache` и кладёт в
архив. Скрипты модуля находят бинарник через `media_tools.py` (env `ISKRA_FFMPEG`
→ вложенный файл → системный `ffmpeg` из PATH), а `START.command` ставит папку
модуля первой в `PATH`, чтобы его нашло и распознавание речи.

- Программа: **FFmpeg** — <https://ffmpeg.org>.
- Сборка: статический билд FFmpeg **9.0.2** для macOS arm64 от Martin Riedl,
  <https://ffmpeg.martin-riedl.de> (скрипт сборки:
  <https://git.martin-riedl.de/ffmpeg/build-script>).
- Лицензия: **GPL v3** (сборка собрана с `--enable-gpl --enable-version3`).
  Текст лицензии: <https://www.gnu.org/licenses/gpl-3.0.html>. Исходный код
  FFmpeg 9.0.2, соответствующий этому бинарнику, доступен на <https://ffmpeg.org>
  (релизы) и в зеркалах проекта; бинарник распространяется без изменений.
- Включённые библиотеки (в т.ч. GPL): libx264, libx265, libvpx, libopus,
  libmp3lame, libvorbis, openssl. Модуль использует FFmpeg только локально для
  чтения и нарезки звука, формы волны, детекции сцен и кадров слайдов.

Обновить/заменить бинарник: впишите новый URL и sha256 (распакованного `ffmpeg`)
в `FFMPEG` в `scripts/buildTranscriptionModule.mjs` или задайте переменные
`TRANSCRIPTION_FFMPEG_URL` / `TRANSCRIPTION_FFMPEG_SHA256` (например, зеркало в
R2) и запустите `node scripts/buildTranscriptionModule.mjs`. Для локальной сборки
без сети можно положить готовый `ffmpeg` (arm64) прямо в
`tools/local-transcription/` — скрипт возьмёт его, если sha256 совпадёт (в git он
не попадёт, папка в .gitignore).
