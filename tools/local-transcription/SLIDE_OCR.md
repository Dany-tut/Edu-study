# Главы по слайдам

Отдельный режим `mode=slides`, `titleRegion` — выбранный край слайда. Существующие текст, голоса и монтаж не входят в результат. Сайт хранит отдельный черновик и применяет только главы по явному действию.

Кадры обрабатываются локально, видео и кадры сервисам не отправляются.

- **Основной путь — Apple Vision.** `frame_text.swift` собирается при сборке .app (`scripts/buildTranscriptionMacInstaller.sh`, CI `transcription-mac-release.yml`) в `Contents/MacOS/IskraFrameText`; приложение передаёт путь в `ISKRA_FRAME_TEXT`. Уровень `.accurate`, языки `ru-RU` + `en-US`, строки с геометрией. Режим `--stream`: один процесс на задание, кадры PPM без перекодирования. Ничего не ставится, swiftc у учителя не нужен. Модуль узнаёт хелпер по `--version` → `iskra-frame-text 2`.
- **Запасной путь — RapidOCR 3.10.0 + ONNX Runtime 1.32.0** (PP-OCRv5 mobile, кириллица) в отдельном `slide-runtime-1`. Только если хелпера протокола 2 нет — это приложения ≤ 1.0.8: их `IskraFrameText` собран с `.fast`, читает только латиницу («Клеточное» → «KneTorue»), и для глав не используется. Установка и OCR наследуют отменяемую группу процессов задания.

Фильтр заголовков (`slide_chapters.heading`, общий для обоих движков и для прохода «Читаем слайды» при расшифровке): отбрасываются хром записи экрана (вкладки и кнопки PowerPoint/Google Slides/Zoom, «Ask Copilot», счётчики «2 of 31», «Стр. 3 из 12»), строки без нормального слова («CD», «Uy», «KneTorue» — внутренний перескок регистра), обрывки с края кадра («/Uy …»), смесь алфавитов. Из оставшегося побеждает самый крупный текст выбранной области, при равном размере — ближе к верху. Кадр, где остался только мусор, не даёт главы. Фикстуры: `fixtures/slides/`, тесты `test_slide_ocr_quality.py`.

Выборка раз в 2 с, подтверждение двумя наблюдениями, уточнение первого появления до 0,5 с, глобальная нормализованная дедупликация. Нумерованные пункты, короткий подвал ЕГЭ/ОГЭ и адреса отбрасываются. Результат нуждается в просмотре: короткие слайды и заголовки с низким контрастом могут не распознаться.

Компоненты и лицензии:
- [RapidOCR](https://github.com/RapidAI/RapidOCR), Apache-2.0.
- [PaddleOCR / PP-OCRv5](https://github.com/PaddlePaddle/PaddleOCR), Apache-2.0; [каталог моделей](https://rapidai.github.io/RapidOCRDocs/main/en/model_list/).
- [ONNX Runtime](https://github.com/microsoft/onnxruntime), MIT.

Лицензии пакетов находятся в установленном Python runtime; модели скачиваются из официального каталога RapidAI.

## Скорость и извлечение кадров

Проход 1 декодирует только ключевые кадры (`-skip_frame nokey`, не чаще раза в 2 с) и читает полосу заголовка. Плотная выборка раз в 2 с — только между ключевыми кадрами, где полоса изменилась или кадры дальше 20 с друг от друга. Если ключевые кадры в среднем реже 20 с — один последовательный проход раз в 2 с (прежняя схема). Ограничение: другой слайд, показанный меньше 20 с между двумя показами одного и того же слайда, может не попасть в главы. Прогресс: «Ищем смену слайдов» (секунды записи) → «Читаем слайды» (N из M смен).

Замер (Mac Apple Silicon, 60 мин 1080p, 30 слайдов, ключевой кадр раз в 10 с, «вебкамера» меняется каждый кадр): последовательный проход с Vision — 99 с; ключевые кадры — 24–29 с; 30/30 глав, таймкоды точные. RapidOCR на реальном уроке: ~27 мин на 1497 кадров.

Повторяющиеся области сравниваются по локальным изменениям, результат OCR переиспользуется; проверка по плиткам ловит небольшую смену буквы/цифры. Кэш ограничен восемью миниатюрами; через 60 с выполняется контрольный OCR. Уточнение времени новой главы обращается к кадру, показанному в этот момент, а не к следующему кадру VFR. Хелпер Vision, не ответивший вовремя, перезапускается, кадр читается снова.

## Скачивание с Google Диска

Сразу `drive.usercontent.google.com/download?…&confirm=t` (без лишних переадресаций; страница подтверждения — запасной путь). Первый запрос — 1 байт: ответ `206` даёт размер, и файл качается 6 кусками по Range параллельно, каждый докачивается после обрыва; без Range — один поток. Прогресс в байтах виден с первой секунды. Скачанное видео хранится на Mac (`video-cache`, 7 дней, до 5 файлов, жёсткая ссылка — без лишнего места): повтор того же урока в другом режиме не качает заново. Замер на локальном сервере с лимитом на соединение (94 МБ): 4 МБ/с — 23,5 с → 4,2 с; 1,5 МБ/с — 62,6 с → 10,5 с.
