# Искра · смысловые 3D-объекты

Шесть самостоятельных иллюстраций для показателей 2×1; сгенерированы imagegen по отдельным промптам. Прозрачные PNG без букв и цифр. Общие материалы: лавандовая смола, молочный фарфор, янтарные акценты.

- Студентов: группа людей → `students.png`.
- Карточек учеников: профили → `student_cards.png`.
- Получено: кошелёк с подтверждением → `received.png`.
- Ожидается: банкнота с песочными часами → `expected.png`.
- Долг: неоплаченный счёт с предупреждением → `debt.png`.
- Прогноз: календарь с прозрачной сферой → `forecast.png`.

Блокнот для проверки ДЗ и часы для уроков используются из существующего набора. Соответствия восьми виджетов: `design/widget-redesign-review/objects.ts`. Декоративные объекты не кодируют значения показателей. Исходные изображения сохранены в generated_images; опубликованный набор — в этой папке.
