# Искра · 3D-объекты виджетов-панелей

Семь иллюстраций для окна «Добавить виджет»: у виджетов-списков и панелей раньше там стояла линейная иконка. Сгенерированы в ChatGPT (gpt-image) по листу-референсу из `widget-metric-objects-v1` и `widget-objects-v2-shadows`: лавандовая смола, молочный фарфор, янтарные акценты, прозрачный фон, без букв и цифр. Уменьшены до 480×480, как набор v2.

- Напоминания → `reminders.png`
- Мои задачи → `tasks.png`
- Должники → `debtors.png`
- История платежей → `payment_history.png`
- Оплаты: ждут вас → `payments_inbox.png`
- Список групп → `groups_list.png`
- Отчёты родителям → `parent_reports.png`

Без генерации: «Расписание» использует `schedule-objects-v2-shadows/calendar.png`, «Связь с учениками» — бумажный самолётик `widget-objects-v2-shadows/ui/next-step.png`, «Требуют внимания» — `widget-metric-objects-v1/debt.png`, как в самом виджете. Соответствия — `src/lib/widgetMetricObjects.ts`.
