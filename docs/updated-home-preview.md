# Обновлённая главная Искры — демонстрация

Публичный маршрут `/student-track-stand` показывает согласованный макет главной:
расписание, полосу виджетов и трек курса. Все курсы, занятия, сроки и ответы здесь
демонстрационные. Обычный кабинет и его данные этот маршрут не заменяет.

Варианты оформления: `?season=candy`, `?season=lanterns`, `?season=potions`.
Переключатель «Оформление главной» позволяет сравнить темы в одной вкладке.
Предпросмотр работает после окончания сезона и не сохраняет выбор праздничной
темы или флаг предпросмотра для обычного кабинета.

Сценарии выбираются в меню «Сценарий трека»; `?scenario=fifty` показывает
50 занятий, а `?scenario=debts` — задолженности в предыдущем модуле.
Кнопки открытия и отправки работ изменяют только данные текущей демонстрации.

Проверки: `npm run check:ui`, `node scripts/checkStudentTrackDebts.mjs`,
`npx tsc --noEmit`, `npm run build`; перед выпуском — `npm run release:check`.
Визуально проверять три темы на десктопе и телефоне: начало, середину и конец
расписания, трека и цепочки модулей, выбор занятия, окна подробностей, тени.
