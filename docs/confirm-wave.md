# Волна подтверждения

Разовый эффект на окончательном действии: цветная волна несёт карточку из «до»
в «после». Библиотека — Distortion Waves 0.1.0 (MIT, Jakub Antalik), вендорная
копия без React: `src/lib/confirmWave/distortionWaves.js`. Концепты согласованы
Дани 19.11.2026, прототип: https://claude.ai/artifact/JE6CavEbUyUnXvYztboLaD

## Где играет

| Момент | Где в коде | Сила |
|---|---|---|
| «Сдать домашку» → «Результат ДЗ» (зачёт или отправка учителю) | `HomeworkFlow` → `ResultModal` | полная волна в цвете предмета, искры влетают в баллы; вместо прежнего салюта |
| Учитель «Завершить проверку» (iPhone) | `MobileHomeworkReview`, карточка ученика | кольцо от статуса |
| Учитель «Завершить проверку» (ПК, журнал) | `HomeworkHub`, панель итогов | кольцо от кнопки |
| Ученик видит зачёт учителя | `HomeworkAttemptPanel` | кольцо один раз на попытку: сразу по realtime или при следующем открытии |
| Модуль закрыт | `CourseTrack`, тело трека | слева направо вдоль трека, палитра Огонька, больше искр; один раз на модуль |
| Верный ответ в ДЗ (ПК, айпад в ландшафте) | `HomeworkFlow` → `fireBurst` | тихий контур по краю карточки, ~0,9 с |

**Без волны:** «На доработку», «Не зачтено», неверный ответ, итог ниже порога,
«Завершить занятие», «Оплачено» (деньги празднует Finansly), ошибки сохранения.

## Правила

- Волна только на непрозрачной карточке. Стекло через снимок не проходит.
- В покое — ноль кадров: холст живёт только во время волны.
- Reduce Motion и отсутствие WebGL2 — мягкая смена без волны (`confirmWaveReady()`).
- Чанк библиотеки (~95 КБ) грузится отдельно: `preloadConfirmWave()` при показе
  экрана с кнопкой. Не импортировать `distortionWaves.js` статически.
- «Один раз» (`waveSeen` / `markWaveSeen`) на первом запуске считает всё
  существующее увиденным: после выпуска историю ученика не празднуем.

## Как добавить точку

```tsx
const wave = useConfirmWave()          // hostRef — карточка, liveRef — её единственный ребёнок
// ...
const handle = wave.begin({ palette, source: buttonEl })  // заморозить «до»
setState(after)                                           // React показывает «после»
handle?.play()                                            // волна; при ошибке — handle.cancel()
```

Для частого события — `pulseConfirmEdge(card)`: только свечение края, без снимка.

## Правка в вендорной копии

Снимок библиотеки терял нулевую ширину рамки при `border-style: solid`
(Tailwind preflight `border: 0 solid`) — на картинке у всех элементов появлялась
рамка 3 px. Помеченная правка `dwZeroBorders` сохраняет ноль. При обновлении
библиотеки — перенести или проверить, исправлено ли у автора.
