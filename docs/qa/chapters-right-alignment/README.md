## Коррекция нативного scrollbar (до прогона)
В production Edge на macOS после выпуска 2097 остаётся зазор между правыми краями вкладок и панели. В прежнем headless fixture нативный scrollbar не занимал ширину. Риск: правый край зависит от режима системной прокрутки. Решение: overlayScrollbar для внешнего ScrollFade записи; фейды сохраняются. Ожидание: совпадение краёв при overflow и принудительном stable gutter, начало/середина/конец, desktop и phone. До изменения проверить воспроизведение на старом коде, после — тот же сценарий. Проверка реальной production-страницы Edge после выпуска обязательна; данные урока не менять.

Результат fixture Chrome 390/870/1200 ×800: до исправления stable gutter даёт 11 px, после — 0 px (gutter-before/after.json). Начало/середина/конец сняты; просмотрены desktop middle и phone end. Повторный delete-check прошёл desktop/touch в обеих темах. check:ui PASS. Физическое устройство, остальные действия/состояния и покадровое движение не проверены; область приёмки ограничена геометрией и сохранением удаления.
