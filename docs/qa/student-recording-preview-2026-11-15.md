# Ученический просмотр записи: сценарий приёмки

- База: d25b11641c825595b9511ace2a56c08295213103; отдельная codex/student-recording-preview.
- Область: настоящий CenterRecording, TranscriptionAction, переключатель и общий LessonRecordingView из LessonPage.
- Риск: учительские кнопки в просмотре, потеря черновика, запись прогресса за ученика, монтаж другого видео.
- Окружение fixture: настоящий React UI и HTML video; подменён только Supabase (учитель, права transcription, пустые данные). Это не авторизованный production E2E.
- Данные A/B: разные ID, URL, названия и реплики, одинаковое число глав; 0/4/40 глав.
- Платформы: ПК 1280/1440, iPhone390, iPad1180, Android412; обе темы. Физические устройства не проверяются этим стендом.

## Результат

Реальный CenterRecording/TranscriptionAction: сохраняются название текстовой главы, название слайда, выбранная вкладка и исправленная реплика после preview→original. Переключение не вызвало ни одного callback сохранения урока. Для видео A/B проверены URL и главы; план монтажа с чужим source игнорируется.

HTML video: cut3–6 пропускается только в preview с соответствующим source; original проходит этот участок. Отображаемая длина13с вместо16с; клик середины сокращённой шкалы приводит к исходным9.5с (без монтажа8с). Проверены главы, воспроизведение, пауза и возврат. Снимки: обе темы, PC1280 (основной сценарий1440), iPhone390, iPad1180, Android412, списки0/4/40 и начало/середина/конец. Пять повторных переключений, Enter/Space и rAF-наблюдение: нет кадра с редактируемыми полями при выбранном preview.

Отрицательная проверка: временно отключённая ветка preview в esbuild fixture возвращает исходный дефект; тест падает, ожидая ученическую главу-кнопку. Исходники продукта отрицательная проверка не меняет.

Доказательства: `student-preview-release` в каталоге визуализаций этого чата, browser.log, negative.log, transition-frames.json и PNG. По логике и указанному fixture UI — PASS. Авторизованный production E2E и физические устройства не проверены: доступные расширению вкладки не содержат профиля Искры, активную пользовательскую сессию Edge не переключали. YouTube/RuTube/Drive и меню плеера (скорость/громкость/полный экран) этим сценарием не проверены; их реализация не менялась. Извлечён общий существующий ученический блок, а не его копия.
