# TEXT-02 — общие списки и переключатели, группа 2

База: a70ddf24253d6e01e2e44eb0e5519c35a3f125b2. Исполнитель S3; публикация S1.
До QA карточка: `~/.codex/iskra-qa/shared-controls-family2-20261122/scenario.md`.

Область: TeacherSelect (подпись и строки меню), MultiSelectField (подписи,
чипы, счётчик дополнительных значений, строки меню), Segmented (три варианта).
Используется общий OpticalText/FadeText optical. Иконки, рамки, native input,
обработчики, ключи значений, доступные имена и размеры контролов сохранены.
Составные ReactNode-подписи Segmented не меняются. Скрытая жирная копия,
резервирующая ширину сегмента, не меняется. Обновление после render учитывает
смену inherited fontWeight при выборе сегмента без изменения его ширины.

## Проверено

Изолированный стенд импортирует реальные компоненты до/после; React state
локальный, без данных пользователей и сервера. Chrome headless/macOS, свой
профиль. Native Edge не используется. Точное тело шрифта приложения;
Android — настоящий локальный Roboto, только для QA, в runtime не добавлен.

12 сочетаний: ПК 1440/1024, iPhone 390, iPad 820/1194, Android 412 × светлая
и тёмная темы. Совпадение размеров рамок и относительных координат всех SVG;
выбор сегмента и обратный выбор, rich fallback, поиск/выбор TeacherSelect,
MultiSelect: выбор двух ключей, удаление чипа, очистка; полная последовательность
callback keys совпадает с исходным компонентом. По AST все 28 JSX обработчиков
событий побайтово эквивалентны после нормализации пробелов. UI guard и tsc проходят.

Артефакты вне git: `~/.codex/iskra-qa/shared-controls-family2-20261122/`:
`fixture.tsx`, `Before*.tsx`, `check.cjs`, `results.json`, `handlers.json`,
before/after PNG обеих тем. Механизм метрик и default-markup FadeText отдельно
покрыт `scripts/checkOpticalText.mjs` из предыдущей группы.

## Границы

Это component fixture, не полная production-приёмка. Не проверены WebKit,
физические iPhone/iPad/Android, нативное iOS-меню TeacherSelect, все экраны
с этими компонентами и серверный E2E. Нативные поля, составные подписи,
нестандартные кнопки и массовые callsites остаются в открытой очереди TEXT-02.
NameEntryField и floating-label поля сохраняют собственную композицию;
их нельзя исправлять сдвигом всей рамки либо универсальным отступом.

Дополнительный прогон той же матрицы PASS: Enter/Escape открывает/закрывает
MultiSelect; длинная строка переносится в меню; сняты open PNG, попытки прокрутки
к середине/концу. С этим коротким списком overflow может отсутствовать — это не
приёмка длинного production-списка. Проверено обновление offset при selected
fontWeight=700; внешние сетевые запросы заблокированы маршрутизатором стенда.
Просмотрены PC-dark, iPhone-light и Android-Roboto-dark/open PNG. Полная
поэлементная визуальная приёмка всех 12 комбинаций человеком не заявляется.
