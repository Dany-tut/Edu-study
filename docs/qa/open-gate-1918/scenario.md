# Приёмка открытой беты · продолжение
Сборка публичной оболочки на старте повторной проверки 3601666e22f1529dad1811ba48b1940adb2d8417. Учитель A и ученик B — изолированные синтетические учётные записи. Цель — войти в каждый основной раздел из свежей вкладки на 390 и 1440 px, в светлой и тёмной теме. Проверять фактический маршрут, содержимое, доступные действия, ошибки и геометрию. Посторонние данные и записывающие действия в обход сценария исключены. Отдельно проверить неуспешную загрузку, возврат и соответствие ID в доступной области. Непроверенные переходы, темы, устройства и состояния остаются открытыми. Для почты требуется доставка через реальный ящик, для Тестли — результат синтетического ученика, для ИИ — отдельное подтверждение фактического обращения к провайдеру. Нагрузка локальная, четыре роли/аккаунта и до 50 параллельных запросов.
