# Сравнение версий курса при конфликте

База — 6371204b. Воспроизводимый стенд использует реальное окно и синтетические строки уроков с различными short_id. Исходные данные преподавателей не используются. Изменение ограничено чтением сравниваемых полей и отображением результата.

| Сценарий | Ожидаемый результат |
| --- | --- |
| Одинаковые названия разных уроков, перестановка | Сравнить по устойчивому идентификатору, подписать номер урока |
| Пустое описание, длинный текст, перенос строки | Прочитать каждую версию целиком, увидеть пустое значение |
| Смена таймкода, режима, варианта и исходного заголовка | Показать отличающиеся значения и сторону каждого |
| Поменялся только счётчик ревизии | Не показывать различие в таймкодах |
| ПК, iPhone 320/390, iPad вертикально/горизонтально, Android 412, две темы | Текст переносится, кнопки доступны, прокрутка и её фейды работают |
| Выбор базы, вкладки, закрытие, сообщение об ошибке | Выполнить только выбранное действие |

Проверено командой `node scripts/checkCourseConflictComparison.mjs`. Синтетическая модель прошла сопоставление двух одноимённых уроков с разными ID при перестановке, добавление и удаление, пустое и длинное описание, различие секунд при одинаковом отображаемом времени, активный режим, источник и исходное название слайда. Изменение одного номера ревизии списка различий не создало.

Фактическое окно в изолированном Chromium прошло 12 сочетаний: 1440×900, 390×844, 320×568, 820×1180, 1180×820, 412×915 в двух темах. Проверены отсутствие горизонтальной прокрутки, видимость кнопок, обе стороны каждого поля, фейды в начале/середине/конце, переход Tab/Shift+Tab через границы окна, Escape и четыре действия. Необработанных ошибок не было. Снимки сохраняются при передаче каталога в `ISKRA_CONFLICT_SCREENSHOTS`. Стенд подменяет callbacks и строки БД. Физические устройства, WebKit и выполнение выбранной записи в production этим тестом не проверяются.

## Применение выбора на свежей базе

База этого изменения — 9e8bf501. В actual-dispatch fixture включены первоначальный отказ CAS, показ сравнения и вызов реального обработчика «Оставить моё» с повторным чтением, а затем существующий клиент сохранения. Когда вкладка меняла только описание, ожидается один подтверждённый запрос с изменением этого поля, без записей уроков. Удалённые таймкоды и скрытые ключи материалов должны сохраниться. Второй конкурентный коммит проверяется как до повторного чтения, так и непосредственно перед записью. Отмена во время чтения не должна считать попытку неудачной или отправлять запись. Отказы сети и прав должны отличаться в диагностике от блокировки защиты данных.
