# MODULE-MOTION-RAF

Границы: настоящий CourseTrack/CourseModuleBar со store-связью и различимыми
фикстурами уроков A/B (одинаковое количество, разные ID), без сервера. База —
production fcddd30fb80cb743b66975319a5e98ce52bec763. До/после — та же страница,
браузер, viewport и данные; меняется только исправление анимации.

Инварианты: вкладки не перекрываются; нет скачка координат после окончания;
постоянная высота центра номера; монотонный ход ширины между концами; правильный
набор ID узлов под выбранным модулем. Наблюдение rAF начинается до pointerdown,
включает кадры до клика и минимум 800 мс после, вместе со scrollLeft и dt.
Метрики: максимальный шаг координат/ширины, изменение направления движения,
поздний скачок, максимальный интервал кадров. Числа сохраняются без утверждения,
что любой большой dt вызван приложением: измеритель и среда тоже дают нагрузку.
Проверка самого теста: baseline — ровно опубликованные исходники.

Не покрыто: серверные поздние ответы, полный домашний экран, физическое устройство,
Safari/120 Гц. Фикстура не выдаётся за приёмку всего production UI.
До запуска: NOT TESTED. Результат — в отдельном README с сырыми кадрами.
