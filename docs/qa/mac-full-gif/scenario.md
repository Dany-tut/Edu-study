## Дополнение: потеря связи
До проверки: сервер 127.0.0.1:18764 не слушает (lsof + curl connection refused). Причина завершения не установлена, задан вопрос пользователю.
Ожидание: transport error сохраняет ID задания и предлагает «Проверить связь»; повтор читает тот же /jobs/ID; 404 после перезапуска предлагает начать заново. Действия не создают дубликат POST /jobs.

Восстановление, IAB fixture: PASS для двух конкретных сценариев. Offline → ready → «Проверить связь»: два GET /jobs/job-a, ни одного POST, получен текст именно задания A. Offline → missing → «Проверить связь»: 404 показал «Обработка больше не доступна» и «Начать заново». Это не E2E реального модуля и не подтверждение причины его остановки.
