# Искра — загрузка и первый экран

3 ноября 2026. Этап 7. Production и физический iPhone не затронуты.

## Подтверждённая причина лишней загрузки

App.tsx статически импортировал DashboardPage, хотя ученический кабинет взаимоисключается с нативным выбором роли и входом преподавателя. Это затягивало в общую стартовую зависимость уроки, трек, ученические виджеты и часть их общих модулей.

DashboardPage переведён на lazy + retryImport. Он монтируется в существующей ветке авторизованного ученика через общий Chunk. Маршрутизация, восстановление присланной ссылки и отдельная ветка кабинета преподавателя сохранены. В новой сборке DashboardPage-Cz6caZEG.js (393 268 B) существует отдельным чанком и не входит в первоначальный modulepreload входа преподавателя. Общие зависимости также перераспределены сборщиком.

Сумма module script + modulepreload, перечисленных в index.html:

Это размер startup-модулей, а не всего приложения. При первом входе авторизованного ученика его чанк всё равно потребуется; стоимость первого ученического перехода отдельно не подтверждена.

## Браузерное измерение холодного origin

Родительский агент снял одну парную пробу headless Chromium с virtual-time-budget=5000 на свежих localhost origin, маршрут #/teacher/login. Измерения помещены на DOM тестовых копий скриптом benchmark-tracer.js. В production-код трассировщик не добавлен.

| Метрика | До | После |
|---|---:|---:|
| Первый видимый button/input в #root | 566 ms | 392 ms |
| DOMContentLoaded | 248 ms | 74 ms |
| Load | 250 ms | 74 ms |
| JS decodedBodySize во время измерения | 1 730 826 B | 911 712 B |

Первый control появился на 174 ms раньше (−30,7%) в этой пробе. Это не нативный TTI, не запуск на физическом iPhone и не статистическая гарантия ускорения. Before взят из общего dist в начале этапа; after собран из текущего рабочего дерева отдельно. Рабочее дерево содержало параллельные изменения, поэтому разницу runtime нельзя целиком приписать одной правке без дополнительных повторов на зафиксированных ревизиях.

## Проверки и ограничения

- Изолированная production-сборка after — прошла; общий dist не переписан.
- TypeScript — прошла.
- check:ui — прошла, включая проверки мобильных жестов/клавиатуры и попыток ДЗ.
- git diff --check — прошла.
- Взаимоисключение ролей проверено по веткам AppRoutes: DashboardPage остаётся только в ученической ветке, teacher/entry/login возвращаются раньше. Подписанный ученический runtime не проверен без тестовой сессии.
- Нативное холодное появление первого кадра/готовность взаимодействия не измерены: CUA этого агента не предоставил браузер, а симулятор использовался родителем для отдельной UIKit-проверки. Перезапуск симулятора и физический iPhone не выполнялись.

## Повторение измерения

Тестовые копии: /tmp/iskra-perf-before-20261103 и /tmp/iskra-perf-after-20261103. Локальные серверы 24593 и 24594. Tracer добавлен только в их index.html. Он публикует JSON в pre#iskra-benchmark после первого видимого control и может также записать firstControlAfterHash при штатном переходе на другой hash. Снимки timing находятся в measurements.json. Для новых cold-проб нужно использовать свежие origin либо чистый браузерный профиль; повторная загрузка того же origin может использовать HTTP/ServiceWorker-кэш.
