# Настоящий Claude Desktop и Искра
Проверяющий Codex. macOS, подписанная сессия Claude Desktop, Edge с активным кабинетом Искры. Начальная версия Искры 1.0.1984 / 1418300cf56aa1831f127d3e9b27afa621655b31. Предоставление OAuth-доступа — только с отдельным подтверждением владельца. В отчёт не включаются токены, адреса авторизации с параметрами, переписка и открытые вкладки пользователя.
- PASS: на странице Customize → Connectors → Yours зарегистрирован новый custom connector «Искра» с адресом production Edge Function; выбран Sign in now / Register automatically. До выдачи доступа Claude явно показывает “You’re not connected to Искра yet”.
- PASS: Connect из настоящего Claude привёл на страницу согласия Искры /oauth/consent. На этом этапе grant ещё не подтверждён.
- PENDING: получение разрешения, возврат в Claude с доступными инструментами, появление точного client ID в профиле и отзыв того же grant. Отдельно сверить состояние после отзыва и итоговый SHA.
- PASS: владелец лично подтвердил OAuth. На странице именно созданного коннектора показываются Disconnect, ожидаемый URL и 4 инструмента: Мои курсы в Искре, Добавить урок в курс Искры, Создать курс в Искре, Добавить тест к уроку Искры. Настройка Needs approval для каждого. Это фактический успешный обмен из настоящего клиента. Учебные записи личного кабинета не изменяли.
- PASS на проде 1.0.2014 / 0c8861014c6f844655c1c96c2a3617b2c7c06125. Полные SHA в release.json и version.json совпали. Показывался реальный grant с именем Claude. В профиле выбран ровно этот client_id и подтверждён отзыв. Снимок из интерфейса: revoked.png. Статус карточки: «Доступ не выдан», уведомление: «Доступ отозван». Адрес сервиса доступен.
- После отзыва SQL-проверка точного пользователя и client_id вернула active=0, revoked=1. Страница именно этого коннектора в настоящем Claude Desktop самостоятельно показала “You’re not connected to Искра yet.” и кнопку Connect. Нового авторизационного запроса не инициировали.
- Граница: в личном кабинете подтвердили подключение, discovery инструментов и отзыв. Вызовы изменения учебных данных и отрицательный запрос со старым токеном относятся к отдельной серверной проверке с изолированными преподавателями.
