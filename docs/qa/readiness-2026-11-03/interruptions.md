# Матрица прерываний и выхода из ожидания

Для каждого сценария проверять четыре условия: пользователь понимает состояние; может отменить/закрыть или сменить действие; повтор безопасен; запоздалый ответ не меняет состояние нового действия. Обязательно проверять не только счастливый путь.

| Процесс | Прерывание | Статус и доказательство |
|---|---|---|
| Apple native OAuth | Закрыть браузер без callback, вернуться в приложение | PASS после появившегося исправления; реальный iPhone ещё не принят |
| Apple native OAuth | Browser.open не завершается, +120 секунд | FAIL на настоящей логике с native fixture |
| Apple native OAuth | Browser.open отклоняет promise | PASS снятия busy; intent остаётся |
| OAuth | Смена Apple → Google после отмены | FAIL: Google disabled в сценарии отмены |
| OAuth | Явный отказ провайдера в callback | Управление PASS, текст FAIL: access_denied; AUTH-INT-04 |
| OAuth web | Блокировка popup/перехода, возврат Back/bfcache | NOT TESTED |
| OAuth native | Фон/возврат во время обмена callback; холодный запуск | NOT TESTED на устройстве |
| OAuth | Отмена → новый вход → поздний ответ старого | NOT TESTED |
| Вход по паролю/коду | Не завершающийся Auth, смена формы/почты, повтор | FAIL controlled-service: OTP send/verify и password→reset; continuation-2.md |
| Восстановление | Закрытие письма, устаревшая/повторная ссылка | Повтор ссылки PASS API; прочее NOT TESTED |
| Приглашение | Закрытие формы/ошибка → повтор без дубликата | NOT TESTED |
| Создание курса | Перезагрузка после сохранения | PASS для опубликованного курса |
| Сохранение курса | Конфликт времени в группе | FAIL понятности ошибки; COURSE-SCHEDULE-01 |
| Сохранение курса | Обрыв на каждом отдельном серверном шаге | NOT TESTED; проверить частичный статус/доступ |
| Сдача ДЗ | Ответ сервера потерян после commit, повтор | PASS browser-cycle, одна попытка |
| Возврат ДЗ | Новый сеанс, новая попытка, повторная отправка | PASS: 10-step browser return replay; две истории сохранены |
| Проверка ДЗ | Закрыть/сменить ученика во время сохранения | NOT TESTED |
| Фото/файлы | Отменить выбор, загрузку, потерять сеть, повторить | NOT TESTED |
| Расписание/журнал | Ошибка записи, закрытие, устаревшая вкладка | Deferred service: FAIL зависание окна; PASS retry и partial-save; серверный UI журнал ещё не принят |
| ИИ/Тестли | Закрыть, таймаут, вернуться, поздний результат | NOT TESTED на настоящих интеграциях |
| Модальные окна | Escape/крестик/backdrop/назад/внешний переход | NOT TESTED полной матрицей |
| Учёт оплат | Повтор/таймаут записи, отмена исправления | NOT TESTED через UI |
