# Короткий CI локального оформления

Запрос Дани: не задерживать каждую мелкую правку полным набором. Область: CI/scripts, без изменения пользовательского экрана. Защита main, release:check, сборка и верификация прода сохраняются.

План/приёмка: отрицательные примеры classifier (логика, workflow, другой селектор, media, неизвестная база), многокоммитная ветка с ранней правкой логики, реальный diff PR206. Targeted browser — настоящий TimecodeRail320px, Chromium,4платформы×2темы,0/10/100, переключения/скролл/геометрия. Само изменение workflow проходит полныйCI. После main отдельная непубликуемая косметическая проба должна выбрать chapter-ui и пропустить только полный набор. Измерить длительность по GitHub, удалить пробу после проверки.

Локально: classifier и временный Gitрепозиторий PASS, реальный diff9f33c11c→fe4f70e0 выбирает chapter-ui. Targeted browser PASS, YAML разобран RubyPsych, checkReleasePolicy PASS. Ни окружение, ни метка коммита не могут принудительно включить быстрый набор. Workflow_dispatch всегда полный. Физические устройства/авторизованныйE2E не нужны для изменения оркестрации и не заявляются.
