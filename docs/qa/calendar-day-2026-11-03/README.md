# Календарь: наполненный стенд и проверка действий

База: `2dfc71679cb16dc72078a80b713f13a84bc98023` + локальные изменения текущего
чата (SHA базы также записан в populated-results.json). Production не обновлён.
Стенд: `/qa/calendar/` локального Vite. Запуск: `npm run check:calendar-browser`.

## Исправления

Большой виджет автоматически включал weekMode, пропуская занятия всей недели.
Exit-анимация удерживала старые карточки. Эти причины устранены. Наполненный
стенд дополнительно выявил отсутствие фейдов списка и возврат «Сегодня» только
к полоске недели: подключён useScrollFades, Сегодня выбирает текущую дату.

## Проверено

Локальный Chrome, реальный WidgetTodaySchedule/TeacherSchedule, фиксированная дата
03.11.2026, различимые ID и подписи каждого дня и недели, без серверных записей.
Фикстуры: 12/2/0/3/1/1/0 занятий, длинное имя, запись и отменённый урок.
Стенд readOnly: создание, редактирование и перенос здесь отключены.

меняются параллельными чатами; HMR в тестовом сервере отключён.

## Закрепление

`calendar-browser.yml` запускает тест на push и PR, устанавливает Chromium,
сохраняет артефакты при успехе и ошибке. Удалённый CI ещё не запускался: изменения
не отправлены. Playwright включён в package.json/lockfile; временный путь к
чужому node_modules больше не нужен. Результат запуска с намеренно отключённым
фильтром даты — в mutant.log; этот запуск должен завершаться ошибкой.

## Не проверено

Живые данные аккаунта, загрузка/ошибка/поздний ответ сервера, сохранение,
создание/редактирование/отмена/перенос, меню, drag-and-drop, свайпы, Safari/Edge,
физические устройства, landscape, zoom, screen reader, количественный контраст,
производительность и полная геометрия движения. Reduced motion покрыт только
на планшетной ширине. Декабрь/январь и граница года пока не включены в фикстуры.
Стенды остальных экранов этим прогоном не приняты.

## Дополнительный аудит качества теста

Исследование `../qa-research-2026-11-03.md` уточняет границы доказательств:
выборки перехода начинаются после ожидания правильных карточек и поэтому не
проверяют весь интервал с момента клика. Проверка opacity самого узла не
доказывает видимость с учётом предков, положение в окне и доступность клика.
Утверждение mask != none не доказывает правильность каждого края маски.
150 — число записей результатов по конфигурациям, а не независимых функций.
Эти ограничения не закрыты одним успешным прогоном; до полной приёмки нужны
отдельные проверки, перечисленные в исследовании.
