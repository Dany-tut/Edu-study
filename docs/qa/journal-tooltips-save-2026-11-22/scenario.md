# Журнал: объяснения значков и подтверждённое сохранение

- Область: custom tooltip для существующих DOM title во всём приложении и Tooltip-компонента; подробные статусы ячеек журнала; однозапросное сохранение отметки расписания.
- База: 823f91a4; окончательный SHA и patch фиксируются в отчёте после проверок.
- Риск: не показывать сохранение до подтверждения БД; не стирать оценки/чужие отметки; перенос и запись не должны списывать баланс. Tooltips не перехватывают клик/тач и не меняют раскладку.
- Проверка: локальный fixture UI Chromium с подменёнными данными, Postgres-compatible PGlite для транзакции и доступа. Production — только read-only проверка определений функций и pg_stat_statements. Реальная запись в production не выполняется.
- Версии: ПК hover/focus; iPhone/iPad/Android touch не вызывает tooltip, подписи доступны в ячейке/редакторе и aria-label. Обе темы; ПК 1440×900, 1280×720; iPhone 320/390; iPad 820/1180; Android 412. Физические устройства не проверены.

| Оранжевый !, галочка, просмотр записи | Подсказка на конкретном значке объясняет ДЗ/просмотр; вся ячейка поясняет посещаемость и ДЗ отдельно | NOT TESTED |
| Короткий/длинный title; края окна; модальное окно | Один custom tooltip в границах окна, без нативного дубля и обрезания overflow | NOT TESTED |

| Hover, уход, переход к соседнему, focus, Escape, scroll, touch | Открытие/закрытие без зависания; клики и tab не перехвачены; touch без hover | NOT TESTED |
| Динамическая подпись при hover | Подсказка обновляется; уход восстанавливает новое значение, не старое | NOT TESTED |
| Сохранение присутствия/оценки/очистки | Один RPC; закрытие только после ответа; точный ученик/занятие, процент посчитан на сервере | NOT TESTED |

До окончательного отчёта UI fixture не считается полноценной production E2E-приёмкой. Цель секунды требует замера авторизованного сетевого пути после выпуска; локальная задержка API моделируется отдельно.
