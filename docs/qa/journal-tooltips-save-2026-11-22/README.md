## Результат

- Оранжевый «!» — долг по ДЗ (просрочено / ниже порога / на доработке), независимо от присутствия. Подсказка отдельного значка поясняет ДЗ, ячейки — все её состояния. Галочка и повторный просмотр также подписаны.
- Общий NativeTitleTooltips переводит существующие HTML title во всём приложении в custom-подсказки. Использует тот же портал, что Tooltip: перенос строк, границы окна, keyboard focus, Escape, скрытие при прокрутке/клике. Исходные title восстанавливаются при уходе, динамические изменения учитываются. Image alt сохраняется как альтернативный текст изображения.
- Для расписанного занятия — один teacher_journal_save_fast: прежняя проверка владельца/источника/баланса, отметка и процент посещаемости в одной транзакции. Legacy fallback только на отсутствие RPC (PGRST202), не на таймаут или ошибку доступа.
- После подтверждённого ответа AttendanceEditor передаёт только записанные отметки родителю: таблица обновляется вместе с закрытием окна. Полная сверка идёт в фоне. Ответ чтения, начатого до подтверждения, не стирает отметки; чтение, начатое после него, авторитетно. Даты, расписание, JSON курсов и записи уроков эта правка не меняет.

## Проверки

PASS: tsc --noEmit, check:ui, check:i18n, production build (тестовые публичные env, без production-учётной записи). Startup assets: 494896 B, shell 1190818 B; серверных ключей в dist нет. Общая подсказка загружается отдельным lazy-модулем.

PASS: Chromium fixture, реальные Tooltip, NativeTitleTooltips, AttendanceEditor, useAttendance и journalCell; API подменён. Проверены вложенные title/«!», исчезновение и смена title при hover, удаление DOM-узла, сохранение обработчика клика, focus, Escape, scroll. Геометрия: 1440×900, 1280×720, 320×700, 390×844, 820×1180, 1180×820, 412×915 × светлая/тёмная тема. Touch-эмуляция iPhone/iPad/Android не открывает hover. Доказательства: browser-results.txt и два PNG.

PASS: двойной клик — один RPC. При API-задержке 450 мс окно закрылось и значение ячейки изменилось за 796 мс в полном fixture-прогоне. До ответа нет нового значения; отказ оставляет окно и черновик. Ошибка доступа не вызывает повторную запись. Старая БД вызывает единственный legacy fallback.

PASS: confirmed-check.mjs проверяет через production journalCell оценку/присутствие/пропуск/очистку, сохранение чужих отметок, неизменность дат, коллизию разных уроков в один день, другую область данных, позднее старое чтение и более новое подтверждение.

PASS: actual PL/pgSQL fast RPC в изолированной PGlite: присутствие, сохранение оценки при отсутствии grade, частичный patch другого ученика, очистка, 67% сводка, источники recording/transfer, запрет чужих ученика/занятия и anon; ошибка обновления сводки откатывает отметку. Использовались определения teacher_lesson_save и teacher_journal_save из предыдущей production-миграции. Финансовый триггер этим fixture не тестировался, его код не менялся.

## Границы и выпуск

Production проверялся read-only: определения RPC, индексы и pg_stat_statements. В накопленной статистике сохранения есть группы со средним 487 / 1958 мс и максимумом 1907 / 5755 мс. Это не замер конкретного клика на скриншоте. Российский прокси — резерв, домен страницы сам по себе не доказывает его использование.

Не выполнены: запись с реальной учётной записью на production, физические iPhone/iPad/Android, полный обход всех экранов приложения. Проверка mobile sheet в дополнительном fixture не принята (tap не дождался устойчивого footer); к приёмке touch-подсказок и desktop-сохранения она не относится. Секунда на реальной сети пока не подтверждена. Нет изменения overflow/фейдов таблицы, поэтому полный QA её прокрутки здесь не заявляется.

Миграция и UI не выпущены. Сначала применить fast-save миграцию штатным процессом оператора, затем выпустить клиент из main по действующим правилам. Старый клиент совместим; новый клиент на старом сервере использует legacy fallback. После выпуска измерить время одного RPC и появления ячейки на фактическом соединении Дани.
