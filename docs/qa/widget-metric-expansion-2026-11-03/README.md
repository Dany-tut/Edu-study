## Результаты fixture UI

В браузерном редакторе (viewport 1440×900, светлая тема) каждый из 12 stat-показателей реально перетянут 1×1→2×1→1×1 за угловой маркер. У всех измерены w=2/h=1 после расширения и w=1/h=1 после сжатия; картинки загружены (naturalWidth>0), display:block и внутри горизонтальных границ карточки. Подробности — resize-desktop.json. Первое переключение «Уроков сегодня» прервал dev-reload из-за первичной оптимизации clsx; после окончания оптимизации повторены остальные десять типов, данные прерванного шага не засчитаны.

У «За месяц» клик «Открыть» переключил наблюдаемый activePage на finances (fixture не рендерит сам экран финансов, серверный E2E не засчитан). В галерее выбран 2×1 для «Проверить ДЗ», после добавления на столе измерено stat-hw: w=2/h=1. Остальные доступные размеры защищены общей регрессией; каждый выпадающий список отдельно не прокликан.

На viewport 390×844 в тёмной теме «За месяц» перетянут из 1×1 в 2×1: фактический размер 326×116, кошелёк загружен и целиком внутри карточки, видны подпись/прочерк/«будет позже». Обратное сжатие вернуло 1×1. Это browser viewport, не физический телефон. Доказательство: earnings-expanded-mobile.png в каталоге визуализаций чата.

Негативный контроль: временно возвращён исходный список stat-earnings только с 1×1; новая проверка упала с actual [1,1], expected [2,1] (checkWidgetSizing.mjs). Затем список восстановлен. Изменения не добавляют запросов данных: placeholder дохода сохранён. Это частичная приёмка resizing/иллюстраций, не всей платформы и не покадровая оценка анимаций.
