# Компактные показатели: выравнивание

Область: одинаковые заголовок, иконка, число и отступы в 1×1; дополнительные подписи не сдвигают число. «Требуют внимания» сохраняет действие перехода к группам. Большие карточки сохраняют свою композицию.

База: a8bc30777e221f68afef223e2e7c3651d3dfe5dc + изменения WidgetAttentionStudents.tsx и widgets.css. Итоговый чистый SHA фиксируется историей коммита.

План fixture UI (настоящие компоненты, подменённые ответы): 156×116 и 190×140 (1×1), 320×116 (2×1), светлая/тёмная тема. Ожидаем одинаковый y заголовка и числа относительно карточки у всех компактных показателей, отсутствие геометрического выхода текста. Подпись следующего занятия сохраняется. A/B с одинаковым количеством, поздние ответы и серверные изменения не затрагиваются CSS-правкой и не считаются проверенными.

| Сценарий | Ожидание | Результат |
|---|---|---|
| 1×1 с подписью и без неё | Число на одной высоте | PASS (fixture UI) |
| «Требуют внимания» 1×1 | Те же отступы, значок, число | PASS (fixture UI) |
| 2×1 | Сохранены 3D и уточнение | PASS (fixture UI) |
| Смена размера без reload | Нет наложения заголовка и числа | PASS (fixture UI) |
| Действие «Требуют внимания» | Переход к группам | PASS (fixture UI) |

Непроверенное: физические устройства, полный серверный цикл, loading/error, все сочетания локализаций, движение при замедленном CPU. Прокрутку не добавляли/не переносили; затронутые 1×1 не должны прокручиваться.

Факт: у 26 настоящих экземпляров (13 типов × 2 размера) заголовок начинается на y=11 px, число на y=44 px относительно карточки. Два дополнительных экземпляра MiniStatCard с подписью «след. 17:30 МСК (21:30 ВН)» сохраняют оба времени и имеют тот же y числа. При изменении ширины на +8 px без reload позиции совпали у всех 28; выхода за высоту контейнера не обнаружено. Проверены светлая и тёмная темы, browser viewport 1280×720 и 390×844. Это эмуляция ширины, не физический телефон.

Негативный контроль: временное удаление общего правила строк дало y числа 45/48/60/67/69/85/93 px — инвариант ловит исходный дефект. Затем правило восстановлено, повторное измерение дало только 44 px. Клик по компактной кнопке «Требуют внимания» изменил наблюдаемый activePage на groups; серверный экран групп этим fixture-тестом не проверен.

Доказательства: compact-alignment-light.png, compact-alignment-mobile-dark.png в каталоге визуализаций текущего чата. Автопроверки и production SHA будут указаны в финальном отчёте после выпуска. Прочие ограничения выше сохраняются; приёмка частичная.
