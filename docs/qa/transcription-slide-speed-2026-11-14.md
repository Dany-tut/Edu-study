# Ускорение чтения слайдов — приёмка

База: af90c3f057225ac32a7cae80802f20d3491e20fd. Ветка codex/slide-ocr-speed. UI и контракты задания не изменяются. Рабочие процессы пользователя/преподавателя и установленный модуль не затрагиваются при тестировании.

Проверка выполняется на изолированном fixture runtime и тестовых видео, не на записи преподавателя. Ожидаем идентичные главы/времена до и после, меньше OCR для неизменных областей, обнаружение локального изменения номера, отсутствие накопления дрейфа при сравнении, ограниченную память, освобождение декодера при ошибке и остановку всей группы при отмене. Отдельно проверяем корректное следующее задание после отмены. Интерфейс не меняется, новая матрица мобильных UI не требуется.

План: короткий A/B/A; Full HD 30 fps с движением вне выбранного края, короткой четырёхсекундной темой и заголовками, отличающимися одной цифрой; односекундное видео; повреждённые/неполные кадры; отмена реального задания. Сравниваем полные массивы глав, замеряем одну и ту же запись на одном runtime последовательно.

## Результаты

- A/B/A 18 с: старый 5,247 с / 11 OCR, новый 0,890 с / 2 OCR (5,9×); главы совпали полностью.
- Full HD 1920×1080, 30 fps, 90,03 с, движущийся фрагмент вне выбранной области: старый 29,175 с / 50 OCR; финальный новый 2,993 с / 4 OCR (9,75×). Массивы одинаковы: ТРИПАНОСОМА0, ЛЯМБЛИЯ1 30, ЛЯМБЛИЯ2 45,5. Четырёхсекундная тема и изменение цифры сохранены. Замеры последовательные на одном Mac/runtime, модели уже загружены. Это не обещание такой же скорости на каждом видео преподавателя.
- Найден и исправлен отдельный дефект уточнения VFR: точный seek выбирал следующий кадр, завышая раннее появление темы. Полное VFR-видео теперь даёт0/30/45,5; отдельный воспроизводимый тест с редкими цветными кадрами требует0/5,5/9.
- Полусекундное видео: один кадр, штатный пустой результат (как раньше — тема требует двух наблюдений).
- Реальная отмена: группа35892, дочерние35894/35898 остановлены за0,399 с, gate освобождён; следующее задание завершилось с двумя ожидаемыми главами.
- 48 обычных Python-тестов PASS; дополнительно тест реального FFmpeg/VFR PASS (в OCR-окружении8 тестов slide_frames). Проверены шум сжатия, изменение9 пикселей в локальной плитке, накопление дрейфа, повтор слайда, контрольный OCR через60 с, предел кэша, повреждённый кадр, завершение декодера при исключении.
- Доказательства: `.build/qa/compare.log`, `compare-long.log`, `final-speed.log`, `edges.log`, `frame-tests.log`, `cancel-ocr.log` в рабочей копии. На физическом Mac преподавателя не запускалось; его текущее задание не изменялось. Новых элементов UI нет.
