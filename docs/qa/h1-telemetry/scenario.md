# H1 — приёмка диагностической логики

Карточка заполнена до запуска тестов. Изолированная ветка codex/h1-telemetry-classification от origin/main c29519cb. Изменяемая область — сбор и классификация метаданных; TSX/CSS, роутинг UI, данные пользователей, RLS и реальные запросы не меняются.

Риск: ошибочно скрыть реальный сетевой отказ или записать секреты из адреса. Ответственный за реализацию и проверку — текущий агент; независимого ревью нет.

До коммита проверяется dirty tree относительно указанной базы, после коммита повторяется логическая проверка на точном SHA. Сервер, роли и браузерные клики: неприменимы к изолированным контрактным тестам; полная приёмка настоящего браузера/физического устройства не заявляется.

| Область | Действие | Ожидаемый результат |
| --- | --- | --- |
| Источник | QA flag, webdriver, Headless UA, обычный UA | qa / automation_suspected / browser_unclassified; ничего не удалено |
| Адрес | OAuth grants, динамический ID, storage, query token | Точный технический маршрут, секреты и ID не записаны |
| Успех/HTTP-ошибка | 200 / 503 | Тот же Response, один итоговый api_request |
| Отмена | DOMException AbortError, Error с name AbortError, Request/init.signal | api_cancelled; та же причина передана вызывающему |
| Таймаут | TimeoutError и signal.reason TimeoutError | api_request outcome timeout, не отмена |
| Настоящий отказ | TypeError, произвольная ошибка, pagehide | Ошибка сохранена, не скрыта из-за ухода |
| Переход/поздний ответ | pagehide/pageshow и смена маршрута до ответа | Снимки начала/конца; исходный ответ неизменен |
| Не завершившийся запрос | Таймеры 8/30 с | api_slow/api_stalled только для видимой активной страницы и неотменённого запроса |
| Повторная доставка | outbox replay с тем же incident_id | Старый ID сохранён для дедупликации монитором; actor на момент события |
| Поломка отчётчика | sink бросает исключение | Запрос и ошибка не меняются |

Кнопки, движение, темы, overflow и размеры: неприменимы — интерфейс не меняется. Вся браузерная/устройственная область остаётся непроверенной. Намеренно возвращённый дефект: тест вложенного OAuth пути должен упасть со старым алгоритмом обрезки.

## Результаты до фиксации коммита

- PASS: npm run check:diagnostics — источники, адреса/секреты, HTTP и транспортные ошибки, обе формы AbortError, Request.signal и init.signal, TimeoutError в signal.reason, pagehide/поздний ответ, локальный native fetch POST/abort/deadline, outbox/replay и actor.
- PASS: npx tsc --noEmit; npm run check:ui; npm run build (включая checkStartupAssets).
- Проверка самого теста: ISKRA_H1_MUTATE_ENDPOINT=1 вернул исходный дефект и получил AssertionError с actual /auth/v1/user, expected /auth/v1/user/oauth/grants. После снятия мутации тест прошёл.
- Сборка оставляет существующие предупреждения про необязательный VITE_CLARITY_ID, eval в lottie-web и размеры чанков. Настройки production не менялись.
- PARTIAL: только логический/локальный HTTP-контракт. Приёмка настоящего браузера с сервером, физического iPhone, производительности и H2 не проводилась. UI не менялся. Реальное поступление маркированных production-событий проверять после согласованного выпуска.
- Точный SHA и результаты повторной проверки чистой рабочей копии сохраняются вне Git в /Users/dany/.codex/monitoring/h1-verification.json, чтобы не изменять сам проверенный коммит отчётом о нём.
