# SOC-01 · одно приглашение, два согласия
База 1d80bf3081f9ba4b518e5a91a6988c07568145ad; итоговый SHA256 миграции — в result.txt.
Автор и проверяющий: Codex. Локальный PostgreSQL (PGlite), синтетические A/luna_7, B/sever_9, C/volna_2, роли anon и authenticated. Никаких данных production.
Риск: выдача чужой карточки, подмена адресата, принятие запроса отправителем.
До прогона все строки NOT TESTED. Предмет проверки — только контракт БД.

| Действие | Независимый ожидаемый результат |
|---|---|
| Назначить ники A/B/C | Разные аккаунты, повтор своего ника допустим; недопустимый ник отвергнут |
| Выпустить/заменить/отозвать/просрочить ссылку | Старый секрет не открывается и не создаёт запрос |
| B открывает и использует ссылку A | Видит только ник A; один запрос B → A; ссылка сгорает |
| B или C пытается принять | Ни один не меняет состояние пары |
| A принимает; A и B перечитывают список | У обоих один друг с ником другого; у C пусто |
| B удаляет связь; A отклоняет новую заявку | Обе стороны видят пустой список |
| Прямое чтение и анонимный вызов | Отказ; нет чтения таблиц, академических полей и UUID аккаунта в ответах |
| Повтор/своя ссылка | Нет дублей и дружбы с собой |

Одновременные транзакции и потеря HTTP-ответа требуют отдельного интеграционного прогона. Интерфейс приложения в этом срезе не меняется; фокус, overflow, движение, темы, физические устройства, E2E и поздние ответы UI не принимаются. Макет статический.

Результат: все перечисленные последовательные проверки контракта прошли; см. check.mjs и result.txt. Серверный стенд с Supabase Auth/PostgREST, физические устройства, конкурентные запросы из независимых соединений, mutation testing и ученический/учительский E2E не проверялись. Общий статус PARTIAL.
