# Компактный вход «Иллюстрация рядом»

Карточка до запуска QA. Ответственный за реализацию и проверку: Codex.
База `1d80bf3081f9ba4b518e5a91a6988c07568145ad`, локальный patch и хеши сборки будут сохранены отдельно. Другие изменения рабочей копии не относятся к задаче.

Сценарий: пользователь выбирает ученика/препода → компактная форма с иллюстрацией справа → пароль либо Apple/Google либо код преподавателя. Существующая авторизация сохраняется. Риски: переполнение узкого экрана, скрытые действия при клавиатуре, неверный OAuth provider/role, потеря ввода при переключении видимости и восстановлении.

Окружение: локальный браузер с эмуляцией размеров/касания, без подключения к телефону пользователя. Реальный UI с подменёнными отказами сети; вход в настоящие аккаунты и отправка настоящих писем исключены. Browser UI/fixture и серверный E2E разделяются.

Остаются отдельной областью: реальная выдача сессии, OAuth в Apple/Google, настоящие письма/коды, физические устройства, аппаратная клавиатура iOS. Любые ограничения результата перечислить после прогона. Итог относится только к точным хешам исходников и локальной сборки, не ко всему приложению.

## Проверка реализации

- `npx tsc --noEmit`, `npm run check:ui`, локальная production-сборка Vite — PASS. `hashes.json` фиксирует исходники и JS/CSS/HTML проверяемой сборки; `source.patch` содержит изменения отслеживаемых файлов, новые AuthHero.tsx/authLayout.css доступны по хешам и в рабочей копии.
- Общий AuthHero и стили карточки применены к обеим ролям и состояниям восстановления. Формы не уменьшают ввод ниже 16 px и зоны основных действий ниже 44 px. Apple — существующий SVG-знак без видимой подписи, с доступным именем; Google — существующий цветной SVG и Google. Политика и условия вынесены за карточку, внутри того же ScrollFade.
- Найден реальный дефект при эмуляции касаний: CSS `:has(input:focus)` смещал компактную форму при blur и терял клик по восстановлению. Сохранены `focus-click-before-fix.json` и `reset-debug.png`. Убраны изменения геометрии от одного фокуса; существующий useKeyboardState продолжает учитывать реальную открытую клавиатуру, низкое окно использует выравнивание сверху. Повторное нажатие проверяется реальным кликом в основном драйвере.
- Один дефект QA-драйвера: чтение localStorage внутри перехвата навигации блокировало сам переход. Исправлено наблюдением Storage.setItem через binding до ухода со страницы. Первый сбой сохранён в `driver-navigation-before-fix.json`. Проверка текста кода заменена на семантическое наличие alert (текст зависит от нормализации AuthError).
- Скриншоты `teacher-mobile.png`, `student-mobile.png` — 390×844; `teacher-desktop.png`, `student-desktop.png` — 1440×900. На 390 px обе формы помещаются полностью, включая юридические ссылки.
- React review: компоненты вынесены за страницы, лишних эффектов/запросов не добавлено, доступные имена провайдеров сохранены, студент учитывает reduced motion, ширина и логотипы не меняются при loading. Существующие обработчики авторизации сохранены.

Область отчёта: настоящий UI локальной production-сборки, контролируемые ответы Auth и перехваченный OAuth URL. Нет настоящего входа, отправки писем или подключения к устройству. Safari/WebKit, физические устройства, настоящие OAuth-провайдеры/коды/сессии, аппаратная клавиатура iOS, увеличение системного текста и количественный контраст каждой пары остаются NOT TESTED. Переходы сохранены как геометрия кадров от момента до клика; это не заменяет визуальную оценку на физическом устройстве. Общая полная матрица — PARTIAL. Production не изменён.

Финальный браузерный итог — PASS для 24 комбинаций: 2 роли × 2 темы × 6 окон (320×568, 390×844, 768×1024, 1440×900, 1024×500, 844×390). Проверены реальные кнопки и поля, логотипы и один ряд провайдеров, принадлежность иллюстраций ролям, размеры целей/полей, фейды трёх позиций, сохранение пароля при показе/скрытии, восстановлении и синтетическом отказе, отмена запроса с поздним отказом. На 320 и 1440: отправка синтетического восстановления, раскрытие/отправка/ошибка/смена почты кода преподавателя, пять возвратов к роли, быстрый повтор, Escape, reduced motion, исходящие OAuth provider и role для Apple/Google. Ошибок JavaScript — 0. Полные результаты в results.json, движение в *-frames.json. Просмотрены начало/середина/конец на 320 в обеих темах и десктоп, включая раскрытую форму кода. Физические устройства не использовались.
