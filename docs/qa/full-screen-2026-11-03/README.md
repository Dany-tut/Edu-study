## Что мешает полной приёмке

- Apple callback/идентичность/сохранение сессии остаются без подтверждения ручного входа; вся матрица OAuth-ролей/устройств не пройдена.
- Claude/MCP endpoint404; рабочая внешняя интеграция не подтверждена, хотя routing consent исправлен.
- R2 не развёрнут/не настроен. Telegram не настроен; неподписанные обновления теперь отклоняются. Доставки в настоящий Telegram-чат не было.
- Учебные платежи проверяют учёт. Эквайринг/автоматическое списание тарифа не реализованы; интерфейс тарифа отправляет заявку. Эти функции не считать успешной платёжной интеграцией.
- Остальные языковые решатели, все вложения, canvas/микрофон/ASR, весь UI-путь Тестли, все конфликты, DST/пограничные зоны, каждая кнопка/zoom/контраст/screen reader остаются частично или не проверенными.
- Нет полной физической матрицы iPhone/Android/iPad. Web emulation и preflight её не заменяют.
- Локальные нагрузка/restore не подтверждают ёмкость и RPO/RTO production. Разрушительный restore рабочей базы ради теста не выполнялся.

По этим причинам нельзя сообщать «всё проверено» или процент готовности. Отдельный успешный релиз исправлений не закрывает оставшиеся клетки.

## Почему проверки должны были ловить это раньше

Проверка открытия экрана/числа строк не доказывает правильность данных. Отрицательные прогоны показали, что нужен независимый oracle: выбранные IDs, принадлежность, ожидаемые ответы и серверный эффект. Отдельно нужны два локальных хранилища черновика, ID после копирования, повтор после потерянного commit, одна/нулевая оценка и клавиатура. Табличная RLS не заменяет аудит RPC; старт OAuth не заменяет возврат; mock/dev demo не заменяет реальную сессию.

В `results.json` отдельно сохранены ошибки подготовки драйверов: межконтекстное сравнение массивов, ожидание комментария до раскрытия истории, consent на свежем устройстве, одинаковые подписи разных работ, неверный корневой скроллер, отсутствие student_session и HTTP-сервер без SPA fallback. Они исправлены/исключены из покрытия, не объявлены дефектами продукта. Так же нельзя засчитывать loading shell как готовый экран.
