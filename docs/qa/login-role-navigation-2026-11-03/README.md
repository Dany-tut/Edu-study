# Вход и возврат к выбору роли

Карточка до проверки. Область: подписи, иллюстрации, новая кнопка возврата и существующий выбор роли. Риск: неверная роль и недоступный возврат на узком экране. Исправление и проверка: Codex.

База: `c688b13db9f049bad523334495c9f35ff7e7fd8f`; точные хеши файлов — в runtime-hashes.json. Рабочая копия содержит изменения других задач. Локальный браузер Chromium, без входа в аккаунт и без отправки писем. Проверяется настоящий UI, серверная авторизация не входит в область.

| Элемент | Действие → ожидаемый результат | Матрица | Статус до запуска |
|---|---|---|---|
| Выбрать роль на обоих входах | Обычный/повторный возврат → видны обе роли, форма закрыта | 320, 390, планшет, десктоп, низкое окно; light/dark | NOT TESTED |
| Я ученик / Я препод | Выбор → соответствующий заголовок и иллюстрация | Те же размеры/темы | NOT TESTED |
| Закрыть выбор роли / Escape | Возврат на лендинг | Телефон/десктоп | NOT TESTED |
| Пароль / показать / скрыть | Значение сохраняется, видимость переключается | Оба входа | NOT TESTED |
| Забыли пароль / назад | Форма восстановления → исходный вход | Оба входа | NOT TESTED |
| Прокрутка | Начало/середина/конец → только нужные фейды, без горизонтального overflow | Телефон/десктоп | NOT TESTED |
| Клавиатура | Tab/Enter → возврат доступен с видимым фокусом | Оба входа | NOT TESTED |

Временные риски: наблюдать переход до клика; повторять переключение ролей; выход вызывает существующий action.cancel(), поздний результат не должен вернуть старый экран. Отправка запросов, OAuth и восстановление настоящего пароля не проверяются. Новый пароль не показывает переключатель роли: активный recovery-поток в App имеет приоритет над маршрутом.

Неохваченные заранее комбинации: физические устройства, Safari, нативный контейнер, реальная авторизация/письма/OAuth, сетевые гонки входа. Все остальные элементы форм вне изменённого сценария требуют отдельной приёмки. Финальный результат и доказательства будут добавлены после прогона.

## Результат

- `npx tsc --noEmit`, локальная production-сборка Vite и `npm run check:ui` прошли. Один промежуточный повтор check:ui упал на синтаксисе сгенерированного общего cache-файла homework facts; повтор без изменения исходников прошёл. Предыдущие успешные и финальные логи сохранены.
- Найден дефект: Escape не закрывал выбор роли. `escape-before-fix.json` сохраняет падение; обработчик Escape и начальный клавиатурный фокус добавлены в RoleChooser.
- React review: общий компонент заголовка, существующие Loop-иконки и токены, без дополнительных сетевых запросов; перед уходом отменяется текущая задача формы. Чужие изменения клавиатуры в TeacherLoginPage сохранены.
- Визуальная область ограничена локальной сборкой и перечисленными скриншотами. Покадровые JSON содержат маршрут и заголовок с начала взаимодействия; они не доказывают плавность всей сцены. Ручной просмотр движения на физическом устройстве, reduced motion, zoom, альбом телефона, быстрые двойные клики, hover/pressed/контраст всех элементов и настоящие поздние ответы сервера остаются NOT TESTED.
- Серверные E2E, реальные аккаунты и нативное приложение не проверялись. Production не изменён. Общий статус PARTIAL по полной обязательной матрице.

Браузерный итог: PASS для 20 комбинаций (2 роли × 2 темы × 5 размеров: 320×568, 390×844, 768×1024, 1440×900, 1024×500). `results.json` фиксирует проверки заголовков, загрузки иллюстраций, отсутствия горизонтального overflow, фейдов в трёх позициях, показа/скрытия пароля, восстановления/возврата, Enter для выбора роли, повторных переключений между обеими ролями и Escape. На 320 и 1440 выполнено пять циклов в обе стороны. Ошибок JavaScript нет. Снимки начала/середины/конца на 320 и десктопа просмотрены в обеих темах; desktop без overflow показывает отсутствие фейдов. Кнопка закрытия мышью отдельно не проверена. Статусы строк карточки для перечисленных проверок — PASS; закрытие мышью и остальные отмеченные ограничения остаются NOT TESTED.
