# Высота карточки расшифровки · ПК

- База: 8037f91b2bf2b5800081a09db501dd38cea55a3b; патч LocalTranscription.tsx/localTranscription.css.
- Причина: невидимые walkthrough/management/update накладываются в одной ячейке grid через visibility:hidden и определяют её intrinsic height. Даже закрытая setup занимает строку с padding/gap.
- Исправление: только html[data-platform=pc], display:none для неактивных состояний и полностью закрытого setup. Страницы открытого walkthrough сохраняют прежнюю геометрию.
- Ожидание: низ подключённой карточки на 18px + граница ниже кнопок; раскрытие/сворачивание возвращает исходную высоту. Обновление, ошибка, подключение и все шаги установки доступны.
- План fixture: настоящий TranscriptionModuleCard, подменены только ответы Mac-модуля. Chromium, ПК1440/1280/900, две темы. Текущий/неизвестный/устаревший/обновляющийся/ошибка, 5 раскрытий, быстрый двойной клик, disconnect → шаги → busy → ошибка → retry.
- Регрессия других версий: сравнить размеры до/после на iphone390, ipad1180, android412. Физические устройства и авторизованный профиль не входят в fixture-проверку.
- Негативный контроль: отключение новых CSS правил должно вернуть пустой резерв и провалить проверку нижнего отступа.
- Прокрутка: карточка не создаёт собственной области overflow; проверка страницы в начале/середине/конце.
- Результаты: PASS. Chromium fixture: 3 ширины × 2 темы × 5 фаз, по5 раскрытий/закрытий и двойной клик; все шаги установки, permission, отключение, busy/error/retry. Консоль без необработанных ошибок. Нижний отступ19px с границей; негативный контроль возвращает327.8px резерва. Размеры iphone/iPad/Android совпадают с вариантом без новых правил. check:ui и tsc — PASS. Физические устройства, реальный Mac-сервис и авторизованный E2E не проверялись. Цвета/типографика/переключение страниц инструкции не менялись; новый переход высоты синхронный без анимации.
