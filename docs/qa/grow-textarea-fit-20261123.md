# Приёмка высоты растущего поля

Стенд использует настоящий GrowTextarea, стили FIELD, Tailwind Preflight и
CSS Искры. Для Android в стенде загружен Roboto. Данные локальные.

- Сборка 1.0.3570 воспроизводит обрезание области прокрутки во всех 16 случаях
  для border-box. Chrome и WebKit, ПК, iPhone, iPad и Android, обе темы.
- После поправки все 16 случаев проходят. Как отдельная регрессия прошли 16
  тех же случаев при content-box. При вводе и сужении поля текст помещается,
  фокус и позиция курсора сохраняются; при удалении строк поле сжимается.
- Увеличение высоты относится к рамке и округлению, которые раньше
  вычитались из доступной для текста области. Значения, обработчики, размеры
  шрифта, внутренние отступы и ширина поля сохранены.

Стенд не использует авторизацию и физические устройства. Числа до/после
и скрипт воспроизведения сохранены в remaining-optical-20261123.
