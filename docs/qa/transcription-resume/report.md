## Ограничения

Mac не должен спать. После загрузки видео обработка локальная. При обрыве первоначальной передачи файла до принятия нужно выбрать файл снова. Загрузка веб-приложения с нуля без интернета не гарантируется; сервер продолжает работу независимо. Проверка сетевого сбоя загрузки выполнялась контролируемым исключением, физический интернет не отключался.
