# Галерея: добавление минимального размера

План до browser-проверки. База — 111f379c412d9d5750d27472d0ec7e95831d7d22 + patch WidgetLibraryModal.tsx/widgets.css. Удаляются выбор размера и ссылка на матрицу из галереи; добавление всегда начинает с 1×1 и применяет общие ограничения реестра. Изменение размера на столе сохраняется. Карточки галереи сжимаются без пустого ряда под выбор размера.

Ожидания: все 18 доступных типов добавляются с правильным type и минимальной допустимой парой (метрики и «Требуют внимания» 1×1; списки/напоминания/задачи 2×2; календарь 2×3). Никакого комбобокса/поля размера и ссылки «Вся сетка размеров». Календарь не получает запрещённый 1×1. После добавления метрика растягивается на столе до 2×1. Галерея закрывается по добавлению/крестику/фону/клавише Escape как прежде.

План: настоящий WidgetLibraryModal и DeskCanvas, fixture без серверного persist, разные type/ID и одинаковые нулевые счётчики. Проверить каждую кнопку добавления, повторное открытие, разные ширины, выбор отсутствует, start/middle/end прокрутки desktop light и phone dark, отсутствие фейдов при помещающемся списке, закреплённые действия. Измерять принадлежность type и w/h в onAdd, а не только число виджетов.

Непроверенное заранее: серверный E2E сохранения, физический телефон, OAuth, ошибки/поздние ответы сервера (запросы данных не меняются), все локализации, CPU slowdown. Общий статус поэлементной матрицы PARTIAL, PASS только для подтверждённых клеток ниже.

## Подтверждённые результаты

- В fixture UI каждый из 18 доступных типов реально добавлен кнопкой. Проверены type, x/y и w/h из onAdd: 12 компактных показателей/сводок 1×1, пять списков 2×2, календарь 2×3. Отдельно при viewport 390×844 добавлены календарь 2×3, ДЗ 1×1, должники 2×2.
- DOM галереи не содержит ww-gallery-size/select/combobox и ссылки на матрицу. После добавления «Студентов» угловым маркером получен 2×1 с иллюстрацией.
- Desktop light 1440×900: прокрутка 0/135/201.5 px при clientHeight=789, scrollHeight=990. Mobile dark 390×844: 0/861/1705 px при clientHeight=733, scrollHeight=2437. В начале виден нижний фейд, в середине оба, в конце только верхний. Шапка/крестик остаются без маски; последние кнопки видны и доступны. Снимки gallery-minimum-desktop-{start,middle,end}.png и gallery-minimum-mobile-{start,middle,end}.png — в визуализациях чата.
- В высоком desktop-окне список целиком помещается: clientHeight=scrollHeight=990, mask=none.
- Закрытие: Escape, крестик (5 повторов), фон и «Настроить на экране» в варианте onEditDesk закрыли галерею. Повторное открытие работало в цикле добавления всех типов.
- TypeScript npx tsc --noEmit прошёл. Численные факты — browser.json. Первый незавершённый обход прервал первичный dev-reload Vite при оптимизации зависимостей; его не засчитывали, затем весь обход 18 типов повторён.

Границы: мышь на desktop и узком browser viewport; не физический touch. Callback/fixture state проверены, серверное сохранение и общая матрица всех данных/тем/CPU не засчитаны. Для формы галереи нет запросов выбора размера, данные виджетов не меняются. Общий статус PARTIAL, перечисленные добавления/прокрутка PASS.
