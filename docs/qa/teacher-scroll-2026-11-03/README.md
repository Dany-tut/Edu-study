# Приёмка прокрутки страниц преподавателя

База 1d80bf3081f9ba4b518e5a91a6988c07568145ad, локальные изменения. Исполнитель и проверяющий — Codex. Стенд — локальный Vite, гостевой кабинет, браузер Chromium. Риск — повторное отсечение страницы предком на расстоянии 100 px от верхнего края.

| Элемент | Действие | Ожидание |
|---|---|---|
| Профиль, финансы | Начало → середина → конец → начало | Область прокрутки доходит до края окна. В начале виден нижний фейд, в середине оба, в конце верхний. При коротком содержимом нет маски. |
| Плавающая навигация | Прокрутка под шапкой | Геометрия шапки не меняется, навигация доступна. |
| Журнал, группы | Проверка архитектуры таблиц | Заголовок и имя закреплены; фейды располагаются на границе подвижных данных. |

Размеры для проверки — телефон и десктоп, светлая и тёмная темы. Запись данных, ответы сервера и бизнес-действия находятся за пределами проверки прокрутки.

## Результат — частичная приёмка

Chrome, 1440×840 и 390×720. Проверены профиль, финансы и тарифы в светлой и тёмной темах в трёх положениях. На телефоне профиль использует отдельный MobileScreen. В пустых финансах контент помещался; для проверки переполнения в DOM повторены блоки пустого состояния. Данные сервера не использовались. Снимки — [десктоп](1440.webp) и [телефон](390.webp). [Замеры](geometry.json) включают положение, маски и 51 кадр плавной прокрутки профиля. Координата шапки постоянна, точка на высоте 89 px доступна скроллеру на каждом кадре. Возврат overflow:hidden родителю убирает скроллер из этой точки.

Прошли npm run check:ui и tsc --noEmit. Хранилище проверено по подключению общего компонента. Таблицы проверены по исходникам. Не проверялись авторизованный серверный сценарий, полная матрица действий и состояний, планшет, физический телефон, Safari, увеличение текста и reduced motion.
