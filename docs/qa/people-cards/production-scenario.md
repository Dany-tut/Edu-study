- Область: реальные имена, роли, аватары; карточка профиля; удаление дружбы. Квизы вне scope.
- База: f0a8de7a; итоговый SHA фиксируется в релизном отчёте. До коммита — рабочий diff этой ветки.
- Ответственный: Codex. Риск: доступ к чужим персональным данным, удаление чужой связи, поздний ответ после закрытия.
- Данные: production dany_tut (учитель) / mita12222 (Митя, ученик); локальные A/B/C с разными ID для запретов.
- Ожидание: только имя аккаунта, ник, роль, выбранный аватар. Не показывать email, контакты, оценки или имя из учительского журнала.

После удаления восстановить дружбу обратной заявкой и приёмом. Физический телефон и все комбинации тем/zoom не считать проверенными без доказательств.

## Предрелизные результаты
- PGlite: 16 assertions PASS (настоящий PostgreSQL, минимальная schema fixture): whitelist, student vs forged metadata admin, self-account guard, скрытый профиль, IDOR удаления, повторное удаление, обратный участник, текущий путь фото и подменённый owner, anonymous guard. Старый RPC заменён stub только в fixture; его production-поведение проверяется отдельно.
- Production SQL read-only, authenticated role: snapshot преподавателя вернул Митя/@mita12222/student/flower; email и данные журнала отсутствуют.
- Fixture реальных компонентов `/qa/people-connected/`: открытие A/B, копирование с feedback, отмена, удаление только A (B остался), повтор загрузки после ошибки PASS. Escape возвращает фокус при сохранённой строке. Отмена исправлена для возврата фокуса к удалению.
- Визуально: light 320×568 — начало/середина/конец прокрутки с фейдами; dark 390×844 — длинное имя и все действия помещаются; dark 1024×600 — низкое окно. 1440 и полный E2E ещё предстоят.
- tsc/check:i18n/check:ui PASS. Реальные две сессии и физические устройства этим не подтверждаются.
- Supabase advisor: изменённые private функции не отмечены как анонимно доступные; public desktop_people invoker. Существующие общепроектные предупреждения вне этого изменения. can_read_avatar остаётся ограниченным authenticated predicate.
- Полная покадровая запись, замедление CPU, загрузка реального фото, физические устройства, полный набор палитр/zoom — NOT TESTED. DOM evaluator не предоставляет requestAnimationFrame; отдельная запись движения требуется.
