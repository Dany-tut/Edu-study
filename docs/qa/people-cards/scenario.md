# Карточки людей — визуальный стенд
План до QA. Ветка codex/people-cards-stand, база origin/main на момент создания. Данные вымышленные, совпадения ников с аккаунтами — только визуальные примеры; сервер не используется.
Область: список (имя, Loop-аватар, роль), поиск с @/без, открытие профиля, копирование, подтверждение/отмена удаления, локальное удаление, повторная заявка, входящая заявка, пустой список, светлая/тёмная темы, reset.
Инварианты: удаляется только выбранный id; отмена оставляет список; учебная связь не изменяется; роль остаётся одинаковой в списке/поиске/профиле. Не использовать технические роли/фальшивую верификацию.
Матрица: 1440×900 light/dark; 390×844 light; 320×568 dark; низкий desktop 1024×600. Клавиатура/Escape/возврат фокуса, длинное имя Алёны, фейды вертикального и горизонтального overflow начало/середина/конец. До клика наблюдать исходное состояние, после — содержимое и принадлежность выбранному человеку.
Пока не проверено: реальные Auth/RPC/БД/аватары, реальные уведомления, физический телефон, CPU slowdown. Стенд — предварительный дизайн, не production implementation.

Результат fixture: PASS в проверенных пределах. База a7f97b84290f874d4d274f4e757a3e9a61e71a7f. Проверены роли и ID Даниила/Анны/Михаила/Софьи/Алёны; отмена удаления оставляет Даниила, подтверждение удаляет только его (3→2), связь «Ваш преподаватель» остаётся. Поиск @alena_chemistry находит учителя с длинным именем; отправка меняет статус; принятие Софьи добавляет только её (2→3). Светлый desktop 1440×900/1000, тёмный 1024×600, светлый 390×844, тёмный 320×568. Фейды вертикальной прокрутки видны; вкладки на проверенных ширинах помещаются. Пять открытий/Escape возвращают фокус на исходную карточку. check:ui PASS, esbuild stand PASS. На стенде нет серверных операций; UI ошибки сети/реальное удаление не проверялись. Не проверены полностью: пустой список, копирование буфера, поиск без @, физические устройства, замедление CPU и покадровые замеры. Движение без новых анимаций, используется общий Modal.
