- Версии Искры (ПК / iPhone / iPad / Android): затронут общий web-кэш; production Edge-проверка ПК обязательна. Мобильные оболочки не изменяются и не проверяются в этой задаче.
- Данные A/B с одинаковым количеством и разными ID; 0/1/много/overflow; статусы: реальные данные проверены read-only: 57 учеников, 24 группы, 33 курса, 127 домашних работ; production RPC показывает обычный разброс и зарегистрированные server timeouts.
- Требование / независимый ожидаемый результат / инварианты: совпадающие owner+shape дедуплицируются. Если компактный и полный снимки запрошены почти одновременно, они не выполняются параллельно: полный стартует после завершения компактного.
