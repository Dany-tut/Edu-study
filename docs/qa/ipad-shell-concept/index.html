Концепт оболочки iPad — кабинет учителя

Разделы приложения уезжают из десктопного топбара в одну стеклянную капсулу у правого края (docs/platforms.md §1.1): общее (разделы + профиль) → экран (0–3 действия раздела) → главный круг под капсулой («+»/«Сдать»). Поповеры открываются влево. Обе ориентации × обе темы.

Интерактивный стенд с переключателями: dev-ipad-shell.html (в корне репо). Иконки здесь — заглушки; в коде будут Loop.
