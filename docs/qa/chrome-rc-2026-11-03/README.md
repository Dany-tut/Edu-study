## Доказанный промежуточный результат R2

Физический прогон завершён до обновления кандидата R3. `chrome-r2-final.xcresult`: форма PASS 27.047с, чтение motion PASS 1.452с, уборка PASS 1.386с. Все собственные тестовые вкладки закрыты; сервер остановлен, отдельная TCP проверка — ConnectionRefusedError. Источники продукта и данные во время прогона не менялись. API запрещён CSP; авторизация/production не затрагивались.

Видеозапись `chrome-form-motion.mp4` начинается до первого tap. Просмотрена контактная последовательность 2 кадра/с и контрольные PNG: нет пустого экрана и перекрытия поля/глаза системной панелью; скрытие иллюстрации при focus и возврат при blur видны. Это ограниченная визуальная проверка движения, без утверждения о каждом видеокадре или измерения performance. `raf-motion.json` содержит 865 геометрических кадров за 25.226с; 414 кадров вокруг шести переключений: глаз DOMy260.78125 неизменен, пароль остаётся в фокусе. При focus форма намеренно меняет композицию, потому общую неизменность layout не заявляем.

У полей и действий читаемые подписи, конец формы и нижняя подсказка целиком достижимы. Верхний scroll edge мягко маскирует уходящий контент, снизу в конце нет скрытого контента. Точный числовой контраст, другие темы и форматы не измерялись. Нет проверки backend loading/error/success, OTP/social/reset переходов, быстрого double-tap и жеста при открытой клавиатуре. Поэлементную полную приёмку этим не заменяем.

До успешного результата первая попытка R2 FAIL на selector harness: у AX поля Пароль placeholder без label, поэтому predicate по label его не находил. Сам ввод Email PASS, cleanup PASS; отказ сохранён в `/tmp/iskra-chrome-rc.twnxA6/chrome-r2.xcresult`. Selector исправлен на `app.textFields["Пароль"]`; код продукта не менялся.
