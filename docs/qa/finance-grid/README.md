# FIN-GRID — раскладка списка финансов

База 1d80bf3081f9ba4b518e5a91a6988c07568145ad + рабочие изменения (см. manifest.sha256). Исполнитель и проверяющий: Codex. Локальный Chrome, компонент преподавателя с тестовыми данными. Риск: у строк без суммы смещаются действия, на телефоне пропадают данные.

| Элемент | Действие | Ожидаемый результат |
|---|---|---|
| Страница | 320/390/768/1440, светлая/тёмная | Ширина до 1180, поля 16/32, нет горизонтальной прокрутки |
| Сводка | Изменить ширину | Четыре показателя, на телефоне два ряда |
| Фильтры | Все → Просрочено → На подходе → Оплачено → Все | Строки только своего статуса |
| Строки | Раскрыть A, B, закрыть | История только выбранного ученика |
| Платёж | Из шапки и из строки, отменить | Пустой выбор / верный ученик и сумма |
| Список | Начало → середина → конец | Фейд только со стороны скрытых строк |

Проверяем верстку и взаимодействие с локальными данными. Запись, удаление, отказы и поздние ответы настоящего сервера, физические устройства — вне этого прогона.

Проверено в Chrome на macOS: 1440×900, 768×620, 390×844 и 320×568, каждая ширина в обеих темах. Во всех восьми комбинациях переключены четыре фильтра со сверкой состава учеников, раскрыта история двух разных учеников с проверкой ID, открыты и отменены формы из шапки и из строки с проверкой суммы. Ширина скроллера совпала с шириной содержимого. Состояния прокрутки: [замеры](results.json), примеры начала, середины и конца на [десктопе](1440-light-0.webp) и [телефоне](390-light-0.webp); соседние файлы с суффиксами 0.5 и 1 — середина и конец.

Итог: PASS для проверенных взаимодействий локального компонента. Полная приёмка PARTIAL: без серверного сохранения, физического устройства, записи движения, проверки всех клавиатурных состояний, увеличения текста и reduced motion. Общий сторож npm run check:ui прошёл.
