# Главы по слайдам — карточка приёмки

- Область: отдельный режим OCR, выбор области заголовка, независимый черновик глав, применение к новой/готовой записи.
- База: 88665238803f1eb9eebf67cc5cf839ae32addd9a + изменения ветки codex/transcription-slide-chapters.
- Ответственный: Codex, этот чат. Риск: потеря старой расшифровки/монтажа, ошибочные заголовки, зависание при отмене OCR.
- Среды: локальный Python, настоящий OCR по предоставленному кадру; Chromium fixture с подменой loopback API. Учительский Mac и серверное сохранение отдельно не подтверждаются fixture.
- Ожидания: два режима; только первое появление каждой темы; не брать нумерованный текст/подвал ЕГЭ; слайды не запускают распознавание речи; до явного применения исходные главы/текст/монтаж не меняются.

Физические устройства и реальная учительская запись не доступны в этой сессии.

## Результаты локальной проверки

- Python: 41 тест, PASS, включая глобальное A/B/A, нормализацию, отличие ДНК/РНК, уточнение первого времени, пустой результат и отсутствие speech-пайплайна для слайдов.
- Реальный OCR: предоставленный пользователем кадр → «ТРИПАНОСОМА». Видео 18 с с тремя слайдами → [{start:0,title:ТРИПАНОСОМА},{start:6,title:ЛЯМБЛИЯ}], без повторной третьей главы. Полная холодная установка отдельного OCR runtime успешна. Разрешение зависимостей под Python 3.12 / macOS arm64 успешно; выполнение проверено под Python 3.14 на локальном Mac.
- Реальный job supervisor: отмена во время OCR, группа 11814 с дочерними 11815/11891 завершена за 0,319 с, gate освобождён; следующее задание успешно. Чужие и учительские процессы не затронуты.
- Fixture UI: режимы текст/слайды, POST mode=slides, измеренные 40%, правка имени/времени, удаление, reload черновика, ошибка сохранения и успешный повтор; 8 комбинаций ширины/темы. Callback полной расшифровки при применении глав намеренно бросает исключение; не вызывался. Число глав после удаления 19, успешное сохранение ровно одно.
- Скриншоты/логи: `.build/qa/` в рабочей копии; снимки начала/середины/конца предпросмотра. Данные fixture вымышлены. Новые файлы находятся в отдельной ветке; не обновляли работающий модуль пользователя.
- Ограничение: физические iPhone/iPad/Android, полный UI с настоящим сервером и исходное видео преподавателя не проверены. Это PARTIAL приёмка по полному протоколу, PASS только для перечисленных локальных сценариев. Дедупликация OCR не гарантирует отсутствие всех ошибок в произвольном видео; есть явный предпросмотр и редактирование. Короткие слайды могут пропускаться при шаге 2 с.

Дополнительная приёмка: все шесть областей выбраны через UI; закрытие и возврат к активному заданию не создают второй POST; отмена → новое задание; «Распознать заново» очищает только черновик, callback сохранения не вызван. Найдено и исправлено наследование фиксированной ширины иконок у кнопок предпросмотра: теперь отдельная flex-wrap раскладка, названия не перекрываются. Повторная матрица 8 размеров/тем проходит. Типы и check:ui проходят.
