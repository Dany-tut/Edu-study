# WIDGET-NAV — карточка приёмки

Область: стрелки перехода и клик по поверхности виджетов преподавателя.
Автор исправления/проверки: Codex. База c74e0f2687de8111f89f93d4ca0dc8fdd3e63c81 + изменения widgetNavigation, пяти TSX и widgets.css (хеши будут в manifest).
Риск: ложная стрелка; пропущенный переход; двойной вызов; вложенная кнопка оплаты одновременно открывает раздел.
Окружение: macOS, IAB Chromium, локальный Vite fixture; настоящие компоненты, контролируемые hook-данные, никаких серверных записей.

Независимые ожидания:
- stat-students/student-count/student-groups/student-active/student-debtors → groups;
- stat-hw → gradebook (существующий alias homework);
- finance-received/expected/debt/forecast → finances;
- stat-lessons с ближайшим lesson-A → lesson-editor, editingScheduleId=lesson-A; без занятия нет перехода/стрелки;
- stat-earnings «будет позже» без перехода/стрелки;
- groups-list → groups по фону/заголовку/стрелке/строке;
- finance-overdue → finances по фону; Оплачено → только fixture payment student-A;
- reminders → первая доступная запись активной категории, строка B → B, вкладка → только переключение; пустое состояние без стрелок;
- attention compact — существующая вся кнопка → groups; большие строки → конкретный ученик;
- задачи/история/расписание: без новой общей ссылки, внутренние действия сохраняются.

Матрица до запуска: desktop 1440×900 light; phone390×844 dark; keyboard Enter/Space; повтор; изменение вкладки; overflow начало/середина/конец. Наблюдение начинается до клика. Сверять ID и число вызовов, не только подпись.

Временные риски: двойной клик не дублирует один вызов на событие; смена категории меняет root destination; поздних сетевых ответов новая логика не вводит. Серверные ошибки/сохранение финансов — вне fixture, не считать E2E пройденным.

Результаты и непокрытые комбинации заполняются после прогона.
