# Переключение модулей: исправление рывков

Проверялась локальная рабочая копия 2026-11-03, компоненты CourseModuleBar и
CourseNode на изолированном стенде. Это не отчёт о полном обходе приложения.
Хеши исходников — в source-hashes.txt; HEAD — в head.txt.

Исходная запись пользователя: «Запись экрана — 2026-11-03 в 11.22.22 AM.mov».
Вкладки перекрывались в переходе, узлы трека появлялись с задержкой по индексу.
Исправление: ширина вкладок меняется в обычном flex-потоке без второго layout
transform; слот номера и высота анимируются вместе с подписью, без подъёма по
hover. Узлы и спутники не проходят невидимое начальное состояние при mount.

Результаты браузерных измерений:
- Последовательность 3→4→3→2→1: 32 промежуточных измерения для последних четырёх
  переходов, перекрытий 0, минимальная opacity узлов 1.
- Матрица 320/390/1440 px × светлая/тёмная тема × 4 перехода: 24 случая,
  по 4 промежуточных измерения, перекрытий 0, opacity узлов 1.
- 20 быстрых переключений клавишей Enter с прерыванием анимаций: 20 измерений,
  перекрытий 0, opacity узлов 1. Использована клавиатура, чтобы браузерная
  автоматизация не ожидала стабилизации движущейся кнопки перед нажатием.
- Геометрия измерялась через DOM браузера; это выборки промежуточных состояний,
  а не запись каждого экранного кадра. Итоговые темы просмотрены визуально.

Данные: geometry.json, rapid.json, light.png, dark.png. `check:ui` пройден.
Стенд воспроизводится копированием fixture.tsx в src/qaModuleMotionTemp.tsx и
fixture.html в .qa-module-motion.html, затем открытием страницы на локальном
Vite. После проверки удалить оба временных файла.

физические устройства, reduced motion, измерение контраста всей палитры,

протокол поэлементной приёмки — ../interaction-acceptance.md.
