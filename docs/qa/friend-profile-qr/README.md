# Ссылка на профиль для друзей

Локальный Chrome и Supabase Auth/PostgREST, два тестовых преподавателя. База 8b5431530bd94367130f8775826bece73caad47f, изменения в коммите данного отчёта. Владелец — 1440 × 900, получатель — 390 × 844; дополнительная проверка ширины — 320 × 480.

- Выключено изначально; отдельное разрешение «Можно найти меня по точному нику» оставалось выключенным.
- Включение, копирование в системный буфер, независимое декодирование QR со снимка: строки совпали.
- Получатель вошёл через форму по адресу из QR. Открылись ник и форма заявки.
- Владелец закрыл доступ до отправки: сервер отклонил заявку, экран получателя убрал ник.
- При повторном включении адрес изменился; перезагрузка старого адреса подтвердила отказ.
- По новому адресу отправлена заявка, владелец принял её в списке. Перезагрузка и запрос состояния подтвердили дружбу.
- Аккаунты удалены после прогона. Физическая камера, вход через сторонние OAuth-провайдеры и полная визуальная матрица тем не проверялись.
