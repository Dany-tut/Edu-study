## Результат · PARTIAL
На локальном стенде в Microsoft Edge (Playwright, macOS) пройдены 320×650, 390×844, 768×1024, 1024×575 и 1466×860 в двух темах. Для каждого варианта сравнивались положение и размеры трёх кнопок и координата подписи на кадрах от момента перед нажатием до завершения переключения. Сводные координаты в geometry.json, SHA-256 двух исходников в sources.sha256.

- Все три раздела открылись, геометрия кнопок сохранилась. В «Работах» проверены оба представления и раскрытие/сворачивание списка учеников домашней работы.
- При узкой панели фильтры раскрылись в пределах окна, Escape закрыл панель. На широком экране отобразились встроенные поля. Поиск отсутствующего ученика дал пустой результат, очистка вернула строки.
- На 390 и 1466 px визуально просмотрены снимки таблиц после установки 0, 50 и 100% доступной горизонтальной прокрутки. Если таблица помещалась (в частности, «Обзор» на десктопе), позиции совпадали. Файлы 1 и 2 — работы и посещаемость соответственно.
- Отдельный вариант fixture передавал журналу 22 незаполненных занятия и длинный заголовок с корейской грамматикой. На 320, 390 и 1466 px счётчик сохранял положение, список раскрывал все 22 записи, заголовок отображался целиком без маски. Снимки long-*.
- Команды npm run check:ui и npm run check:gradebook прошли. Повторяемая проверка панели — qa/journal-layout/check.mjs.

Не покрыты реальная учётная запись и запись на сервер, физическое устройство, поздние ответы, ошибки/повтор запросов, изменение масштаба, полный аудит контраста и клавиатурных маршрутов, reduced motion. Сценарии редактирования оценок, профиля и проверки работ выходят за проверенную область.
