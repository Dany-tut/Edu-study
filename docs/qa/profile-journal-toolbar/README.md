# Профиль и шапка журнала
База 8b5431530bd94367130f8775826bece73caad47f. Локальная проверка Codex, Edge, демонстрационные данные.
- Профиль → Друзья → Заявки → Поиск → Мой ник. Обе группы вкладок на одной горизонтали, выбранная кнопка соответствует открытому разделу. Узкий экран — одна горизонтальная прокрутка, начало/середина/конец.
- Журнал → Обзор → Работы → Посещаемость. Двузначный счётчик отделён от подписи и от края кнопки, ряд стабилен. Селекты как в группах, отдельно проверить узкое окно, поиск и клавиатуру.
- Границы проверки: локальный UI. Сохранение данных, ошибки сервера, задержанные ответы и физический телефон отдельно.

Проверка локальных React-компонентов в Edge прошла на учебных данных. В профиле при ширинах 320, 390, 768 и 1466 px координаты Y двух навигаций совпали; каждая из четырёх кнопок открыла одноимённую секцию, «Главное» закрыло дополнительную навигацию. Снимки profile-* показывают начало, середину и конец прокрутки. Снимки groups-header и journal-header сняты с реальных компонентов страниц на локальном стенде с подменёнными данными. При ширине 1466 px поля выбора имеют высоту 40 px, поиск 180 × 40 px, внутренние отступы панели 14 / 20 / 12 px в обеих шапках. На 320, 390 и 1466 px счётчик 22 сохранил положение при переключениях, Enter раскрыл список из 22 занятий и повернул шеврон на 90°, повторное нажатие мышью закрыло его. Снимки long-* и disclosure-open фиксируют оба состояния.

Проверены TypeScript и npm run check:ui. Непокрыты физические устройства, реальная сессия, тёмная тема, масштабирование, reduced motion, покадровое измерение переходов и полный аудит контраста на этой сборке.
