# Проверка текстовых фейдов Искры · 2 ноября 2026

Проверка исходников охватывает весь `src`: CSS text-overflow/line-clamp, inline-стили, utility-классы и ручное добавление многоточия после slice(). Проверка включена в `npm run check:ui` и CI. Многоточия в учебной нотации, незавершённых фразах и сообщениях загрузки сохраняются.

Вместо браузерной обрезки используются `FadeText`, `textFadeStyle`, `textFadeLines`. Текст остаётся полным в DOM. Общий наблюдатель измеряет фактическое переполнение, учитывает RTL, изменения текста, ширины, шрифтов и загрузку стилей. Короткий текст без маски. Нативные поля выбора сохраняют клавиатуру, доступное имя и системный список; маскируется только отдельная видимая подпись.

## Визуальные проверки

Адаптивный браузер: 320×740, 390×844, 1280×720, 1440×900.

- Заполненная главная ученика: центральные и соседние дни, длинные названия, время и действия. На десктопе высота документа равна окну; расписание, полоса виджетов и трек видны.
- Дневник: выбор длинного курса, состояния и сортировка, лента с большим числом домашних работ. Начало, середина и конец прокрутки на телефоне и десктопе.
- Финальный тест с восемью заданиями: длинное название, условия, варианты, поля ответа; начало, середина и конец на телефоне и десктопе. Тест не отправлялся.
- Преподавательский журнал на учебных данных: обзор, вкладка работ, имена, заголовки столбцов, длинное название группы. Горизонтальная прокрутка таблицы в начале, середине и конце, вертикальный список учеников.
- Изолированные состояния общего механизма: одна, две и три строки; RTL; короткий текст; смена текста и ширины; ленивый CSS; портал; кнопка с отдельными значками. У кнопок маски нет, у переполненной подписи есть; при коротком тексте маска снимается.

Проверка всех исходников не означает ручной обход каждого скрытого состояния редакторов и всех сочетаний данных. Внешний модуль Тестли и текстовые многоточия в уже сохранённых учебных материалах не преобразуются автоматически. Реальное устройство iOS/Android не использовалось.

## Автоматические проверки

`npm run check:ui`: запрет старых способов обрезки во всех исходниках, отрицательные/положительные примеры для сторожа, расчёт масок (помещающийся/переполненный текст, RTL, несколько строк), существующие проверки прокрутки, размеров виджетов и Loop.

Дополнительно: TypeScript и полный GitHub Actions `Типы, сторожа, сборка` для выпускаемого SHA; `npm run release:check` до отправки ветки. Production проверяется по полному SHA обоих манифестов после Git-релиза через актуальный main.
