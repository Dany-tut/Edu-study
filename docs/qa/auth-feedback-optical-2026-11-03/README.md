Карточка до QA: обе роли, ошибка/загрузка/успех. Исполнитель Codex. База 1d80bf3081f9ba4b518e5a91a6988c07568145ad + локальные изменения, точный состав source.sha256. Не production.

Причина: margin-bottom заголовка смещал одноcтрочный статус относительно Отмены; разные line-height усиливали ощущение. План: одинаковые 16px строки для статуса и отмены, убрать margin заголовка, уменьшить значок до 18px. Фиксированный слот 56px и зона отмены 44px сохраняются.

Ожидание: визуальный центр значка, текста и Отмены совпадает; у ошибки две строки занимают 32px; loading/error/cancel/recovery success не меняют координаты формы. Длинные сообщения прокручиваются с фейдами. Данные двух ролей synthetic, реальная почта/OAuth/телефон не используются. До проверки NOT TESTED. Повторный полный UI прогон 20 сочетаний из ../auth-feedback-compact-2026-11-03/README.md, edge и screenshots на390/1440. Реальные backend/физические устройства/Safari/полная AT матрица вне покрытия; требуют отдельного разрешённого прогона.

Диагностика отрицательного контроля: после уплотнения idle и error имели одинаковую естественную высоту в teacher форме, поэтому удаление fixed-height случайно не сдвигало primary. Контроль усилен короткой однострочной fixture-подсказкой перед вызовом ошибки. Production DOM/исходники этим не меняются. Исходное падение edge-first-diagnostic.log сохранено.
