# Искра · закрытое тестовое занятие

Кандидат 1.0.1855, локальный Supabase, отдельные учётные записи. В рабочем журнале стенда не хватало пяти миграций из кандидата. После применения версий 20261101164928, 20261102013000, 20261102045052, 20261102051629 и 20261102082617 страница открылась. Повторная матрица доступа дала 102 PASS.

В Chrome преподаватель создал группу, ученика и два задания через интерфейс. Для одного задания был задан эталон ответа, для второго требовалась ручная проверка. Ученик зарегистрировался по приглашению. Для повтора на локальной сборке тестовый драйвер переустановил пароль этой синтетической учётной записи. Ученик сохранил черновик свободного ответа, перезагрузил страницу и сдал работу с повтором после обрыва. Преподаватель открыл её из напоминания и опубликовал 90% с комментарием. Новый сеанс ученика и перезагрузка показали оценку, исходные ответы и одну попытку. В мобильном Chrome с эмуляцией Pixel 7 проверены вход, согласие и история с оценкой. Проверки возврата на доработку выполнены отдельно в PostgreSQL.

Локальный почтовый ящик получил письмо восстановления. После перехода пароль успешно заменён, повторный переход отклонён, старый пароль отклонён и новый принят. Доставляемость во внешние почтовые сервисы требует отдельного стенда с SMTP.

В нагрузочном прогоне до начала волны уже созданы сессии разных учеников. Каждая сессия загрузила уникальный валидный JPEG размером 1 399 318 байт и записала сдачу. Затем преподаватель прочитал работы, скачал вложения, сверил каждую ссылку с владельцем и каждый SHA-256 с оригиналом. Время проверки преподавателем не входит в p95. После обновления схемы при 30 учениках p95 загрузки составил 2757 мс, записи сдачи 402 мс, всего 3007 мс. При 60 учениках соответственно 2362, 74 и 2369 мс. Каждая ступень запускалась один раз. Холодный и прогретый прогоны не разделялись. Проверка резервной копии в отдельном приватном бакете охватила 93 объекта суммарно 125 938 824 байта.

Тестовый стенд использует восстановленную локальную схему. Windows, внешний SMTP, фактическая инфраструктура беты и происхождение исторических ролей остаются открытыми. В браузерном прогоне локальные Edge Functions testly-bridge и hw-grade-run отвечали 404. Выставление оценки преподавателем прошло, интеграция с Тестли и автоматическая проверка ИИ этим прогоном не подтверждены.

Для повтора нужны запущенный локальный стенд на 55321 и Mailpit на 55324, а также fixture.json от checkLocalSupabase.mjs. Скрипт checkLocalDeadline.mjs читает синтетический JPEG из /tmp/iskra-local-security/class-photo.jpg. В этом прогоне использовано изображение Pillow размером 1600 × 1200 с шумом и JPEG quality 91. Оба скрипта запускаются через node из репозитория. Каждый нагрузочный запуск заводит 60 новых локальных аккаунтов.
