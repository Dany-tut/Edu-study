Открытый набор отложен. Windows в UTM запустила среду восстановления. Для допуска нужны сквозной прогон на рабочей Windows, проверка происхождения существующих ролей и состояния паролей в целевой среде и нагрузочная приёмка конфигурации будущего сервиса. Локальный тест параллельного чтения не определяет вместимость сервиса при одновременной сдаче заданий и загрузке файлов.
