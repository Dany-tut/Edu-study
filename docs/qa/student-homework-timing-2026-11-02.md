# ДЗ по расписанию и единый виджет дел

Исходная production-версия при расследовании: b161f0ea93c1237ed0bc1d2cf53d099ef1cd12b7.
Релизная база: 97d37ea0 (актуальный main, включая явные сроки ДЗ).
Рабочая копия выпуска: codex/homework-timing-release, от актуального origin/main.

Причины:
- Бейдж CircleAlert в CourseNode получает overdueLabel из CourseTrack: diaryOverdue по выданному ДЗ и его сроку, а не по просмотру или посещению урока.
- homeworkNeedsVideo проверял только зачёт урока/видео и сохранённую работу; временного ограничения не было.
- StudentHome добавлял виджет «Нужно сдать» с id 12, а WidgetCarousel продолжал выводить прежний «Твои дела» с id 11.

Изменения:
- Отдельная проверка времени до проверок видео и черновиков: для живого занятия начало + 90 минут. Для записи — назначенное время, без выдуманной длительности. Тесты сохраняют собственную политику доступа.
- До открытия ДЗ не попадает в дневник, дела, следующий шаг и просрочки. Страница задания также проверяет время.
- По запросу пользователя бейдж просрочки удалён с кружков уроков и из их aria-label; информация о сроке сохранена в карточках и списке работ.
- Сводка называется «Твои дела» и использует id 11; ведущие виджеты исключаются из последующей карусели по id. «Следующий шаг» сохранён.

Проверено автоматически: check:video-access (до начала, начало, 89:59, ровно 90 минут, черновик и посещение, исключение из дневника), check:student-home, check:ui, git diff --check.

Визуально: локальный StudentHome с синтетическими данными и подменённым ответом метаданных, без production-записей. Десктоп 1280×720 и телефон 390×844: сводка, список поверх главной, начало/середина/конец длинного списка с фейдами, главная без вертикальной прокрутки. Экран конкретного урока №6 реального ученика не проверен в авторизованной сессии.

Полная проверка `tsc --noEmit --extendedDiagnostics` успешно завершена без ошибок: 1421 файл, 131,05 секунды. При переносе сохранены актуальные тесты 70% просмотра и видеоплеера из main. Повторно пройдены check:video-access, check:student-home, check:diary-views, check:course-track.

После удаления бейджей повторно проверены локальные StudentHome и список из 30 работ: десктоп 1280×720, телефон 390×844, начало/середина/конец прокрутки с фейдами. Кружки не содержат индикаторов просрочки, карточки сохраняют сроки.
