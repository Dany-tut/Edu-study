# Еженедельный отчёт исправлений

Согласование Дани: еженедельная проверка, общие замены только с его одобрения; интерфейс только ПК. Концепт4платформ×2темы показан, выбран ПК.
Область: админка/Словарь, список личных исправлений, раскрыть было/стало, подтвердить/не применять повторно, ошибки/повтор. Подтверждение личной правки не публикует полный заголовок общим правилом. Общие термины добавляются/одобряются существующим словарём.
План QA: реальный компонент fixture Chromium на ПК1280/1440 в двух темах; раскрытие, решения, отказ сервера, повтор, пустой список, длинные тексты. Непоказ отчёта на iPhone/iPad/Android проверяется по PLATFORM guard. SQL транзакционно: три разных учителя не переводят термин в approved; cron ровно один, недельный; review не добавляет общие термины. Нет изменения текущих задач расшифровки. Полный авторизованный E2E и физические устройства не заявляются.

Результаты: реальный компонент в Chromium fixture PASS1280/1440×светлая/тёмная; confirm/reject, отказ UPDATE/SELECT, refresh/retry, пустой список. Во время загрузки решения заблокированы. SQL BEGIN/ROLLBACK: три разных преподавателя предложили одну пару — pending; повторная проверка не опубликовала её; после rollback тестовых строк0. Cron ровно один, active=true, `0 2 * * 1`. Применённая миграция20261114182722. Прежние RPC/RLS/MFA проверки журнала остаются в предыдущем отчёте PR203. Автопроверка — признаки конфликтов, регистра и чисел, не языковая модель и не гарантия правильности.
