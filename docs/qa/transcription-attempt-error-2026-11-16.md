# Ошибка повторной обработки

База d244c68995ac39ae239335c872c8ad76b0221b9d, ветка codex/transcription-attempt-error.
Сценарий: фактические CenterRecording/TranscriptionAction, Chrome на Mac, локальный fixture, подменены только API модуля и БД, запуск native отключён. Production-данные не изменяются.

Инварианты: сохранённый результат не является результатом неудавшейся новой попытки; ошибка не перекрывает его; закрытие ошибки сохраняется после F5; A не пишет состояние в B; новый результат — черновик до сохранения.

Матрица до приёмки: обе темы ПК 1440×1000; saved/empty; отказ API задания; закрытие/F5; другой урок; retry с файлом; успешный новый ответ; задержанный ответ A после перехода B. Ожидается прежний текст A/B и 0 записей в сервер до явного сохранения. Источник файла остаётся ссылкой текущего урока, пользователь должен выбрать то же видео.

Реальный источник преподавателя и его job id не предоставлены. Точное сообщение происходит из link_video._fetch: HTTP не 200, ошибка curl либо HTML вместо файла; это не доказательство ложной ошибки. URL просмотра и URL скачивания имеют разные условия доступа.

Риски: API старых модулей не возвращает source/lesson; привязку обеспечивает key owner+course/lesson, source и подпись файла, авторизация GET job модулем. Переходы размонтируют keyed состояние и игнорируют поздние ответы.

Fixture PASS: saved/empty, обе темы ПК, закрытие/F5, переход A/B, поздний ответ, повтор с исходным файлом, успешный результат без записи на сервер. Отрицательный контроль возвращает перекрывающую панель и тест падает. check:ui PASS. Physical Mac преподавателя / его реальная запись: не проверены; не запускаем дубликат. Остальные платформы: только техническая регрессия, визуальная приёмка ограничена ПК.

Реальная ссылка Drive получена позднее от оператора: штатный downloader текущего worker успешно скачал 128679617 байт за 4.125 с. Исторический сбой конкретного job этим не опровергается; источник сейчас доступен из этого окружения. Скриншоты saved/empty light/dark визуально проверены; отступы заголовок/описание/кнопки 16px, padding20px у recovery.
