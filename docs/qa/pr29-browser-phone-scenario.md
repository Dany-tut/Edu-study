Матрица браузера: Chromium/WebKit; 320/390, планшет 768, desktop1280, low1280×600, portrait/landscape; light/dark, reduced motion/zoom. Физическое устройство: подключённый iPhone17Pro, отдельный QA bundle; не перезаписывать пользовательскую Искру/сессию. Перед запуском зафиксировать подпись/хеши и источники данных. Первые падения и повторные прогоны сохраняются. Итог PASS только для доказанного объёма. Выпуск требует отдельного согласия владельца; этот прогон не выдаёт разрешения на публикацию.
