# Колонка «Тест» в списке учеников

Карточка до запуска проверки. База: beb5f961; точный patch — git diff ветки codex/journal-course-tests.
Риск: колонка присутствует без тестов; устаревший процент ошибочно выглядит относящимся к курсу.
Ответственный: Codex. Данные: синтетические, без записей в БД.
Ожидание: состав текущего курса определяет видимость колонки; результат 0 и отсутствие попыток не скрывают существующий тест. Поиск не меняет набор колонок. Строки без теста не показывают старый процент.

| Сценарий | Ожидание | Факт |
|---|---|---|
| Курс без теста, старые результаты есть | Нет колонки | PASS: checkCourseTestColumn |
| Есть тест, попыток нет | Колонка есть | PASS: checkCourseTestColumn |
| Тестли внутри ДЗ курса | Колонка есть | PASS: checkCourseTestColumn |
| Тест вне курсов | Не создаёт колонку курса | PASS: checkCourseTestColumn |
| Переключение A → B → A, поиск, сортировка, пустой поиск | Заголовки/ячейки/colgroup совпадают, поиск не переключает колонку | PASS fixture UI; поиск — только при видимом поле |

План fixture UI: реальные TeacherGroupsPage и loadFixture; ПК 1440/1280, iPhone 320/390, iPad 820/1180, Android 412; обе темы. Физические устройства и настоящий сервер не проверяются этим стендом.

Результат: PARTIAL. `tsc --noEmit`, `check:ui`, новая регрессия и fixture browser PASS. Проверены 1440/1280/320/390/820/1180/412 px, светлая/тёмная темы; сверены 7/8 th, td, col; A→B→A, сортировка, пустой поиск при доступном поле, начало/середина/конец горизонтальной прокрутки. pageerror: 0. Данные — loadFixture (2 группы × 8), реальный TeacherGroupsPage; связь с сервером и нативные оболочки не проверены. Изображения: /tmp/iskra-journal-{1440,390}-{light,dark}.png. Исходники во время успешного прогона не менялись. Поиск скрыт существующей адаптивной вёрсткой в части комбинаций; эти клики не проверены. Движение покадрово, физические устройства, zoom и reduced motion не проверены.

Общая `check:course-journal` останавливается до изменённой области на прежнем утверждении «Attendance cannot invent a video credit for a recording-only lesson». Новая регрессия запускается отдельно и импортирована в эту общую проверку. `npm run build` заблокирован отсутствующим установленным @sentry/vite-plugin, конфиг сборки не менялся. Проверки не подтверждают production.
