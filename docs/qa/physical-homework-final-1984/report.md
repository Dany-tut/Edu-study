# R10: физический путь ДЗ

Проверена сборка `84dea0784d0f162529077753da45908ab0121be6`, web `1.0.1984`, отдельный bundle `com.dany.iskra.qa.physical.final1984`. Устройство: iPhone 17 Pro, iOS 27.2 (24B119), портрет, светлая тема. Карточка заполнена до запуска. Изменены только параметры локального backend, его anon key и отдельный bundle ID. Исходники продукта не инструментировались. Хеши подписанного бинарного файла и web-файлов до и после совпали.

Бизнес-цикл сохранения и принадлежности пройден. Визуальная приёмка R10 не пройдена: найдены отсутствие нижнего фейда на странице ДЗ и скачок при закрытии клавиатуры. Результат не переносится на следующий SHA.

| Элемент и переход | Подтверждённый результат | Доказательство |
|---|---|---|
| Роль и настоящий вход ученика | Обычные Email, password, глаз; точное сравнение ввода; Auth 200 с actor A, кабинет | Приватные XCUI и transport logs |
| Дневник → самостоятельное A | Реальная строка, заголовок и маркер A, два поля | AX и reviewed loaded PNG |

После входа B независимый reader подтвердил один progress A и ровно две попытки: первая returned с первоначальным ответом и qareturna, вторая completed с исправленным ответом, 90 и qaaccepta. У B progress 0. UI показывает номера и тексты попыток; UUID сверены отдельным reader, они не выдаются за UI-идентификаторы.

API preflight для обеих сторон подтвердил RLS: свой homework/profile читается, чужой homework/progress не читается. Канонический RPC is_staff возвращает false ученику и true преподавателю. Это отдельная API-проверка, она не подменяет вход на устройстве.

Все шесть обычных выходов завершили POST 204 с ожидаемыми actor IDs: student A → teacher A → student A → teacher A → student A → student B. Обход через профиль преподавателя после неудачного student logout не применялся. Подтверждённый logout-дефект R7 на этом пути не воспроизвёлся.

Continuous XCTest 2 завершён с exit 0 и requiredFailures 0 за 1231.555 с. Это длительность подробного драйвера, AX-проверок и ввода, а не задержка интерфейса. Первый отдельный runner остановил несовпавший Email до Auth POST (его xcresult имеет exit 65). Временный драйвер получил ожидание клавиатуры, обычный Select All и один повтор с точным сравнением. В рабочем continuous runner Mac-скрипт продолжался после таймаутов consent/AX; эти исключения сохранены. Это не единый чистый запуск всех шести скриптов. Все авторизации настоящие, через UI; DOM/API/session bypass и API-заполнение прогресса отсутствовали.

Fresh TLS health smoke пройден. Транспорт использует взаимную проверку цепочек и точные pins, только CoreDevice peer и loopback API. Системные CA, профили и доверие не менялись; backend не публиковался в интернет. Negative client control ранее проверен на том же транспорте. Постоянный WebSocket realtime не поддержан; выводы основаны на REST и свежем входе.

Найдены два остатка UI:

1. На studentA-loaded-start.png и studentB-blank-work.png длинный текст остаётся контрастным до самого нижнего края под progress и nav. Мобильная Lesson/ДЗ ветка DashboardPage использует body/window scroll wrapper без MobileScreen и useScrollFades. Нижний content fade отсутствует в этом состоянии.
2. До Done активный длинный ответ находится внизу (recording 270.2 с). После Done уже видна верхняя summary и вопрос 1 (271.3 с), ещё до последующего намеренного cold launch. HomeworkFlow безусловно вызывает window.scrollTo(0,0) на keyboard hide. Подтверждающий безопасный clip 269.7–271.4 с: keyboard-dismiss-scroll-reset.mp4; также сохранены before/after PNG.

Полные записи с авторизацией, AX и xcresult остаются приватными. Публикуемые PNG просмотрены после загрузки данных; skeleton не считается доказательством готового UI. Из наличия recording не выводится полная приёмка движения и всех фейдов. Не закрыты тёмная тема, landscape, увеличенный текст, reduced motion, контраст и вся палитра; teacher B в UI; каждый back/cancel/SwipeBack; double tap, late A→B, save 503 и потерянный ответ после сохранения. Отдельное раскрытие старых ответов через повторяющиеся кнопки истории не засчитано: оба комментария и серверные ответы доказаны, текущий исправленный ответ доказан в UI.

Телефон освобождён. Runner и временный host transport остановлены. Последний B Auth завершён обычным UI logout. Продуктовые файлы, main и production не менялись. Следующий кандидат требует новой независимой пары и собственного допуска.
