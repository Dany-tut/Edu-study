# Оптическое выравнивание букв вариантов ответа

Область: только буква А/Б рядом с текстом вариантов в редакторе задания.
Исполнитель: Стратег 3; интеграция editor через единственного владельца, выпуск
Стратег 1. База 7efd8558346f8f252839991a771a975308852119.

Причина: буква font12 центрировалась в фиксированных 40px, а ответ font14
использует GrowTextarea с оптическим подъёмом 0.12em. При нескольких строках
буква дополнительно съезжала к середине всего ответа. Буква после external patch использует
те же font-size/line-height, что поле, и держится первой строки. Для всей пары
локально задан оптический подъём 0.06em вместо общего 0.12em: это центрирует
пару внутри рамки и не меняет остальные GrowTextarea.
Touch font16 следует действующему глобальному правилу textarea. Формат данных,
выбор правильности, редактирование и сохранение не меняются.

План до прогона: реальный GrowTextarea и readonly JSX карточки,
два варианта А/Б, короткий/многострочный текст, ввод/сокращение, выбор single/multi;
ПК/iPhone/iPad portrait/landscape/Android × светлая/тёмная темы, baseline-метрики
и визуальный просмотр. Full constructor/server, WebKit/физические устройства
вне этой fixture-проверки. Native Edge не использовать.

Редактор в ветке не изменён; external patch только CSS import, одна точка буквы и className поля ответа:
/Users/dany/.codex/iskra-qa/choice-letter-alignment-20261122/editor-integration.patch.

Из неё извлечён настоящий JSX choice block и AutoTextarea/Label; GrowTextarea,
FIELD и Loop-иконки настоящие. Только task/onUpdate и перевод — fixture.

многострочная буква остаётся у первой строки. Runtime errors отсутствуют.

## Уточнение Дани: центр всей строки, а не только совпадение baseline

добавлен .editor-choice-answer только к этому AutoTextarea. Scoped CSS переопределяет
только два вертикальных padding для буквы и поля; общий GrowTextarea не меняется.

высота рамки и внешняя отметка не сдвигаются. Соседние контролы/ответы/save прежние.

Повторная независимая проверка actual row в 12 комбинациях — PASS.

actualBoundingBoxAscent/Descent относительно центра рамки — 0.2127px (допуск <0.75px);
центр внешней отметки относительно рамки — 0px. Проверка фокуса и выбора
