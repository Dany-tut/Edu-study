# Условная колонка посещаемости

Карточка до проверки. База 1ea684e6; ветка codex/journal-course-attendance; patch = git diff ветки. Ответственный Codex. Логика: journalDemo, UI: loadFixture 2×8, без записей в БД.
Ожидание: только записи без отметок → колонки нет; живой или смешанный курс → есть; явные «был»/«не был» на записи сохраняют колонку. Просмотр видео и общий старый процент не включают колонку. Тесты и домашки сами по себе не включают посещаемость. В смешанном списке у ученика только с записями — прочерк.
План: логика форматов/отметок; UI — 16 сочетаний четырёх колонок + возврат, сортировки и скрытие выбранной колонки, пустой поиск, th/td/col/colspan 4–8, горизонтальный overflow 0/50/100%, 7 ширин × 2 темы. До запуска NOT TESTED.
Непроверенное fixture: сервер, физические устройства и нативные оболочки, покадровое движение.

Логика, check:ui и типы PASS на исходном patch. Браузер: первый load превысил 30s при оптимизации Vite; ожидание заменено на DOMContentLoaded/120s. Снимки /tmp/iskra-journal-{1440,390}-{light,dark}.png просмотрены на телефоне и ПК. Исходники продукта во время успешного прогона не менялись. Физические устройства/сервер/нативные оболочки, скрытый адаптивный поиск, zoom/reduced-motion и покадровая анимация не проверены.
