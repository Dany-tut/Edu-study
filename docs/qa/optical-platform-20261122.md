3. Пройти составные строки и прямые поля конструктора, журнала, ученика,
   входа, профиля, админки и overlay. Для каждого случая записать состояние,
   размер, тему, ожидаемую геометрию и визуальное доказательство.
4. После стабилизации общего профиля закрепить значимый regression fixture
   в check:ui. Проверка измеряет результат и границы глифов, а не наличие CSS-строки.
5. Полный UI с сервером и физические версии принимаются отдельно; непроверенное
   не включается в заявление «везде проверено».
