# Цвет «Добавить» при прикреплении ссылки

Область: LessonLinkAttach.tsx — LessonLinkPanel на скриншоте и одноимённая
кнопка компактного варианта в том же компоненте. Исполнитель: Стратег 3;
публикация через Стратега 1. Данные/обработчики/геометрия/editor не меняются.

Причина: текстовый токен color-green-text использовался как заливка. В тёмной
теме он становится ярким #4ADE80, при этом белый текст теряет контраст.
Заливка заменена на существующий color-green-fill (#1B7A45) для залитых
контролов с белым текстом в обеих темах. Стили палитры глобально не меняются.

Сценарий до проверки: readonly локальный fixture реального JSX LessonLinkPanel,
без сервера. ПК, iPhone, iPad портрет/ландшафт, Android × светлая/тёмная темы.
Ожидание: вычисленный фон #1B7A45, белый текст читается; ввод/ошибка/сброс/отмена
не меняются; размеры/кнопки прежние. Результат: PASS в 10 комбинациях (ПК 1440, iPhone 390, iPad 820/1180,
Android 412 × обе темы). Вычисленные цвета во всех случаях #1B7A45 / #fff
для normal/hover/focus/forced-disabled. Использованы действующие root/dark
переменные и общие hover-правила из index.css. Кнопка в production не имеет
disabled prop: disabled принудительно установлен только в fixture для проверки
цвета, новый disabled-сценарий в продукт не добавлен.

Проверены вызовы submit/cancel и показ ошибки на fixture; useT и makeLinkFile
там явно заменены заглушками. Проверка не является приёмкой валидатора ссылок
или серверного сохранения. Скриншоты светлой/тёмной тем просмотрены.
Компактный вариант получил ту же двухстрочную замену токена; его отдельный
интерактивный прогон не проводился. npm run check:ui — PASS.
