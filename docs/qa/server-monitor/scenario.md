# Серверный монитор — карточка до прогона
База: cb9a7d47, отдельная рабочая копия iskra-server-monitor. Версия кандидата будет записана в результате.
Риск: потеря коротких/восстановленных ошибок, раскрытие диагностических данных в public-репозитории, ложное здоровье при остановке monitor.
Локальная приёмка: настоящий Postgres16 в отдельном временном контейнере; искусственные analytics_events/auth/cron. Ни одна migration не применяется к production.
Инварианты: сбой сохраняется после recovery; повтор incident_id не увеличивает число; тесты/other_host отдельно; злонамеренный meta не ломает insert; anon не читает сигналы, admin читает; публичная сводка не содержит ID/логов; capture error виден; устаревший heartbeat не считается успехом.
Клиент: lazy import first fail → success; все попытки fail; reporter/storage fail; повтор/reload сохраняет failure_id; восстановление mount не объявляет урок рабочим; таймаут остаётся ошибкой.
Пульс: удалённый источник ошибся/устарел/исправен, локальный статус release/hotfix независим. Никаких внешних URL или команд из логов.
UI: только инструментирование существующих кнопок, без изменения геометрии. Проверка данных/React fixtures отдельно от визуальной приёмки/нативного устройства. Native crash и полноценный lesson data success требуют отдельных доказательств.
