# Условные колонки оплат

Карточка до проверки: база c263924c, ветка codex/journal-course-payments, patch = git diff ветки. Ответственный Codex. Данные journalDemo/loadFixture, без записей в БД.
В текущей модели нет флага учёта оплат курса. Принятое условие: стоимость > 0, срок оплаты, последний платёж или долг > 0 на карточке ученика. Баланс уроков сам по себе недостаточен; нулевой долг при наличии платежа не отключает учёт. В курсе используются карточки его состава; оплата/долг другой карточки того же человека из другого курса не переносятся. В списке всех курсов сохраняется собственная карточка строки; суммы между карточками не агрегируются.
Ожидание: обе колонки включаются/скрываются вместе по полному списку до поиска; сортировка использует тот же финансовый контекст. У строки без учёта — два прочерка, пока другие ученики сохраняют колонки.
