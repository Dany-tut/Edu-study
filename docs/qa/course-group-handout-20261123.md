# Выдача копии группе

База проверки — 5d377494. Команда из корня интегрированной рабочей копии с
установленным PGlite — `node scripts/checkCourseGroupHandout.mjs`.
При отдельной установке пакет указывается в `ISKRA_PGLITE_MODULE`; для проверки
двух рабочих веток путь к миграции 20261123090000 задаёт `ISKRA_COPY_MIGRATION`.

Изолированный PostgreSQL, 47 синтетических уроков, разные UUID преподавателя,
групп и ученика. Вызов настоящего обработчика подтверждения выдачи связан
с настоящими функциями копирования, назначения аудитории и создания расписания.
Сетевой ответ имитируется. Проверено следующее.

- При несохранённой правке в исходнике обработчик не выдаёт копию. Два быстрых
  подтверждения запускают один вызов. После фиксации транзакции потерянный ответ
  и повтор из заново открытого редактора возвращают ту же копию.
- Несовпадение версии, уроков или модулей, чужая группа, неподтверждённая
  сессия, попытка выдать исходной группе и повтор с подменой параметров отклонены.
- Конфликт слота после создания курсовой структуры и аудитории откатывает
  всю выдачу. После освобождения слота повтор успешен.
- У копии отдельные UUID, собственные ссылки 47 уроков, описание, таймкоды и
  версии глав сохранены. Перенос календаря сохраняет интервалы уроков, записей
  и домашних заданий, а также дополнительные поля JSON. Назначение содержит
  только целевую группу и её ученика. Снимки исходника и его расписания совпали.
- Проверены публикация и черновик, явное копирование из копии, отсутствие
  переноса дат и один слот для записи, совпадающей по времени с уроком.

Полный браузерный интерфейс ПК/iPhone/iPad/Android, физические устройства,
production latency и политика доступа production в этой изолированной проверке
не воспроизводились.
