# Искра — продолжение исправлений входа, 3 ноября 2026

Исправлены вход ученика при задержках/ошибке профиля, доступность восстановления и размеры показа пароля. Production не изменялся. Проверенная production-сборка использует настоящий локальный Supabase и синтетические аккаунты; хеши — snapshot.json, итог — verification.json. Общая рабочая папка продолжает меняться другими чатами.

## Ошибки и исправления

**STUDENT-AUTH-01.** Раньше signInWithPassword сохранял общую сессию до проверки профиля. Ошибка чтения students игнорировалась: отсутствие data отправляло ученика в кабинет преподавателя. Теперь профиль читается в отдельном Auth-клиенте в памяти, до записи общей сессии. Ошибка отклоняет вход и оставляет форму с введёнными значениями. Только успешный пустой ответ разрешает прежний сценарий входа преподавателя через общую форму. Несколько карточек ученика выбираются детерминированно: самая ранняя, при одинаковой дате — по id.

**STUDENT-AUTH-02.** Вход/восстановление ученика получили ограничение ожидания, отмену и защиту от запоздалого результата. Переключение на восстановление, возврат и выбор роли отменяют активное действие. Поздний ответ не выполняет навигацию, не показывает отправленное письмо и не сохраняет intent восстановления. При отмене чтения профиля общая сессия не записывается; подтверждено после перезагрузки.

**AUTH-TARGET-01.** Кнопки показа пароля ученика и обеих регистраций увеличены до 44×44 px, справа оставлено место под текст. У всех четырёх форм состояние переключателя доступно через aria-pressed. Кнопка преподавателя 44×44 уже была исправлена в параллельной работе; её размер повторно проверен.

**AUTH-KEYBOARD-01.** «Забыли пароль?» и возврат у преподавателя теперь настоящие кнопки, доступные через Tab/Enter/Space. Вход ученика также имеет доступные действия отмены и восстановления минимум 44 px.

**AUTH-SCROLL-01.** Вход ученика и обе регистрации используют общий ScrollFade на фактическом скроллере. В низком окне доступны верх и низ формы, есть фейды начала/середины/конца. Поля регистрации увеличены с 14 до 16 px, высота минимум 50 px.

## Поэлементные границы

| Элементы | Проверено | Осталось |
|---|---|---|
| Пароль, показать/скрыть во всех четырёх формах | Ввод, Space, обычные/повторные клики, сохранение значения, 44×44, обе темы и 4 размера | Физическая iOS-клавиатура/Keychain на новом коде, screen reader, zoom/reduced motion |
| Забыли пароль / назад, ученик и преподаватель | Keyboard Enter, переход туда/обратно без потери пароля, отмена pending и поздний ответ | Внешняя доставка письма и полный браузерный reset на новом коде |
| Войти / отмена ученика | Ошибка профиля, timeout, повтор, поздняя отмена, настоящий успешный вход | Полная матрица every state × theme × browser; несколько вкладок |
| Поля email/имя/фамилия | Геометрия и 16 px в регистрациях; настоящий email/пароль в auth-прогоне | Полная клавиатурная/валидационная матрица всех регистрационных полей |
| Предметы, согласия, регистрационная кнопка преподавателя | Только присутствие и визуальный контекст в текущем прогоне | Все действия/ошибки/успех регистрации преподавателя, раскрытие списка, полный контраст |
| Apple/Google, ссылки политики, вход по коду | Присутствие в визуальном контексте; предыдущие отдельные OAuth/OTP-тесты сохраняются | Настоящие внешние провайдеры и полный визуальный/поэлементный прогон этих действий |

Замедление CPU, покадровая плавность всех форм, Edge/Safari и физические устройства этим продолжением не проверены. Измерение контраста всей палитры не выполнялось; визуальный просмотр не означает сертификацию доступности. Изменение пароля и отправку письма нельзя отменить задним числом, если сервер уже выполнил действие; отмена здесь ограничивает ожидание/последующие UI-действия.

Повторяемые команды: `node scripts/security/checkLocalStudentLogin.mjs`, `node scripts/security/checkLocalAuthCancellation.mjs`, `ISKRA_QA_OUTPUT=docs/qa/readiness-fixes-2026-11-03/student-login-followup/forms node scripts/checkInterruptedForms.mjs`. Для UI нужен localhost frontend и приватные fixture-файлы; визуальный драйвер сохранён в auth-form-visual.mjs. Для основной логики использованы [signInWithPassword](https://supabase.com/docs/reference/javascript/auth-signinwithpassword) и [abortSignal](https://supabase.com/docs/reference/javascript/using-modifiers-abortsignal), проверенные по официальной документации.
