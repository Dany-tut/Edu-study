# Искра · приёмка пилота 3 ноября 2026 года

Тестовые аккаунты и учебные работы были вымышленными. Браузерный сценарий на публичном домене использует отдельную группу. Преподаватель через API создаёт карточку ученика и задание, затем участники выполняют регистрацию, сдачу и проверку через интерфейс.

## Проверки рабочего сервера

| Проверка | Наблюдение |
|---|---|
| Назначение роли | Значение admin в пользовательских метаданных оставляет нового пользователя учеником. Изменить собственную роль напрямую не удалось. Принятие действительного приглашения выдало роль преподавателя. |
| Выдача и сброс пароля | Преподаватель выдал пароль тестовому ученику. Вход прошёл. Сброс учеником через служебный обработчик получил 403. После сброса владельцем новый пароль принят, старый отклонён, поле временного пароля осталось пустым. |
| Восстановление | Supabase выдал токен восстановления для тестовой почты. Токен позволил сменить пароль один раз. Старый пароль и повторное предъявление токена отклонены. Доставку письма во внешний почтовый ящик этот тест не проверяет. |
| Удаление открытых паролей | До исправления 35 карточек содержали открытый пароль. Все 35 уже имели отдельную учётную запись Auth. После очистки открытых паролей 0, новые значения запрещены на уровне базы. |
| Права записи | Четыре миграции применились, в базе подтверждены 36 дополнительных ограничительных политик. Обновлены обработчики выдачи аккаунта, сброса паролей ученика и преподавателя, а также аналитической сводки. |
| Приглашения и аналитика | В исходной проверке найдено 28 событий с параметром приглашения. Среди сопоставленных с ними ссылок не было действующих непринятых приглашений. Удалены также секреты из обратных ссылок авторизации, включая вложенный фрагмент после маршрута. Защита действует в базе и для старых клиентов. Повторный поиск по проверяемым параметрам в пути и метаданных дал 0. |
| Затронутый сеанс | Один действующий токен продления входа совпал со значением в старой аналитике. Отозван соответствующий сеанс, проверено его отсутствие. По этим данным нельзя определить, был ли токен использован посторонним. |
| Исторические роли | У четырёх старых профилей преподавателя не найдено ни сохранённого принятого приглашения, ни роли в серверных метаданных Auth. Их права требуют сверки владельцем. Менять роли только по возрасту профиля небезопасно. |

## Что проверил браузер

Ученик зарегистрировался по приглашению, ввёл два ответа, перезагрузил черновик и сдал работу. Браузер намеренно потерял ответ сервера после сохранения. Ученик повторил отправку. Преподаватель прочитал исходные ответы, выставил 90% и опубликовал комментарий. Ученик вошёл в новом сеансе и увидел балл, комментарий и свои ответы. В базе осталась одна попытка.

На предварительном прогоне тестовый преподаватель без настроенных предметов увидел штатное окно выбора. Драйвер научился нажимать «Позже». В другом прогоне ожидание итога после перезагрузки превысило 25 секунд. Полный повтор прошёл; причину единичного тайм-аута не установили. Все созданные драйвером учебные аккаунты и карточки были удалены.
