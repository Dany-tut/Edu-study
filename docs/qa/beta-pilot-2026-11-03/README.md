# Искра · приёмка пилота 3 ноября 2026 года

Тестовые аккаунты и учебные работы были вымышленными. Браузерный сценарий на публичном домене использует отдельную группу. Преподаватель через API создаёт карточку ученика и задание, затем участники выполняют регистрацию, сдачу и проверку через интерфейс.

| Восстановление | Supabase выдал токен восстановления для тестовой почты. Токен позволил сменить пароль один раз. Старый пароль и повторное предъявление токена отклонены. Доставку письма во внешний почтовый ящик этот тест не проверяет. |

| Приглашения и аналитика | В исходной проверке найдено 28 событий с параметром приглашения. Среди сопоставленных с ними ссылок не было действующих непринятых приглашений. ## Что проверил браузер

Ученик зарегистрировался по приглашению, ввёл два ответа, перезагрузил черновик и сдал работу. Браузер намеренно потерял ответ сервера после сохранения. Ученик повторил отправку. Преподаватель прочитал исходные ответы, выставил 90% и опубликовал комментарий. Ученик вошёл в новом сеансе и увидел балл, комментарий и свои ответы. В базе осталась одна попытка.

На предварительном прогоне тестовый преподаватель без настроенных предметов увидел штатное окно выбора. Драйвер научился нажимать «Позже». В другом прогоне ожидание итога после перезагрузки превысило 25 секунд. Полный повтор прошёл; причину единичного тайм-аута не установили. Все созданные драйвером учебные аккаунты и карточки были удалены.

## Опубликованная сборка

На публичном домене /release.json и /version.json вернули один и тот же коммит 8992d2f8ef3d4bda55c2e16099114594b41d74ca, версию 1.0.1875 и номер 1875. Релиз вышел через Git-интеграцию Vercel после обязательного CI. Отдельный раздел «Проверка» остался удалён. В релизном коммите также исправлен вывод краткого текста задания в тренажёре.

На опубликованной сборке повторно пройдены все семь шагов в Chrome на macOS, включая перезагрузку после оценки. Проверка ширины 390 px охватила вход преподавателя, переход к форме восстановления и отказ по недействительному приглашению. В отдельном браузерном тесте перехватили исходящий запрос аналитики и подтвердили, что в нём только маршрут без токена. В итоговом аудите БД открытых паролей, событий с проверенными секретными параметрами и оставшихся тестовых логинов в проверенной выборке — по нулю.

## Границы сегодняшнего пилота

Проверенный маршрут охватывает преподавателя и ученика с приглашением, выдачу задания, сдачу, ручную оценку и повторный вход. В эту приёмку не вошли внешний почтовый ящик, реальный iPhone, финансовые операции, автопроверка ИИ и внешний сервис Тестли. Нагрузочный результат предыдущей локальной сборки нельзя переносить на прод. Для остальных модулей и выпуска без ограничения по участникам нужны отдельные результаты. Сводная рабочая ветка других чатов с конфликтами не является частью этой поставки.
