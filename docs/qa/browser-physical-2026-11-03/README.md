# Искра — браузеры на физическом iPhone, 3 ноября 2026

Safari и Яндекс отрисовали форму преподавателя на iPhone 17 Pro с iOS 27.1. В обоих браузерах проверены ввод Email/пароля и сохранение значений после вертикального swipe. Кнопка входа не нажималась; использованы только ui-only@example.invalid и фиктивный пароль.

## Safari

Статические файлы dist обслуживал отдельный временный XCUITest runner через NWListener, привязанный только к loopback телефона. CSP connect-src none блокировал API и телеметрию. Пройдены форма, фокус полей и прокрутка. Снимки: safari-login.png, safari-password.png, safari-scroll.png. Этот проход предшествовал последнему изменению геометрии формы.

## Яндекс

Loopback сначала вернул ERR_CONNECTION_FAILED. Проверка продолжена через временный HTTP-сервер на частном Wi-Fi адресе Mac, без публикации в интернет. Сервер отдавал только index.html и публичные runtime assets dist, без listing, API, исходников и sourcemaps. Ресурсы размещались под случайным 128-битным префиксом. Корневой index разрешался только для подтверждённого peer IP тестового телефона; другим клиентам GET / возвращал 404. CSP сохранял connect-src none, form-action none, frame-src none и object-src none.

Исходный dist не менялся: сервер переписывал только пути Vite preload и публичного trainer.png для размещения ресурсов под префиксом. Первоначально trainer.png не входил в whitelist; после исправления стенда выполнен отдельный успешный визуальный проход с загруженной картинкой. Итоговый чистый снимок: yandex-lan-form.png.

Из-за нормализации pathname маршрутизатором форма должна загружаться на /, а ресурсы — под префиксом. XCTest.open периодически зависал при загрузке accessibility Яндекс; восстановление terminate/launch позволило проверить уже открытую правильную форму. Последний визуальный проход успешно открыл адрес штатно через новую вкладку и адресную строку: URL вводился посимвольно, полное значение проверялось до кнопки Go. Разрешения локальной сети/firewall не запрашивались; настройки системы и браузера не менялись.

## Подтверждённые проверки

- browser2.xcresult: Safari форма/прокрутка PASS.
- browser7.xcresult: закрытие своей вкладки Safari PASS.
- browser-lan-verify.xcresult: Яндекс Email/пароль/системная клавиатура/прокрутка PASS (10.7 с), уборка PASS (4.9 с).
- browser-lan-clean.xcresult: Яндекс визуальная проверка с trainer.png PASS (22.4 с), уборка PASS (4.9 с).
- Все созданные тестовые вкладки закрыты. Исходная вкладка Яндекс сохранена, assertion app.cells.count == 1 прошёл.
- Временный Wi-Fi сервер остановлен; повторная TCP-проверка вернула ConnectionRefusedError.

Полные результаты и исходники находятся во временном harness; путь записан в /tmp/iskra-browser-uitest-path. В репозиторий включены только снимки локальных страниц. У раннего yandex-loopback-blocker.png обрезана область системного уведомления.

Наблюдение проверенной сборки: hit target кнопки «Показать пароль» составляет 32×32 pt, при проектном минимуме 44 pt. Передано основному агенту; компонент формы в этой подзадаче не изменялся.

Отправка форм, реальная авторизация через эти браузеры, production API и полная матрица размеров в этот браузерный проход не входили. Публикация и коммиты не выполнялись.
