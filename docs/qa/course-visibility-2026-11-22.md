# Видимость модулей и уроков — приёмка

Согласован концепт в чате Стратега 2. База: c263924c; итоговый SHA фиксируется после интеграции исправления очереди сохранения.

Область: самостоятельная видимость элемента, без изменения прав прохождения, прогресса, содержимого и расписания. Скрытый модуль скрывает все свои уроки. Показ модуля сохраняет собственные флаги уроков. Старые content snapshots не сбрасывают видимость.

Данные: два разных курса/преподавателя, ученик, два модуля A/B с разными уроками; новые и существующие элементы, пустой модуль, повторяющиеся названия. Production-данные и открытая вкладка с несохранённым черновиком не используются для QA.

| Проверка | Ожидание | До запуска |
|---|---|---|
| Глаз модуля/урока, обычное/повторное/быстрое нажатие | Один подтверждённый результат; независимость от прохождения | NOT TESTED |
| Ошибка и повтор | Прежняя видимость; понятная ошибка; без ложного успеха | NOT TESTED |
| Модуль скрыт, урок отдельно скрыт/показан | Модуль доминирует; собственная настройка урока сохраняется | NOT TESTED |
| Прямая выдача урока / старый клиент | Скрытые материалы отсекаются RLS | NOT TESTED |
| Чужой преподаватель / ученик / anon | Нет записи видимости чужого курса | NOT TESTED |
| Старый content snapshot | Не изменяет visibility или progress | NOT TESTED |
| Перестановка/удаление модулей A/B | Видимость следует стабильному ID, не позиции | NOT TESTED |
| Новый модуль/урок до первой записи | Скрытие фиксируется до публикации содержимого | NOT TESTED |
| Поздний ответ загрузки / смена курса | Не отменяет подтверждённый клик и не подменяет соседний курс | NOT TESTED |
| ПК 1440/1280×720, iPhone 320/390, iPad 820/1180, Android 412 × обе темы | Кнопки доступны без hover; текст читаем; без вложенных кнопок | NOT TESTED |

Фиксируются отдельно: модульные проверки, реальная БД в изолированном PGlite, fixture UI, опубликованные ассеты и манифесты. Полный авторизованный production UI и физические устройства не заявляются проверенными без отдельного прогона.
