# Кандидат календаря и регрессионная приёмка

Область: исправление фильтра выбранного дня в большом календаре Искры,
устранение удержания старых карточек, фейды списка и возврат к текущему дню.
Основа: актуальный main и согласованный кандидат исправлений входа/трека.
Не включает незавершённые изменения других чатов из общей рабочей папки.

Критерии приёмки:

- Выбранная дата, подпись и точный набор ID/дат карточек согласованы.
- Наблюдение MutationObserver/rAF устанавливается до клика, включая короткую
  подмену, которая исчезает до конечного состояния.
- Различимые недели и дни с одинаковым количеством, 0/1/overflow, запись/отмена.
- Повтор, 20 быстрых переключений, Enter, стрелки и Сегодня.
- Обе темы, desktop 1280, mobile 320/390, tablet 768, низкое окно 1280×600.
- Маски: начало только снизу, середина сверху и снизу, конец только сверху.
- Сквозной путь: настоящий локальный Auth/БД и полный кабинет; мобильный вход
  в расписание через «Расписание и переносы», а не скрытый desktop-виджет.
- Негативные контроли: фильтр отключён; краткий неверный ID, затем правильный.
- Артефакты успеха/ошибки сохраняют SHA и SHA256 исходников; первый FAIL сохраняется.

Команды:

```
npm run check:calendar-browser
ISKRA_CALENDAR_TRANSIENT_MUTANT=1 npm run check:calendar-browser
ISKRA_QA_BASE_URL=http://127.0.0.1:5316 node scripts/security/checkLocalCalendarDay.mjs
ISKRA_QA_BASE_URL=http://127.0.0.1:5316 node scripts/security/checkLocalStudentLogin.mjs
ISKRA_QA_BASE_URL=http://127.0.0.1:5316 node scripts/security/checkLocalStudentLoginRace.mjs
ISKRA_QA_BASE_URL=http://127.0.0.1:5316 node scripts/security/checkLocalReturnCycle.mjs
```

Негативный контроль ожидаемо падает из-за неверных данных; падение загрузки,
сборки или недоступный сервер не считается успешным обнаружением мутации.
Серверные сценарии ограничены localhost и отдельными синтетическими аккаунтами.
Созданные тестом календарные строки удаляются по их собственным UUID.

Исправлен тестовый драйвер повторного входа: переход к заданию происходит после
исчезновения формы входа. Клик «Войти» не означает, что профиль и маршрутизация
уже завершились. Продуктовый обработчик ради этого ожидания не менялся.

Обязательный CI запускает календарь рядом с геометрией шапки и сохраняет
артефакты. Windows workflow дополнительно запускается на ветке этого кандидата.
Результаты не принимают остальные кнопки платформы, внешние интеграции,
физические устройства и количественный контраст, если нет отдельного evidence.
