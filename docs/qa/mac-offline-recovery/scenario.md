# Восстановление доступа к локальному модулю
Проверяет Codex. Сценарий составлен до запуска QA.
База 094f2aed791c11cb829cc05cc1ad80a6e47c4cad, изменения LocalTranscription.tsx.
Chrome, macOS, fixture UI с подменённым loopback-сервером. Преподаватели A/B с разными ключами подключения. Физические устройства и полный серверный профиль проверяются отдельно.

| Элемент | Действие | Ожидаемый результат |
|---|---|---|
| Сохранённое подключение | Открыть карточку | Надпись «Доступ сохранён», инструкция доступна |
| Инструкция | Открыть, закрыть, повторить пять раз, быстро повторить | Правильное expanded, видео и адрес настроек, нет потери ключа |
| Отключить | Недоступный сервер, отказ 403, успешный 204 | Ключ A удалён, ключ B сохранён, появляется «Запуск на Mac» |
| Отключить | Запрос завис | После 3 секунд доступно повторное подключение |
| Подключить | Ошибка сети, затем успех | Ошибка не сохраняет ключ, успех сохраняет новый ключ A |
| Поздний DELETE | Переподключить после таймаута | Старый ответ не удаляет новый ключ |
| Перезагрузка | После отключения | Остаётся отключено |
| Запуск на Mac | Enter, повторный клик | Подсказка раскрыта и сфокусирована |
| Плеер | Запуск, перемотка, сворачивание | Воспроизведение, смена времени, пауза |
| Прокрутка | Начало, середина, конец | Фейды соответствуют скрытому содержимому |

Размеры 320×680, 390×680, 768×680, 1440×900, 1440×600. Светлая/тёмная тема, reduced motion. До/после действий сохранять состояние и запись движения. Доказательства в /tmp/iskra-offline-qa.

Проверено 4 ноября 2026 в IAB (WebKit). Недоступный сервер, ответ 403 и 204 очищают только ключ A; таймаут освобождает кнопку через 3 секунды. Перезагрузка сохраняет отключённое состояние. Повторное подключение с успехом сохраняет new-A, ошибки не создают ключ. Ключ B остаётся token-B. Пять циклов раскрытия/закрытия, клавиша Enter на втором шаге и сохранённая привязка проверены.
Восемь сочетаний 320/390/768/1440 × 680 и light/dark проверены на отсутствие горизонтального переполнения, наличие видео и системной ссылки. Снимки сохранены в /tmp/iskra-offline-qa. Ошибок консоли в прогоне не было.
Непроверено — живой сервер и полный профиль, запуск моделей, физический телефон, reduced motion, низкое окно, количественная проверка кадров и контраста, перемотка/воспроизведение в этом прогоне, поздний ответ после abort. Новых областей прокрутки в продукте нет.
Вывод — PASS для перечисленных fixture-сценариев, общая приёмка PARTIAL.
