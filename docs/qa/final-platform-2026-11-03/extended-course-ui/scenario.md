# Дополнение полной приёмки Искры: экраны и авторские задания

- База: cb9a7d47 (полный SHA сохраняется в runtime.json перед прогоном); чистая отдельная копия. Изменения других чатов не включаются.
- Среда: http://127.0.0.1:5397, настоящий production Supabase; Chrome macOS, desktop/mobile emulation. Подготовка синтетических пользователей через API не считается регистрацией через UI.
- Ответственный: текущий QA-чат; риск: потеря авторского содержания, неверная принадлежность задания, недоступные элементы.
- Данные: собственные UUID преподавателя/ученика/курса/ДЗ; A/B различаются ID и содержимым; пустые и длинные данные. Удаление только собственных записей, секреты вне отчёта.
- Ожидаемый результат: содержимое после сохранения/reload соответствует выбранной записи и исходному вводу; копирование не меняет оригинал; действие ошибки сохраняет ввод.

| Область | Действия | Ожидание | Статус до запуска |
|---|---|---|---|
| Конструктор/курс | создание, поля, урок/модуль, сохранение, reload, копия, изменение, удаление | Полная иерархия сохраняется, независимые IDs | NOT TESTED |
| Типы заданий | выбор, заполнение, изменение, сохранение, ответ ученика | Задание своего типа, ответ сохраняется и проверяется правильно | NOT TESTED |
| Все маршруты | содержимое, доступность имени, ввод, клавиатура, overflow | Роль/данные корректны, элементы достижимы | NOT TESTED |
| Интеграции | сверка существующих реальных прогонов и их границ | Нет ложного PASS по старту OAuth или mock | NOT TESTED |

Для каждого результата сохранять точные размеры, тему, IDs/эффекты, console/pageerror, доказательства и непроверенные комбинации. Наблюдение переходов начинается до действия. Открытие экрана не равно функциональной приёмке. Начало/середина/конец прокрутки, focus/Escape, zoom, мобильные цели, контраст проверяются отдельно. Полная физическая матрица и неподтверждённые OAuth callback остаются видимыми.
