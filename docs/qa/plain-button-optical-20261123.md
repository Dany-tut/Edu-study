# Приёмка выравнивания обычных подписей кнопок

База 234ac10b. Проверяем реальные OpticalText и btn, сформированный
Tailwind Preflight, CSS Искры и Android, локальный Roboto для эмуляции Android.
Стенд использует данные примеров, без сервера продукта и аккаунтов.

| Проверка | Сценарии | Результат |
| --- | --- | --- |
| Сравнение исходников | 1025 подписей в 237 файлах. Удаление только новой обёртки и добавленного импорта даёт исходный файл побайтно | PASS |
| Chrome и WebKit | 14 сочетаний размера и темы в каждом движке. ПК, iPhone 320/390, iPad в двух ориентациях, Android 412 | PASS |
| Геометрия | S/M/L, SVG рядом с текстом, flex utility, длинный перенос, составная подпись со счётчиком, disabled и переход в состояние сохранения | PASS, размеры кнопок и положение SVG совпадают |
| Управление | Имя кнопки, мышь, Space и касание, disabled, исходная цель события | PASS |
| Существующие подписи и счётчики | Отдельный тег только для новой подписи, CSS для дочерних span по-прежнему применяется только к ним | PASS |

Для составных карточек, кнопок с несколькими связанными текстовыми частями
и полей ввода нужны проверки их собственных композиций. Визуальная матрица
проверяет общие формы кнопок, а не авторизованный сквозной проход всех страниц
или физические устройства.

Артефакты: remaining-optical-20261123 в каталоге визуализаций задачи.

## Выборочно проверенные локальные поля

Стенд снял однострочные поля входа, приглашений, профиля и лендинга с их
существующими стилями. Chrome и WebKit, ПК, iPhone и Android с Roboto, обе
темы. Пробные сдвиги на 0.5–1 px помогали одним строкам, но ухудшали другие,
включая цифры и прописные буквы. Для этих локальных полей сохранены прежние
отступы. Отчёты о пиксельных границах находятся в inputs и inputs-half.
