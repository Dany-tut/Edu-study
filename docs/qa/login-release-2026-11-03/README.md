# Выпуск компактных экранов входа Искры

Область: только вход ученика и преподавателя, общие заголовок/карточка, возврат к выбору роли, Apple/Google в одном ряду с оптическим выравниванием и подписью, более тёмный знак преподавателя. Исходная база: b2ad04ad (актуальный origin/main при подготовке). Исполнитель и проверяющий: Codex.

Авторизация, БД, кабинет, стикеры, меню курсов и материалы других задач не входят в изменение. Из актуального main сохранены исправления сброса пароля. Опциональные размеры сервисных логотипов сохраняют прежние значения по умолчанию в настройках аккаунта.

## Карточка проверки до выпуска

Окружение: чистая отдельная Git-рабочая копия от origin/main, локальная production-сборка. Браузер на компьютере с эмуляцией размеров/касания; телефон пользователя не подключается. Только синтетические адреса @example.invalid, ответы Auth перехвачены. Реальный OAuth и настоящие письма не отправляются.

| Элемент | Действие → ожидаемый результат | Матрица |
|---|---|---|
| Роли/иллюстрации/логотип | Заголовок и объект соответствуют роли; deep-логотип только у препода | light/dark; 320/390/768/1440; низкое и альбомное окно |
| Email/пароль | Ввод, показать/скрыть, восстановить/назад → значение сохранено | Обе роли, 16px поля, 44px цели |
| Apple/Google | Логотип+подпись в одном ряду; правильный provider и role в исходящем URL | Обе роли; без обращения к провайдерам |
| Войти/отмена | Контролируемый отказ/задержка → ошибка, сохранённый ввод, отменённый поздний ответ | Обе роли |
| Код преподавателя | Раскрыть/отправить/неверный код/сменить почту/закрыть → правильное состояние | Только синтетические ответы |
| Возврат к роли | Пять повторов, быстрый повтор, Enter, Escape → нужный экран | Телефонная и десктопная ширины |
| Прокрутка | Начало/середина/конец → соответствующие фейды; без горизонтального overflow | Телефон/ПК; раскрытый код |
| Переходы | Кадры начиная до клика, reduced motion → нет потерянных действий | Локальный браузер |

До запуска на релизном SHA — NOT TESTED. Предыдущая локальная приёмка: 24 комбинации ролей/тем/размеров и отдельные проверки подписей, логотипа и выравнивания; артефакты остаются в рабочем каталоге исходного чата docs/qa/compact-login-2026-11-03. Кандидат проверяется повторно, результат привязывается к точному SHA в итоговом отчёте чата и внешнем каталоге доказательств.

Обязательные ворота выпуска: чистый коммит, npm run release:check, зелёный GitHub check «Типы, сторожа, сборка» для точного SHA, обычный fast-forward main, проверка полного SHA в production /release.json и /version.json.

Ограничения: реальная сессия, Apple/Google, настоящие коды/письма и физические устройства не входят в эту визуальную приёмку. Полная матрица физического UI остаётся PARTIAL. После выкладки проверяются публичные формы без отправки учётных данных. Production выпускается только Git-интеграцией Vercel из main.
