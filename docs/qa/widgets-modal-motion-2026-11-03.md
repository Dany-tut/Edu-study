# Плавность окна «Виджеты»

Симптом: короткий рывок при открытии окна настроек виджетов преподавателя.
Кандидат причины: scale/y-анимация предка во время первоначального измерения
Reorder. Исправление: стабильная геометрия окна, проявление opacity за 160 ms.
Это устраняет этот источник смещения; не доказывает отсутствие всех фризов
при загрузке тяжёлой главной.

Локальная браузерная проверка отдельного компонента, viewport 1280×720:
40 последовательных requestAnimationFrame после первого открытия; разброс
координат и размеров dialog — 0 px, координаты Y первой строки — 0 px;
наибольший интервал кадров — 16.7 ms. Окно и строки визуально проверены.
Эти измерения не заменяют запись полной главной на устройстве пользователя.

Для приёмки остальных экранов применять MOTION-01 из docs/ui-rules.md:
первый/повторный запуск, быстрое открытие-закрытие, длинные списки, загрузка
данных, телефон/десктоп, замедление CPU. Нужны запись или измерения перехода,
а не только скриншот установившегося состояния.
