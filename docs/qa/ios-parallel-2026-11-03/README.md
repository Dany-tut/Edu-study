# Искра — результат параллельного прохода, 3 ноября 2026

Три агента проверили визуальный UI, клавиатуру/жесты и мобильный цикл ДЗ. Родитель просмотрел изменения, подтвердил исправленные размеры журнала браузером и выполнил совместные проверки.

## Исправлено

- Шторка не закрывается при touchcancel, втором пальце или коротком рывке с паузой; поля, рисунок и горизонтальные списки сохраняют свои жесты. Действует только верхний dialog; фоновая страница не перехватывает свайп назад.
- Pinch zoom без активного поля не считается экранной клавиатурой.
- Новая попытка ДЗ с прежним progress id снова доступна для проверки. Публикация привязана к attemptId, legacy — к времени сдачи; снимок результата хранит отправленную оценку.
- Ошибка обновления очереди после публикации не объявляет саму публикацию неудачной. Дубли standalone/course-сдач одного ученика объединяются по новейшей дате с обработкой invalid/unknown.
- В мобильном журнале вторичные тексты, подписи и вкладки — 12 px; refresh 44×44. После правки подтверждены computed размеры и отсутствие горизонтального переполнения при 320×568, просмотрены начало, середина и конец списка.

## Проверки

Прошли TypeScript, check:ui с включённым новым check:mobile, 9 touch + 6 keyboard adapter-сценариев, регрессии попыток/дедупликации, веб-сборка, cap copy и подписанная Debug-сборка для физического iPhone. Новые тесты запускаются в отдельных Node-процессах через check:mobile, поэтому их DOM adapters не загрязняют остальные проверки. git diff --check прошёл.

Браузерный цикл отказ/черновик/reload/повтор/новая попытка/следующий ученик описан в ../homework-cycle-2026-11-03/README.md. Оценки в production не отправлялись.

## Осталось

Нативная визуальная проверка и реальные касания/клавиатура/VoiceOver пока не подтверждены: DeviceHub снова потерял доступ и завис. Подписанный com.dany.iskra.debug собран, но не установлен на физический телефон. Локальный Supabase54321 недоступен, поэтому реальный путь API→БД→кабинет ученика не засчитан. Дальнейшее упрощение структуры журнала, замеры запуска и аппаратная приёмка остаются следующими этапами.

Все изменения сохранены без коммита и релиза. Точная контрольная точка, команды и пути артефактов — CHECKPOINT.md; хеши проверенных исходников — source-hashes.json. Нет активных отправок, транзакций или загрузок в App Store.
