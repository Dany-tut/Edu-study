# Статус урока и корзина

Карточка до QA: база 1d80bf3081f9ba4b518e5a91a6988c07568145ad + локальный patch (sources.sha256). Исполнитель и проверяющий: Codex. Изолированный fixture извлекает реальный LessonRow, CSS приложения; без сервера. Риск: пустое место справа, перекрытия при появлении корзины.

Ожидается: без hover статус справа; hover/focus раскрывает 22px корзины + 8px промежутка; уход возвращает статус. На touch корзина видна. Reduced motion без перехода. Удаление вызывает только callback выбранного урока. Наблюдение геометрии начинается до hover, повторить вход/выход. Размеры 320/390/1440, обе темы; начало/середина/конец прокрутки fixture.

Серверные задержки неприменимы к CSS-переходу. Полный UI с сервером, физические устройства, прочие действия конструктора, zoom и измерение контраста — не проверены; итог ограничивается fixture.

Факт: PASS для 6 комбинаций 320/390/1440 × light/dark (высота 900), по 5 входов/выходов, фокуса и callback удаления. Промежуточные ширины 0…22 подтверждены frames.json; проверены touch 390×844 и reduced motion. Снимки начала/середины/конца сохранены; визуально просмотрены hover 320 light, idle 1440 dark и конец 320 light. npm run check:ui — PASS.

PARTIAL: fixture имеет прокрутку документа и не воспроизводит ScrollFade настоящей панели; приёмка её фейдов, все прочие комбинации и полный UI остаются непроверенными. Изменение не затрагивает overflow. Доказательства относятся только к извлечённой строке и CSS с хешами, без подтверждения production.

## Сворачивание статуса — карточка до проверки
Ожидается: при появлении статуса 1,4 с читается «Открыт», за 280 мс плашка сжимается до круга 24×24 с открытым замком; подпись доступна через title/aria-label. Наведение корзины не перезапускает текст. Reduced motion: подпись исчезает без анимации после той же паузы. Проверить размеры, обе темы и промежуточные кадры. Сервер и устройства остаются вне fixture-приёмки.

Сворачивание: PASS в 6 комбинациях 320/390/1440 × light/dark; первые кадры шире 24 px, промежуточные кадры сохранены в collapse-frames.json, финал 24×24. Hover не возвращает надпись; aria-label сохранён; reduced motion проверен. Визуально просмотрен 320-light-circle.png. check:ui PASS. Границы PARTIAL и непроверенные комбинации выше сохраняются.
