# EXT07 «Формулы для вашей работы: рецепты под задачи группы компаний» — заметка исследования

Дата: 27.11.2026. Модуль сверх ТЗ: `src/data/accounting/ext07.ts` (12 уроков `x07-01…x07-12`, 72 вопроса `acc-x07-NN-qN`, 66 схем).
Учебный файл: `public/courses/accounting/formuly-dlya-raboty.xlsx`, скрипт `scripts/accounting/build_formuly.py`.

## Для кого и от чего отталкивались

Учащаяся — опытный бухгалтер-экономист группы ~10 организаций (автодороги и дома, транспорт, асфальтобетон, бетон, плиты, знаки, стойки, секции). Задачи — из `confirmed_user_context` и `target_architecture` (industry_v4.json): ежемесячная численность по ЗУП, квартальный управленческий учёт с исключением ВГО, калькуляции, КП, ответы министерствам и ФНС, реестры самозанятых, сверки. Её реальных файлов нет — все данные вымышленные.

Версия Excel: по уточнению координатора от 27.11.2026 — **Excel 2016 или новее** (новое меню «Файл → Учётная запись», Windows 11), номер не известен. Поэтому в каждом уроке абзац «Какой маршрут выбрать»: основной — Excel 2016+, запасной — 2007/2010, современный (2021/2024/365) — с пометкой «проверьте в своей версии», Power Query — где уместно. Учебный файл — на функциях Excel 2007 (кроме столбца ЕФОРМУЛА, помечен зелёным).

Не дублируем энциклопедию (EXT03–EXT05): синтаксис функций там, здесь — композиции под задачу. Ссылки на уроки — словами в абзаце «Где подробнее в курсе». Проверено, что уроки с этими названиями есть в ext03/ext04/ext05/ext06, exp14, exp21, exp23, exp25. exp24 в рабочей копии нет — ставку НДС брали из exp11 (`nk-164`).

## Какие задачи разобраны и почему эти формулы

| Урок | Задача учащейся | Лестница формул | Почему так |
|---|---|---|---|
| x07-01 | квартальный сбор ОСВ 10 организаций | СУММЕСЛИМН с литералами → со ссылками и $ (матрица) → ключ & + СУММЕСЛИ (ловушка ИНДЕКС по неуникальному ключу) → контроль → сводная и ПОЛУЧИТЬ.ДАННЫЕ.СВОДНОЙ.ТАБЛИЦЫ | заменяет цепочки «=Лист3!F45+Лист7!F12» таблицей фактов (архитектура v4) |
| x07-02 | исключение ВГО | матрица продавец × покупатель → встречная сумма → статус ЕСЛИ+СЧЁТЕСЛИМН+ABS с порогом в ячейке → сумма к исключению и контроль трёх групп | «нет пары» отличается от «0» только счётом строк |
| x07-03 | распределение общих расходов, мостик | доля → ОКРУГЛ распределения → разница и ПОИСКПОЗ(МАКС) → поправка в крупнейшую через СТРОКА → мостик сумма − ВГО | данные подобраны так, что сумма округлений = 500 000,01 |
| x07-04 | калькуляции по рецептурам | норма × цена → СУММПРОИЗВ → цена на дату ПРОСМОТР / ИНДЕКС+ПОИСКПОЗ(…;1) → НДС из ячейки (×22/122 и ×1,22 через параметр) → партия | НДС с 2026 года сменился — ставка в ячейке |
| x07-05 | цены в КП | себестоимость с ЕСЛИ(выпуск=0) → наценка → цена по марже → ОКРВВЕРХ до 10 и фактическая маржа, цена с НДС | частая путаница «маржа 25 % = наценка 25 %» |
| x07-06 | транспорт (свой вид деятельности группы) | рейсы ОКРВВЕРХ → пробег и топливо → два тарифа (часы вверх) → ЕСЛИ/ABS/МИН и цена тонны | **добавлено сверх брифа:** остаток последнего рейса и округление часов к оплате |
| x07-07 | периоды и сроки | КОНМЕСЯЦА → квартал ОКРВВЕРХ(МЕСЯЦ/3) → метка ГОД&"-Q"&… (и ТЕКСТ с оговоркой) → ДАТАМЕС → РАБДЕНЬ с праздниками 2027 | **своё:** метка периода через ГОД/МЕСЯЦ вместо ТЕКСТ — коды формата ТЕКСТ зависят от языка Excel; ЦЕЛОЕ((МЕСЯЦ+2)/3) как альтернатива |
| x07-08 | ответы министерствам и ФНС | ФОТ между датами ">="&ячейка → СЧЁТЕСЛИМН месяцев и СРЗНАЧЕСЛИМН → средняя зарплата → сверка с ОСВ | **своё:** СЧЁТЕСЛИМН «сколько месяцев в периоде» как защита от пропущенной выгрузки; оговорка: простое среднее ≠ среднесписочная по Росстату |
| x07-09 | внутригрупповые займы, рассрочка | дни и дни в году формулой → проценты по дням (= ДОЛЯГОДА базис 1) → ПЛТ → ЧПС и дисконт | дни в году формулой ловят 2028 (високосный) |
| x07-10 | сверки с контрагентами, реестры | ключ СЖПРОБЕЛЫ&ОКРУГЛ(сумма×100) → дубль по растущему диапазону → «есть/нет» → дни долга и корзины, СУММЕСЛИМН "<>дубль", РАЗНДАТ с оговоркой | **своё:** сумма в копейках целым в ключе (не зависит от формата); растущий диапазон, чтобы не выкидывать оригинал дубля (при первом прогоне скрипта ошибка «обе строки — дубль» занизила корзину — оставлена как «Исправьте формулу») |
| x07-11 | контроль цепочек | «до = после» с ABS → СЧЁТЗ−СЧЁТ → ЕЧИСЛО → лечение ЗНАЧЕН(СЖПРОБЕЛЫ) → ЕФОРМУЛА (2007: «Показать формулы» / «Выделить группу ячеек») | |
| x07-12 | численность, самозанятые | ПРОПИСН → ПОДСТАВИТЬ Ё после ПРОПИСН → СИМВОЛ(160) + СЖПРОБЕЛЫ → тёзки СЧЁТЕСЛИМН с "<>"&табельный → ЗНАЧЕН чисел с кодом 160 | **найдено:** формула из брифа `СЖПРОБЕЛЫ(ПРОПИСН(ПОДСТАВИТЬ(A2;"Ё";"Е")))` не заменяет строчную «ё» (ПОДСТАВИТЬ различает регистр) — в уроке это вопрос «Исправьте формулу», верный порядок — ПРОПИСН внутри |

## Как проверено

- **Программно (Python):** `build_formuly.py` считает эталоны отдельно (арифметика, `datetime`, `Decimal` с округлением «половина от нуля»), пишет их на лист «Проверка», затем пересчитывает формулы книги мини-вычислителем `_xleval.py` (расширен в скрипте: даты, РАБДЕНЬ, ПРОСМОТР/ПОИСКПОЗ тип 1, ПЛТ, ЧПС, ДОЛЯГОДА базис 1, СРЗНАЧЕСЛИМН, ЗНАЧЕН, ЕФОРМУЛА, СТРОКА с аргументом). 249 проверок, расхождений 0.
- `--check-ts`: 31 ключевое число из листа «Проверка» найдено в тексте `ext07.ts`. Числа вопросов «поменяйте и проверьте» (Q2, порог 0, 10.07.2027, 201 т, АБЗ, 15.09.2027, 31.10.2027 и т. д.) пересчитаны отдельно на Python.
- `node scripts/checkAccounting.mjs ext07.ts` → OK.
- **В Excel не проверялось** (Excel у автора нет). В частности, не проверено, что русский Excel показывает ДАТАМЕС, РАБДЕНЬ без «Пакета анализа» в 2007, что `_xlfn.ISFORMULA` открывается в 2016 как ЕФОРМУЛА.

## Что не подтверждено (вынесено в `open` уроков)

- ПОЛУЧИТЬ.ДАННЫЕ.СВОДНОЙ.ТАБЛИЦЫ, ДАТАМЕС, КОНМЕСЯЦА, РАБДЕНЬ, ДОЛЯГОДА в Excel 2007/2010 — по общей практике; страницы Microsoft перечисляют версии с 2016. ЕФОРМУЛА — 2013 по алфавитному списку, 2016 по странице.
- Версии ОКРВВЕРХ.МАТ, РАБДЕНЬ.МЕЖД, ЧИСТНЗ не проверялись — упомянуты без года.
- Пути «Найти и выделить → Выделить группу ячеек → Формулы» и «Формулы → Показать формулы» — по общей практике Excel.
- Коды формата ТЕКСТ («ММ.ГГГГ» в русском Excel) — по общей практике; поэтому в файле метка без ТЕКСТ.
- ЗНАЧЕН с запятой — при русских региональных настройках Windows.
- Норма топлива, тарифы, рецептура, порог ВГО, границы корзин, правило «копейка в крупнейшую» — учебные/практика, не нормы.
- Средняя численность — простое среднее; официальная среднесписочная — по методике Росстата (урок курса о численности). Состав «ФОТ = кредит 70» — учебное упрощение.
- Налоговые правила процентов по займам (ст. 269 НК РФ) не разбирались.
- Сводная таблица в учебном файле не создана (openpyxl не строит сводные) — шаги в уроке.
