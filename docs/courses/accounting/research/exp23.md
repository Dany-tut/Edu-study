# EXP23 «Управленческий учет группы строительных и производственных компаний» — заметка исследования

Дата проверки: 27.11.2026. Модуль: `src/data/accounting/exp23.ts` (11 уроков m23-01…m23-11, 62 вопроса, 12 схем; темы ТЗ 20/20).
Шаблон: `public/courses/accounting/konsolidaciya-gruppy.xlsx`, скрипт `scripts/accounting/build_konsolidaciya.py`.
Вход: контекст учащейся `industry_v4.json` (≈10 организаций, квартальная консолидация, слои архитектуры, пример 700/1000/1500).

## 1. Рамка модуля

- Это **управленческая** модель группы по согласованной методике. Официальная консолидированная отчётность (208-ФЗ, МСФО (IFRS) 10) — только справочная сноска в m23-01 и m23-07 с пометкой «отдельная нормативная проверка».
- Элиминации — управленческие корректировки, в учёте юрлиц не отражаются; в 1С ничего не удаляется.
- НДС и налоги юрлиц не исключаются: обороты ОПиУ — без НДС, сальдо расчётов — с НДС; НДС к вычету по РК-1 (22) остаётся в балансе группы.
- «Чистая прибыль» не считается: шаблон показывает «прибыль до налога (управленческую)».

## 3. Шаблон и эталоны

Листы: Инструкция, Организации, План статей, Маппинг, Факты, Матрица ВГО, Расхождения ВГО, Элиминации, Мостик, По объектам, Проверка.
Формулы — только Excel 2007: SUMIFS, COUNTIFS, COUNTIF, VLOOKUP, INDEX, MATCH, IF, IFERROR, AND, OR, MIN, ABS, SUM, LEFT, RIGHT. Без таблиц-объектов, динамических массивов, Power Query.

Учебная группа (вымышленная): O01 дороги, O02 дома, O03 асфальт, O04 бетон, O05 плиты, O06 знаки, O07 транспорт, O08 аренда техники, O09 снабжение, O10 УК; O11 вышла из периметра 30.06.2026. ИНН начинаются с «00».

Ключевые эталоны (тыс. руб.): выручка компаний 170 500 → группа 133 400; себестоимость 138 850 → 103 750; ВГО-выручка 37 100; элиминация себестоимости 35 100; наценка в остатках на конец 700 (запасы 300, НЗП 400), реализовано из остатка на начало 200; прибыль до налога 25 250 → 24 750; объекты К-101 / К-102 / Д-201 — маржа группы 10 100 / 3 550 / 7 400. Пример учащейся: продано — валовая прибыль группы 800; не продано — наценка 300, запасы 700.

Проверено программно:
1. Python в скрипте считает эталоны независимо от формул (assert на пример 700/1000/1500 и на мостик).
2. Формулы книги пересчитаны собственным вычислителем подмножества Excel (scratchpad, вне репозитория): 0 ошибок формул, 47 проверок листа «Проверка» и 5 строк примера — «ОК».
В Excel и LibreOffice файл не открывался (их нет).

## 4. Вопросы учащейся (industry_v4.questions) → параметры «уточняется»

- Собственные силы — переключатель «По объектам»!B2 (1 — работы компаний группы свои, 0 — нет).
- Чистая прибыль — не считается; строка-пометка на «Мостике».
- Наценка продавца по паре — жёлтые ячейки «Элиминации»!F5:F14.
- Периметр — даты на листе «Организации».
- VBA/ПО, релизы 1С, обезличенный пример цепочки — в `open` уроков m23-04, m23-11.
