## Что проверено и как
- **Числа.** Все значения в эталонах, шагах, схемах и вопросах пересчитаны на Python (`scripts/accounting/verify_ext03.py`, все `assert` проходят). **Проверено программно, не в Excel и не в 1С**: Excel у нас нет. Округление считалось десятичным способом «от половины» (Decimal), а не float, чтобы не получить банковское округление Python.
- **Данные.** Листы «Платежи», «Сотрудники», «Сверка» из `praktikum-ishodnyj.xlsx` (Платежи и Сверка использованы; Сотрудники в этом модуле не понадобились). Остальное вымышленное: закупка (бумага, тонер, папки), акты сверки (5 контрагентов), НДС-накладная, выгрузка с числом-текстом.

- **Версии** — по `excelCompat.ts` и таблице 1 матрицы: ЕСЛИМН, ПЕРЕКЛЮЧ, МАКСЕСЛИ, МИНЕСЛИ — нет в 2007–2016, есть с 2019; ЕСНД — с 2013; СУММЕСЛИМН, СЧЁТЕСЛИМН, ЕСЛИОШИБКА — с 2007. Для каждой функции в уроке есть абзац «В какой версии Excel» с заменой для старых версий и строкой про Google Таблицы и Power Query.

## Не открылось / не подтвердилось (внесено в `open` уроков)
- **МИН** и **ОТБР**: адреса страниц угадать не удалось (404 на предполагаемых GUID), отдельные страницы не открыты; в уроках — общая страница «Функции Excel (по алфавиту)».
- **АГРЕГАТ**: в нашей матрице строки нет; «с Excel 2010» — по сведениям автора, не по источнику. Страница Microsoft в списке «Относится к» начинается с 2016. Замена для 2007 дана массивной формулой.
- **РАНГ.РВ, РАНГ.СР**: упомянуты как новые варианты по сведениям автора, страницы не открывались.
- **Приоритет операторов** («Порядок операций»), **характеристики и ограничения Excel** (глубина вложенности), **«Присвоить имя»** и **«Диспетчер имён»**, **связи между книгами** (поведение при закрытом файле): страницы не открывались, формулировки осторожные.
- Ctrl+Shift+Enter для Windows: на странице сочетаний найден только вариант «CTRL+SHIFT+RETURN» в разделе Mac; для Windows — по знанию автора.
- Русские имена на странице Microsoft расходятся с интерфейсом: ЕСЛИМН — «УСЛОВИЯ», ПЕРЕКЛЮЧ — «SWITCH»/«ПЕРЕКЛЮЧАТЕЛЬ», АБС — «ABS», МАКСЕСЛИ — «МАКСЕСЛИ» (заголовок) при «МАКСЕСЛИМН» в списке. В уроках используются имена из матрицы; пусть учащаяся сверит их по подсказке при вводе.
- Google Таблицы: наличие функций (MAXIFS, IFS, SWITCH, IFNA и др.) и отсутствие `AGGREGATE` указано по сведениям автора, в Таблицах не проверялось. Аналоги Power Query (`List.Sum`, `List.Max`, `Number.Mod` и др.) названы, в самом Power Query не запускались.

## Спорное (для Дани и специалиста)
1. **Версия Excel учащейся неизвестна** — поэтому у каждой функции есть замена для 2007/2010. После подтверждения версии лишние ветки можно сократить.
2. **Способ округления НДС** (по строке или по итогу) — вопрос учётной политики и формата документа; урок показывает только расхождение в копейку и не называет норму.
3. **Тренажёр.** Интерактивного тренажёра с изменяемыми значениями в Искре нет; в каждом уроке сделан `qtable` («одно значение изменено, впишите результат») и абзац «Поменяйте и проверьте». Когда концепт тренажёра утвердят, эти пары можно перенести в него.
4. Текст `qfill` в нескольких уроках принимает по смыслу; при желании заменить на `qgap`/`qnum`, где ответ один.
