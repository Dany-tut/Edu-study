## 3. Excel

- Консервативный маршрут — функции, которые есть с Excel 2007: СУММЕСЛИМН, СЧЁТЕСЛИМН, СУММПРОИЗВ, ВПР, ИНДЕКС/ПОИСКПОЗ, ЕСЛИОШИБКА, ОКРВВЕРХ, ОКРУГЛ, имена (CalcDate, PriceTab). Официальные страницы Microsoft перечисляют только поддерживаемые версии (2016+), поэтому наличие в 2007 — по справочникам; в Excel 2007 файл не открывался.
- Действующая цена/версия на дату — СУММПРОИЗВ по условиям (а не СЧЁТЕСЛИМН с ">"&дата): так формула одинаково считается и в Excel, и в других программах.
- Современный маршрут — МАКСЕСЛИ + LET (Microsoft 365 / 2021+), приведён в уроке m24-01.
- Цикл: полуфабрикат (бетон в плитах) берёт цену прямо с листа «Бетон», а не из справочника цен — иначе циклическая ссылка через диапазон СУММЕСЛИМН.
- Версия Excel у бухгалтера не подтверждена (compat v8): консервативный маршрут — обязательный.
