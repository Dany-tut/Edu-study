## Что подтвердилось по страницам
— СЖПРОБЕЛЫ убирает только пробел с кодом 32, неразрывный (160) не убирает; ПЕЧСИМВ убирает знаки с кодами 0–31; СИМВОЛ принимает 1–255; страница функции CODE называется КОДСИМВ.
— ПРОПНАЧ: заглавная — первая буква строки и каждая после знака, не являющегося буквой.
— ЧЗНАЧ: не зависит от локали, пробелы в тексте игнорируются, даже внутри.
— РАБДЕНЬ.МЕЖД: код выходных 1 — суббота и воскресенье, 11 — только воскресенье; строка из семи знаков с понедельника, 1 — выходной.
— ЧИСТНЗ: ряд значений должен содержать хотя бы одно положительное и одно отрицательное значение; платежи дисконтируются на основе 365-дневного года (пример урока поэтому построен с отрицательным первым платежом).
— ЧПС: платежи в конце периодов, равномерно распределены во времени.
— ДОЛЯГОДА: базисы 0–4 (1 — фактический/фактический, 3 — фактический/365).
— ДЕНЬНЕД: типы 1, 2, 3 (и 11–17); ТЕКСТ: коды «ДД.ММ.ГГГГ» на русской странице.
— ТЕКСТДО, ТЕКСТПОСЛЕ, ТЕКСТРАЗД: «Применяется к» — Excel 2024 и Microsoft 365. ОБЪЕДИНИТЬ: 2019 и новее.
— РАЗНДАТ: страница предупреждает, что функция сохранена ради старых книг Lotus 1-2-3 и в некоторых ситуациях может давать неправильные результаты; режим "MD" не рекомендуется.
— ДАТАМЕС: в синтаксисе на самой странице имя ДАТАМЕС (в списке функций ссылка названа «ДАТАТЕ» — машинный перевод).

## Что не подтвердилось
— Страница НАЙТИ по адресу функции вернула 404: описание НАЙТИ в уроке — по общему поведению, ссылка помечена `unreachable`.
— Версии Excel 2007, 2010, 2013 для классических функций: страницы Microsoft в списке «Применяется к» начинаются с Excel 2016. Утверждение «функция есть в 2007» в уроках сформулировано как «по общим сведениям, не проверялось».
— Имя «АМОРТ» из брифа: такой функции для уменьшаемого остатка на странице нет, функция DDB называется ДДОБ; в уроке 14 используется ДДОБ, «АМОРТ» оставлено в `topics` как тема модуля.
— Номера пунктов ФСБУ 6/2020 (32, 34, 35) сверены только по вспомогательной статье buh.ru; страница КонсультантПлюс открыла лишь оглавление. Официальный текст не открывался.
— Допущения о составе 20-значного номера счёта (1–5 знаков — балансовый счёт, 6–8 — код валюты, 810 — рубль) и длине ИНН (10/12) — общеизвестные, официальные страницы не открывались.
— Перечень нерабочих дней 2027 года взят из файла курса `kalendar-srokov-2027.xlsx`; производственный календарь не открывался.
— СИМВОЛ(160) на Mac, ЮНИСИМВ (упомянута как возможная замена), русское имя ошибки разлива, поведение ЗНАЧЕН с обычным пробелом внутри числа — не проверялись.
— РЕГИЗВЛЕЧЬ: только Microsoft 365 по матрице курса; имя не сверено с живым Excel.
— Все результаты формул — проверено программно (Python), не в Excel.
