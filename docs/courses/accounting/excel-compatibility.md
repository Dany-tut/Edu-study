# Матрица совместимости Excel для курса «Бухгалтерия»

Дата проверки: 27.11.2026. Статус: **проверено по документации Microsoft (support.microsoft.com, learn.microsoft.com); в самом Excel не проверялось** (Excel у нас нет). Данные для кода: `src/data/accounting/excelCompat.ts` (держать в синхроне).

## Версия учащейся не подтверждена

Раньше сообщалось «Excel 2007» (со слов). На последнем скриншоте виден раздел «Учётная запись» без читаемого номера версии: интерфейс указывает на Excel 2013 или новее, но это не доказано. Курс не ограничен 2007. Не утверждать версию, пока нет читаемого окна «О программе Excel» (версия, сборка, 32/64 бит), ОС и вкладки «Данные».

## Маршруты (v8)

— **conservative** — без макросов: базовые формулы, вспомогательные столбцы, таблицы, сводные, ручной импорт. Универсальный резерв и учебный маршрут, работает с 2007.
— **installed** — основной рабочий: выбирается после подтверждения реальной версии; Power Query по фактической доступности, без требования обновления.
— **modern** — отдельная ветка: Power Query, Power Pivot по доступности, современные функции, динамические массивы, язык M; отличия по версии и редакции.
— **vba** — только по разрешению работодателя и ИТ; локальные тесты, резервные копии, без отключения защиты.

## Как читать

Значения: **да** — есть; **нет** — нет; **надстр.** — отдельная надстройка; **огов.** — с оговоркой (редакция, лицензия, канал, платформа; см. «Примечание»). Пусто/«?» — источник не называет версию. «Excel 2021/2024» — постоянные (перпетуальные) версии. Маркер года в алфавитном списке функций Microsoft («Version markers indicate the version of Excel a function was introduced») принят как первая постоянная версия с функцией; в подписке Microsoft 365 функция может появиться раньше.

## Примечания по строкам

— **Power Query / Get & Transform** (Power Query («Получить и преобразовать данные»)): В 2010 и 2013 это бесплатная надстройка; Microsoft официально признала её устаревшей летом 2019 (может работать, но не гарантировано; ссылка на загрузку может не открываться). 2016 и 2019 (Windows): встроено. 2021/2024: страница PQA перечисляет их в «Применяется к», но отдельно не описывает; считать встроенным по семейству «2016 и новее» (PQS). Mac: 365 для Mac — есть; 2016 и 2019 для Mac — нет (прямая цитата PQA); 2021/2024 для Mac — не подтверждено. Web: ограниченный набор источников (PQS).
— **Data → Get Data** («Получить данные» (Данные → Получить данные / Get Data)): Название «Получить данные» — интерфейс современных сборок; в 2016/2019 группа называется «Получить и преобразовать данные» (Get & Transform Data, PQA). В 2007 есть только старые «Данные → Из Access/Web/Текста». Прямой источник на названия кнопок по версиям не найден.
— **Get Data → From File → From Folder** (Power Query: «Из папки» (коннектор Folder)): PQS: «Local folder» есть в колонках Office 2016/2019/365; «SharePoint Folder» — только Office 2019 Professional Plus Standalone и Microsoft 365 Apps for Enterprise. Mac: только обновление, не импорт. Web: только SharePoint-папки. Коннектор Folder: Excel, GA (FOLD). Для 2010/2013 состав коннекторов надстройки не проверялся.
— **Power Pivot / Data Model** (Power Pivot и модель данных): Зависит от редакции. Выдача поиска по PP (страница обновлена 08.01.2019): есть в Office 2013 Professional Plus и отдельном Excel 2013, Office 2016 Professional Plus (только корпоративное лицензирование), Office Professional 2019/2021 и Home&Business/Student 2019/2021 (по списку страницы), нет в Office 2016 Professional, Home&Student/Home&Business 2013 и 2016, Office 2013 Standard и Professional, для Mac. Для 2010 отдельная бесплатная надстройка — по ответам Microsoft Q&A (не официальная страница). 2024 и Microsoft 365: PP говорит «надстройка Excel и встроено в модель данных в современных версиях», редакции не перечислены. Страница при повторном открытии отдавала только вводный текст — список редакций сверять с ИТ.
— **VBA / macros** (VBA и макросы (.xlsm)): Наличие VBA в версиях отдельной страницей Microsoft не проверялось (в Applies To источника — только политики блокировки). Только если разрешат работодатель и ИТ.
— **Macros from the internet blocked by default** (Блокировка макросов из интернета (Mark of the Web)): Microsoft 365 Apps: по умолчанию с версии 2203 (Current Preview) / 2206 (Current Channel) / 2208 (Monthly Enterprise, Semi-Annual) на Windows. Для постоянных версий (Office LTSC 2021, Office 2019) страница описывает иной порядок проверки; значения по 2024 страница не называет. Mac, Android, iOS, веб не затронуты. Для 2007–2016 страница не говорит — в 2007–2016 действует обычная панель «Включить содержимое» (не источник, оценка). Файл из интернета: ПКМ → Свойства → «Разблокировать» либо доверенное расположение.
— **Excel tables** (Умные таблицы («Форматировать как таблицу», Ctrl+T)): Наличие таблиц с 2007 отдельной страницей Microsoft не проверено (косвенно: SL описывает срезы «для таблиц»).
— **Convert to Range** («Преобразовать в диапазон»): Отдельная страница Microsoft не открыта; считать доступным везде, где есть умные таблицы (не проверено).
— **Slicers (PivotTable)** (Срезы для сводных таблиц): SL: Applies To — 365, 365 Mac, web, 2024, 2024 Mac, 2021, 2021 Mac. Версия, в которой срезы появились (2010), страницей не названа. Web: только локальные сводные (SL).
— **Slicers (Table)** (Срезы для умных таблиц): W13 («Что нового в Excel 2013») — срезы для таблиц; в вебе срезы таблиц недоступны (SL).
— **Timeline** (Временная шкала для сводных): Версия 2013 как первая — по выдаче поиска к W13, страница целиком не перепроверялась. Mac и web не проверены.
— **Dynamic arrays, #SPILL!** (Динамические массивы и ошибка #ПЕРЕНОС! (#SPILL!)): DY перечисляет в Applies To и 2016/2019, но сама не называет версии; по FILTER/UNIQUE (FI, UN) 2019 и 2016 исключены, по алфавитному списку маркер (2021). Страницы Microsoft здесь расходятся — осторожный вывод: нет в 2019 и ранее. Русское имя ошибки #ПЕРЕНОС! — в источниках не проверено.
— **Flash Fill** (Мгновенное заполнение (Ctrl+E)): W13 называет Flash Fill функцией Excel 2013. Mac/web не проверены.
— **Python in Excel** (Python в Excel): Только Microsoft 365: Windows — Enterprise/Business с версии 2408 (Current Channel, сборка 17928.20114) и далее по каналам; Mac — 16.96; web — Business. Постоянные потребительские лицензии не поддерживаются; Excel 2021/2024 страница отдельно не называет (в Applies To их нет). Выполняется в облаке Microsoft — для рабочих данных бухгалтерии не использовать без решения работодателя.
— **COPILOT function** (Copilot в Excel: функция COPILOT): Была в предварительной версии только для Microsoft 365; с 14.09.2026 функция недоступна (после пересчёта #ИМЯ?/#NAME?). Microsoft рекомендует панель Copilot. Облачный ИИ; не для рабочих данных без решения работодателя.
— **SUMIFS** (СУММЕСЛИМН): Маркера на странице нет (функция ранее 2010); введена в 2007 — по самой странице не проверялось. Аналог в 2003: СУММПРОИЗВ.
— **COUNTIFS** (СЧЁТЕСЛИМН): Маркера нет; см. SUMIFS. На странице ru — «СЧЁТЕСЛИМН» (с Ё).
— **AVERAGEIFS** (СРЗНАЧЕСЛИМН): Маркера нет; см. SUMIFS.
— **IFERROR** (ЕСЛИОШИБКА): Маркера нет; введена в 2007 (не проверялось страницей).
— **IFNA** (ЕСНД (на ru-странице: «ИСНД»)): Маркер (2013). РАСХОЖДЕНИЕ: ru-страница Microsoft пишет ИСНД, в русском интерфейсе Excel известна форма ЕСНД — написание в программе не проверено, сверить в «Мастере функций». Mac: функции с маркером года есть в Mac-версии того же года и новее (Microsoft: Applies To включает 2021/2024 для Mac и Microsoft 365 для Mac); точную сборку Mac проверять по «О программе».

## Русские имена и расхождения написаний (ru-ru, алфавитный список функций)

— ПРОСМОТРX и ПОИСКПОЗX: в заголовке и списке последняя буква латинская X (проверено по коду символа в HTML страницы); в примере синтаксиса на странице функции встречается кириллическая Х. Вводить имя через Мастер функций или автодополнение.
— IFNA на странице пишется ИСНД, в брифе принято ЕСНД; в программе не проверено.
— SWITCH на странице: ПЕРЕКЛЮЧАТЕЛЬ; в брифе ПЕРЕКЛЮЧ — не подтверждено источником.
— MAXIFS/MINIFS: МАКСЕСЛИМН/МИНЕСЛИМН (не МАКСЕСЛИ).
— NUMBERVALUE: на странице ЧИСЛОЗНАЧЬТЕ; ЧЗНАЧ из брифа в источнике не найдено.
— GROUPBY: на странице ГРУПППО (три П).
— UNIQUE и LET на ru-странице без русского имени; УНИК из брифа источником не подтверждён.
— COPILOT: в алфавитном списке нет; русское имя не найдено.

## Как узнать свою версию и сборку Excel

Источник: https://support.microsoft.com/en-us/office/what-version-of-office-am-i-using-d21c5935-40b1-b117-122d-5e5f05a1a263 (Applies To: Office 2024/2021, в т. ч. Mac, Microsoft 365 для дома; проверено 27.11.2026).

— Excel 2013 и новее (Windows): «Файл → Учётная запись» (если пункта нет — «Файл → Справка»); название продукта — в «Сведения о продукте»; «О программе Excel» показывает полный номер версии, сборку и разрядность 32/64 бит (так сказано в выдаче Microsoft по этой странице; страница целиком для 2013/2016/2019 не описывает шаги).
— Excel для Mac: меню приложения → «О программе Excel» (источник: та же страница, раздел Mac).
— Excel 2010: «Файл → Справка» — путь из брифа, **не подтверждён** (страница Microsoft по 2010 не открыта). Если нет ни «Файл → Учётная запись», ни «Файл → Справка», версия более старая (формулировка Microsoft).
— Excel 2007: кнопка Office → «Параметры Excel» → «Ресурсы» → «О программе» — путь из брифа, **не подтверждён** (официальная страница не найдена). Признак: круглая кнопка Office вместо вкладки «Файл».
— Что запросить у учащейся: читаемый скриншот «Файл → Учётная запись → О программе Excel», версию Windows, вкладку «Данные» (есть ли группа «Получить и преобразовать данные» или «Получить данные»), решение ИТ по установке и обновлению.

## Что выбрать для автоматизации по версии

Правило: маршрут «installed» выбирать только после подтверждения версии; обновление не обязательно.

— **Версия неизвестна** — conservative: СУММЕСЛИМН, СЧЁТЕСЛИМН, СРЗНАЧЕСЛИМН, ЕСЛИОШИБКА, ВПР/ИНДЕКС+ПОИСКПОЗ, вспомогательные столбцы, умные таблицы, сводные, ручной импорт. Маркера года у этих функций нет (https://support.microsoft.com/en-us/office/excel-functions-alphabetical-b3944572-255d-4efb-bb96-c6d90033e188); введение в 2007 страницей не проверено.
— **Excel 2007** — только conservative (формулы и сводные). Power Query для 2007 не упомянут (https://support.microsoft.com/en-us/office/about-power-query-in-excel-7104fbee-9e62-4cb9-a02e-5bfb1a6c536a); срезы, ЕСНД, ЕСЛИМН, ПРОСМОТРX, динамические массивы недоступны (таблица 1).
— **Excel 2010 и 2013** — conservative плюс Power Query как бесплатная надстройка, только если разрешит администратор. Microsoft объявила надстройку устаревшей летом 2019 (может работать, но не гарантировано) (https://support.microsoft.com/en-us/office/about-power-query-in-excel-7104fbee-9e62-4cb9-a02e-5bfb1a6c536a). В 2013 добавляются IFNA, NUMBERVALUE (https://support.microsoft.com/en-us/office/excel-functions-alphabetical-b3944572-255d-4efb-bb96-c6d90033e188), срезы таблиц, временная шкала, мгновенное заполнение (https://support.microsoft.com/en-us/office/what-s-new-in-excel-2013-1cbc42cd-bfaf-43d7-9031-5688ef1392fd).
— **Excel 2016** — встроенный Power Query в Windows (https://support.microsoft.com/en-us/office/about-power-query-in-excel-7104fbee-9e62-4cb9-a02e-5bfb1a6c536a); состав коннекторов зависит от редакции (https://support.microsoft.com/office/power-query-data-sources-in-excel-versions-e9332067-8e49-46fc-97ff-f2e1bfa0cb16). Функций ЕСЛИМН, МАКСЕСЛИМН, ОБЪЕДИНИТЬ, СЦЕП нет (маркер 2019, https://support.microsoft.com/en-us/office/excel-functions-alphabetical-b3944572-255d-4efb-bb96-c6d90033e188).
— **Excel 2019** — плюс ЕСЛИМН, ПЕРЕКЛЮЧАТЕЛЬ, МАКСЕСЛИМН, МИНЕСЛИМН, ОБЪЕДИНИТЬ, СЦЕП; нет ПРОСМОТРX, ФИЛЬТР, УНИК, СОРТ, динамических массивов (https://support.microsoft.com/ru-ru/office/%D1%84%D1%83%D0%BD%D0%BA%D1%86%D0%B8%D0%B8-excel-%D0%BF%D0%BE-%D0%B0%D0%BB%D1%84%D0%B0%D0%B2%D0%B8%D1%82%D1%83-b3944572-255d-4efb-bb96-c6d90033e188, https://support.microsoft.com/en-us/office/filter-function-f4f7cb66-82eb-4767-8f7c-4877ad80c759).
— **Excel 2021** — плюс динамические массивы, ПРОСМОТРX, ФИЛЬТР, УНИК, СОРТ, СОРТПО, ПОСЛЕД, LET (маркер 2021, https://support.microsoft.com/ru-ru/office/%D1%84%D1%83%D0%BD%D0%BA%D1%86%D0%B8%D0%B8-excel-%D0%BF%D0%BE-%D0%B0%D0%BB%D1%84%D0%B0%D0%B2%D0%B8%D1%82%D1%83-b3944572-255d-4efb-bb96-c6d90033e188); ещё нет ЛЯМБДА, ТЕКСТДО/ТЕКСТПОСЛЕ/ТЕКСТРАЗД и других с маркером 2024.

## Русские имена функций: в уроках и на страницах Microsoft

Русские справочные страницы Microsoft местами переведены машинно, и имена в них не совпадают с тем, что пишется в ячейке русского Excel. В уроках курса используем имена из интерфейса, а вариант со страницы даём только как пометку:

| В уроках (интерфейс русского Excel) | Англ. | Встречается на странице Microsoft |
|---|---|---|
| ЕСНД | IFNA | ИСНД |
| ПЕРЕКЛЮЧ | SWITCH | ПЕРЕКЛЮЧАТЕЛЬ |
| МАКСЕСЛИ / МИНЕСЛИ | MAXIFS / MINIFS | МАКСЕСЛИМН / МИНЕСЛИМН |
| ЧЗНАЧ | NUMBERVALUE | ЧИСЛОЗНАЧЬТЕ |
| ПРОСМОТРX, ПОИСКПОЗX (латинская X) | XLOOKUP, XMATCH | в примерах встречается кириллическая Х |

Статус: имена «в уроках» основаны на знаниях автора курса, а не на открытой странице. В живом русском Excel они **не проверены**. Пусть учащаяся сверит их по подсказке при вводе `=` и первых букв. Если в её Excel имя другое, урок исправляется.
