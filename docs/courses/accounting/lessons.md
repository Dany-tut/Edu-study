## Открытые вопросы из уроков (465)

- №6 «Месячные отчёты: пакет документов за месяц»: Состав «пакета месяца» — организационное решение бухгалтера. Сроки сдачи отчётности и налогов в уроке не приводятся: их надо брать из налогового календаря и законодательства на дату отчётности.
- №7 «Шаблоны и справочники»: Путь «Файл → Сохранить как → тип Шаблон Excel (*.xltx)» известен автору из практики; страницу Microsoft о шаблонах Excel в этой версии курса открыть не удалось. Проверить.
- №8 «Резервное копирование»: Защита и локализация персональных данных при хранении копий в облаке — вопрос политики вашей организации и права; в курсе не разбирается. Уточните у специалиста.
- №8 «Резервное копирование»: Резервное копирование баз 1С — отдельная тема модуля про 1С (не здесь).
- №9 «История изменений и версии файла»: Срок хранения и число версий зависят от типа учётной записи и настроек администратора; цифры из справки Microsoft приведены на дату проверки.
- №10 «Горячие клавиши Windows и работа с несколькими окнами»: У Win+Z справка Microsoft даёт два разных описания (макеты привязки и команды приложения в полноэкранном режиме); проверьте на своём компьютере.
- №11 «Поиск файлов в Windows»: Расширенный синтаксис запросов Windows Search (например, фильтры по дате в строке поиска) в этой версии курса не проверялся.
- №12 «Пакетное переименование файлов»: Шаблон с точками в дате (Выписка (\d{2})\.(\d{2})\.(\d{4}) → $3-$2-$1_Альфа_Выписка) адаптирован из примера справки Microsoft с дефисами и проверен логически, но не на живой утилите PowerRename: проверить на ПК с PowerToys до публикации.

- №13 «PDF и архивы: как сохранить и отправить»: Объединение и разделение PDF встроенными средствами Windows в курсе не разбирается: официальной инструкции Microsoft найти не удалось. Если нужно, используйте проверенную программу и политику организации.
- №13 «PDF и архивы: как сохранить и отправить»: Шифрование ZIP-архивов в Windows 11 24H2 не поддерживается встроенными средствами (по справке Microsoft); сторонние программы — по решению организации.
