# Адресный снимок перед заведением acc-ru (25.11.2026)

Курс добавляет только новые строки (`short_id like 'acc-ru%'`), существующие не меняются. Поэтому копия строк не делалась. Сняты только число строк и контрольная сумма ключевых полей — одним лёгким запросом на таблицу, без выгрузки содержимого.

| Таблица | Строк | md5 ключевых полей |
|---|---|---|
| courses (id, short_id, status, title) | 46 | e2ea4d511afd9ba65000dbdc2559c4a6 |
| course_modules (id, course_id, label, position) | 167 | 634f2fee8900560bb68df5a1e9f216ff |
| lessons (id, short_id, course_id, module_id, position) | 2112 | fdd7fbd329e6132207c346be822e3081 |
| строки acc-ru до записи | 0 | — |

Проверка после записи: тот же запрос с условием `short_id not like 'acc-ru%'` (а для модулей — по курсам, кроме `acc-ru`) должен дать те же числа и те же суммы.

Полный снимок `backupProductData.py` НЕ запускать на рабочей базе: 25.11 в 21:51 он совпал с падением прода — база не принимала подключения с 21:54 до ~22:00. Скрипт тянет каждую таблицу целиком через `jsonb_agg`.

Видимость по RLS (`read_all_courses`: `is_admin()` или `my_course_ids()`): владелец (`created_by`) и администраторы. У других учителей нет общего доступа (`course_shares`), а у учеников — записи на курс, поэтому они курс не видят.

Пока код курса не выпущен в `main`, в приложении у курса видна только структура: модули и названия уроков. Конспекты, домашки и файлы для скачивания лежат в коде ветки и появятся после выпуска.
