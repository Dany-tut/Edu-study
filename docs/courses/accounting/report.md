# Курс «Бухгалтерия» в Искре — отчёт о сдаче

Дата: 25.11.2026. Ветка: `claude/course-accounting-793ba9`. Статус: **черновик на локальном стенде.** В `main` и в продовую базу Supabase ничего не выпущено, SQL каталога не применён.

## 1. Что сделано

- Курс «Бухгалтерия: Excel, 1С и закон на практике» (`acc-ru`): вводный модуль и 21 модуль ТЗ.
  - **188 уроков, 994 проверочных вопроса, 212 схем.** Справочник по рабочим вопросам собирается автоматически.
  - **8 скачиваемых учебных файлов** — таблица в разделе 4.
- **Полнота: 332 из 332 обязательных тем ТЗ** закрыты уроками, а не заголовками. Матрица «тема → урок»: [coverage.md](coverage.md), сводка по модулям: [modules.md](modules.md).
- **Исходные материалы пакета сохранены:**
  - все 34 урока пособия вошли в курс, их шаги и формулы перенесены дословно (проверено скриптом);
  - все 34 исходных вопроса стоят первыми в домашке своего урока;
  - практикум извлечён из пакета, SHA-256 совпал.
- **Устройство каждого урока соответствует ТЗ:** вопрос из работы → результат → программа и версия → пример → шаги по одному действию → формула моноширинным шрифтом с кнопкой «Копировать» → почему работает → было/стало → типичные ошибки → подсказка → эталон → автоматизация → готовый промпт для ИИ → источники с датой проверки. Домашка в каждом уроке — 4–7 вопросов разных типов с объяснениями и практическое задание с критериями проверки.
- **Урок №1 — знакомство:** платформа и как задавать вопросы; шесть открытых вопросов ученику уходят преподавателю на проверку: реестр, версия 1С и банк, правила численности, Excel, организации и режимы. Фото — через «Обратную связь».
- **В каждом уроке** в конце конспекта — «Вопрос или комментарий к уроку». Используется существующая форма Искры «Обратная связь»: свой раздел «Бухгалтерия, урок №N», текст, скриншоты. Новых компонентов не понадобилось.
- **Где лежат ответы и комментарии ученика** (таблицы, поля, SQL): [student-answers.md](student-answers.md).
- **Решения Дани от 25.11 учтены:**
  - курс рассчитан на практика: модули основ помечены как справочные, во вводном уроке есть маршрут «с чего начать»;
  - проводки даны в двух вариантах: основной без НДС и рядом «Вариант с НДС» по ставке 22% (такие блоки есть в 38 местах курса);
  - непроверенные пути 1С ученик сверяет у себя и присылает в практическом задании вместе с релизом;
  - файлы используются как домашка: например, заполненный чек-лист закрытия месяца.

## 3. Реальные кейсы сестры Дани

**Отчёт по численности в нескольких организациях** — модуль EXP14, серия из 9 уроков:
- человек, запись и ставка — разные вещи; ФИО — только кандидат на совпадение, нужен подтверждённый ID;
- правила ОСН/СОВ/ДЕКРЕТ; почему максимальная ставка не равна основному месту;
- формулы и статус «Проверить»;
- итоги по организациям и по группе;
- раздельные показатели: записи, уникальные люди, распределённая численность, сумма ставок, списочная и среднесписочная численность по Указаниям к форме П-4 (приказ Росстата от 17.11.2025 № 638);
- организации, приславшие только итоги;
- Power Query с журналом ошибок;
- промпт для ИИ;
- 10 тестовых случаев.

К серии прилагается шаблон `chislennost-shablon.xlsx`: формулы в строках 2–4001, протягивать не нужно; 63 эталона, пересчитанных в Excel для Mac, — все OK. Эталоны пособия пересчитаны независимо: 10 записей, 7 ID, 5,25 ставки, учтено 5, на проверке 2.

**Реестр выплат самозанятым не проводится** — модуль EXP13, 10 уроков:
- 9 этапов: создание → заполнение → запись → проведение → выгрузка/отправка → приём банком → выписка → «Оплачено» → чеки;
- дерево диагностики «этап → что проверить → если не так»;
- задания «найди этап по симптому» и тренажёр из 5 учебных ситуаций;
- изменения по релизам 1С до 3.0.212: с 3.0.176 нет отдельного вида контрагента «Самозанятый»; через ДиректБанк реестр принимает только Бланк-Банк, со Сбербанком — выгрузка файлом.

Шаблон `samozanyatye-kontrol.xlsx` проверяет статус НПД на дату выплаты, чек, совпадение сумм, повторную оплату и признак «бывший работник».

Ни один урок не предписывает менять проводки или платить повторно без проверки. Чтобы указать точную ветку дерева, нужны релиз 1С, банк и текст ошибки (вопросы в разделе 7).

## 8. Требования к площадке курсов

Переданы через общую папку заметок; сами система продаж, оплата и каталог не строились.
- **Публичная карточка курса:**
  - название, описание, 22 модуля, 188 уроков;
  - для кого: практикующий бухгалтер;
  - что внутри: 8 файлов, справочник;
  - бесплатный вводный урок — у конкурентов это работает.
- **Доступ по покупке** к курсу `acc-ru` для покупателя-ученика. Сейчас ученик видит курс только после записи (`course_enrollments`) и при статусе `published`.
- **Версия и дата проверки курса:** нормы меняются; нужен признак «проверено на дату» и уведомление купившим об обновлении уроков. Метаданные для этого уже есть в коде уроков.
- **Загрузка файла (XLSX) в ответ на практическое задание.** Сейчас в домашке есть текст, фото и доска. Решение Дани: «присылать заполненные файлы как домашку».
- **Увеличение схем в конспекте.** Схемы шириной 640 на телефоне 375 мелкие; в спецификации курса это требование.
- **Поиск по справочнику прямо в приложении.** Сейчас справочник — урок курса и отдельная страница. Экран поиска внутри Искры — новый экран: ему нужен концепт на 4 платформы × 2 темы.
- **Проверка практических заданий преподавателем или ИИ:** конкуренты продают именно ручную проверку.
- **Песочница 1С** (облачная учебная база) — у Skillbox есть, у нас 1С-практика опирается на учебную версию ученика.

## 9. Как завести курс в базу (только после согласия Дани)

1. Показать курс на стенде: `npx vite --port 5187` в рабочей копии → `http://localhost:5187/dev-accounting.html`.
2. Применить [catalog.sql](catalog.sql): курс `acc-ru` в статусе `draft`, 22 модуля, 188 уроков. Скрипт идемпотентный, откат описан в шапке файла.
3. Перед этим: снимок затронутых таблиц по `docs/data-preservation.md`.
4. Курс не трогает чужие данные: только новые строки с `short_id like 'acc-ru%'`.
5. Порядок уроков после заведения в базу не менять: short_id = индекс.
6. Чтобы курс попал на витрину площадки (ветка `claude/course-marketplace-0cc252`, коммит 004637df, тоже ждёт согласия Дани), строка `acc-ru` в `courses` должна стать `published`, а карточку заполняет автор или админ в «Витрине курсов». Бесплатный вводный модуль — через `preview_module_ids`, дата «проверено на» — `course_listings.content_checked_on`. Уведомление купившим, XLSX в ответ на ДЗ, увеличение схем, поиск по справочнику, платная проверка практики и облачная 1С — отдельные задачи площадки (docs/analysis/course-marketplace-2026-11-25.md, §9).
