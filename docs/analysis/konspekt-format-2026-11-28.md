## 2. Какой у Искры стиль — и какой у конспекта уже есть

**Общий язык Искры:** спокойная рабочая поверхность, нейтральные графитовые фоны
(`#F5F5F6` / `#111113`), карточки-поверхности с мягкой тенью `--shadow-2` и радиусом 24,
фиолетовый = фокус и «сейчас», цвет статуса — парой «мягкий фон + контрастный текст»,
иерархия размером и весом (без капслока у длинных заголовков), один главный CTA на
карточку, таблетки 999, SF Pro.

**Язык карточек внутри конспекта уже сложился** — три компонента сделаны одинаково:

| | «Проверка себя» (`AnswerReveal`) | «Вопрос по уроку» (`LessonAskCard`) | Алерт (`Alert`) |
|---|---|---|---|
| Карточка | `bg-2`, рамка `border-soft`, r16 | `bg-2`, рамка в тон акцента 28 %, r16 | `surface` + `shadow-pill`, r16 |
| Значок | плитка 32×32, r10, `accent-soft` + иконка `accent` | то же | плитка 30×30 тона |
| Текст | заголовок 14/600, подсказка 12 muted, lh 1.35 | 14/600 + 13 text-2 + 12 muted | жирный + приглушённый |
| Действие | таблетка справа 32, рамка, «Показать ⌄» | таблетка 34 `accent-soft` «Задать вопрос» | одна таблетка `--grad-purple` |

Это и есть образец для выносок: **плитка-значок тона слева + карточка без заливки
тоном + таблетка-действие справа**. Новые «Подсказка», «Не путайте», «Ошибка →
исправление» должны быть родственниками этих трёх, а не новым стилем.

**Чего у конспекта нет (расхождения со своей же системой):**

- Колонка во всю карточку (~1750 px), хотя у Искры есть `reading 720`, а схемы
  конспекта уже рисуются листом 680 px (`FIGURE_W`). Текст шире своих же схем в 2,5 раза.
- Кегль 15 и «Крупный» ×1.6 = 24 px: при текущей ширине крупный текст не спасает
  читаемость — строка просто становится длиннее на экране.
- Жирное лид-слово — единственный уровень иерархии. Заголовков H3 нет.
- Формулы: блок (r 0.65em, кнопка всегда видна) и чип (клик без иконки) — два поведения.
- «Подсказка.» (132 раза в курсе), «Не путайте…», «Типичные ошибки.» — обычные абзацы.

## 3. Что взять у других (кратко)

- **Таскли** (`SMMSelectableText.swift`, `NoteEditor.swift`): сущности как в Telegram
  (жирный, курсив, подчёркнутый, зачёркнутый, моно, спойлер «пылью», раскрываемая
  цитата, ссылки) + markdown-заметки (H1–H3, цитата, маркеры, нумерация, чекбоксы,
  черта). Блок кода — **лавандовая подложка в тон бренда, круглая кнопка копирования
  у первой строки, видна всегда**. Это совпадает с нынешним блоком формулы Искры — его
  берём за единый образец.
- **Telegram:** моно-вставка копируется тапом с тостом «Скопировано» — привычно; блок
  `pre` — шапка + «Копировать».
- **Claude / ChatGPT / Codex:** колонка ответа ~680–760 px при любом окне; заголовки
  вместо жирных лид-слов; блок кода с шапкой и копированием; таблицы в рамке с
  прокруткой. Широкие вещи шире текста.
- **Notion / Stripe Docs / Практикум:** выноски с иконкой, нумерованные шаги кружками,
  оглавление сбоку на широком экране, ответ «под спойлером». **Полосу слева у выноски
  не берём** (AI-01).

## 4. Выводы для системы конспекта

1. **Колонка текста = `40em`** (640 px при 16 px ≈ 70 знаков кириллицы), в `em` —
   растёт с «Крупным текстом», мера сохраняется. Совпадает с `reading 720` за вычетом
   полей и с листом схем 680.
2. **Широкие блоки** (таблица, схема, реконструкция Excel) — до 680–900 px по центру
   колонки; на телефоне во всю ширину, шире — прокрутка с фейдом/SoftEdge.
3. **Кегль прозы 16** (iPhone 17), lh 1.6; «Крупный» оставить ×1.6 или снизить до ×1.25
   — вопрос Дани (×1.6 при новой колонке даст 25 px и ~38 знаков в строке).
4. **Одно поведение копирования:** любая формула (блок и чип) — клик по ней копирует,
   иконка «Копировать» видна всегда, после — галочка «Скопировано». Пара RU/EN —
   один компонент (переключатель или две строки — выбор Дани).
5. **Выноски по образцу AnswerReveal/Alert:** карточка `bg-2` + плитка тона 32/r10;
   без заливки тоном и без полосы слева.
6. **Иерархия:** лид «Вопрос из работы» крупно; разделы — H3 18/600 вместо жирного
   лид-слова; шаги — нумерованные кружки.
7. **Без правки 335 уроков:** тип блока узнаётся по `p.id` и лид-слову (стабильны:
   «Вопрос из работы.» ×284, «Типичные ошибки.» ×277, «Почему работает.» ×214,
   «Быстрее с ИИ.» ×212, «Шаг 1.» ×209, «Подсказка.» ×132 …), пара формул — по строке
   «Англ.: `…`», ошибки — по «— … Исправление: …». Неизвестное — обычный абзац.
   Конспект общий для всех курсов (языки идут через `GlossedText`) — им ничего не ломать.
8. **По платформам:** ПК — колонка + оглавление справа на ≥1280; iPad — колонка,
   управление конспектом в капсуле справа; iPhone — 16 px поля, стеклянная шапка,
   SoftEdge; Android — таблетки с заливкой, фейды.
