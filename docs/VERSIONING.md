# Версия сборки на экране

Между «коммит ушёл» и «обнова доехала до телефона» стоит очередь: сборка на
хостинге → http-кеш → service worker → иконка PWA на домашнем экране. Любое
звено может отстать, и внешне это неотличимо от «фича не сделана». Поэтому
номер сборки виден в интерфейсе, а рядом — что лежит на сервере.

## Как устроено

Номер сборки = **порядковый номер коммита** (`git rev-list --count HEAD`).
Версия показывается как `1.0.<номер>`, рядом — короткий хеш коммита.

1. **Хук `.githooks/pre-commit`** перед каждым коммитом пишет
   `public/version.json` (`node scripts/stampVersion.mjs --next --stage`) и
   кладёт файл в этот же коммит. То есть номер едет ВНУТРИ коммита.
2. **Сборка** (`vite.config.ts`) читает этот файл и вшивает в бандл константы
   `__APP_BUILD__`, `__APP_COMMIT__`, `__APP_VERSION__`. Git при сборке не
   нужен — на Vercel клон мелкий, и `rev-list --count` соврал бы.
3. **`public/version.json` попадает в `dist` корнем** и отдаётся по
   `/version.json`. Приложение тянет его с `cache: 'no-store'` и сравнивает
   число с вшитым: `remote.build > APP_BUILD` → есть обновление.
4. **Строка версии** (`src/components/AppVersionRow.tsx`) стоит в профиле
   ученика и учителя (моб.) и в меню аватара на десктопе. Тап = проверить;
   если обновление есть — тап сносит service worker со всеми кешами и
   перезагружает страницу.

## Что нужно сделать один раз на новой машине

```bash
git config core.hooksPath .githooks
```

Без этого хук не сработает и номер застынет (сборка возьмёт старое число из
файла). Проверить руками: `npm run stamp`.

## Нюансы

- `git commit --amend` сдвигает номер ещё на единицу: коммит уже в HEAD, а хук
  снова прибавляет 1. Номер остаётся уникальным и растущим — этого достаточно.
- `git commit --no-verify` пропускает хук: номер не изменится, и на экране будет
  версия предыдущего коммита.
- Параллельные сессии в одном репозитории иногда дают конфликт в
  `public/version.json`. Лечится в одну строку: `npm run stamp` поверх и
  `git add public/version.json`.
- В нативной обёртке (Capacitor) `/version.json` лежит в бандле и сравнивается
  сам с собой. Чтобы сравнение работало, задайте при сборке
  `VITE_VERSION_URL=https://<прод>/version.json`.
