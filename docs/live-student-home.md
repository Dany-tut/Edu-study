# Главная ученика с реальными данными

Обычный `#/` кабинета ученика открывает `StudentHome` на компьютере и телефоне.
Экспериментальный флаг `home_redesign` больше не подменяет эту главную старым
концептом. Демонстрационный `/student-track-stand` не является источником данных.

Расписание и трек читают текущие session-scoped stores. Две первые карточки
карусели используют тот же `useStudentDiaryMetadata` и `buildStudentDiary`, что
и дневник. Срок берётся только из выданной работы; даты занятий не создают долг.
Работы без срока не просрочены, отправленные/принятые не требуют повторной сдачи.
Кнопки открывают существующие экраны реального урока, теста или ДЗ; дополнительные
домашки сохраняют свой `hwRef`. Назначенные диагностические тесты доступны отдельной
кнопкой в шапке. Остальные настроенные виджеты остаются в карусели.

В цепочке модулей показаны долги только выбранного курса. Нажатие счётчика
открывает список над главной. Полные списки работ также открываются в `Modal`.

Кнопка «Оформление главной» переключает три хэллоуинские темы и обычный вид.
Это личная настройка браузера, а не изменение `app_seasons` школы; можно выбирать
тему и после окончания автоматического сезона. Ссылки `/?halloween=candy#/`,
`/?halloween=lanterns#/`, `/?halloween=potions#/` делают тот же явный личный выбор
и сохраняют обычную авторизацию кабинета. Новые таблицы и RLS не требуются.

Проверки: `npm run check:student-home`, `npm run check:ui`, `npm run check:i18n`,
`npx tsc --noEmit`, `npm run build`, затем `npm run release:check` и CI точного SHA.
Визуальная матрица: три темы, телефон 320/390px, низкое/обычное окно десктопа,
короткое и длинное расписание, длинный трек, начало/середина/конец прокрутки,
выбор занятий, открытие урока/ДЗ, смена курса, пустое/загружаемое/ошибочное состояние.

Если локальные тяжёлые проверки ограничены нагрузкой Mac, тот же чистый
preflight можно выполнить в GitHub Actions: `gh workflow run ci.yml --ref
<ветка-кандидат> -f release_preflight=true`. Он запускает `npm run release:check`
перед обычными типами, сторожами и сборкой; проверяется точный SHA кандидата.
