# Временное наполнение личного профиля

На основном сайте `?demo=danil#/` включает расширенный учебный пример для текущего
профиля «Даниил Макаренко» / «Данил Макаренко». Включение привязывается к точному
ID выбранного ученика и сохраняется в localStorage этого браузера на семь дней.
Параметр убирается из адреса; при обычном обновлении наполнение остаётся.
Другие профили и браузеры автоматически его не получают. Это режим отображения
с вымышленными данными, а не механизм серверной авторизации.

`?demo=off#/` отключает его и возвращает настоящие курсы и расписание.
В базу не создаются ни курсы, ни уроки, ни сдачи из примера. Ответы и результаты
демонстрационных работ хранятся в браузере под отдельным ключом профиля.
Все ссылки на занятия имеют префикс `personal-demo-`; общий transport Supabase
перехватывает их до сети, включая записи из уже открытой работы после отключения.
Обычные запросы других профилей проходят как раньше.

Набор: четыре курса, 128 занятий, 61 день по три занятия, 16 тестов по восемь
вопросов, 112 домашних работ по восемь базовых и одному сложному заданию,
дополнительная практика. Сезонное оформление этот режим не меняет.

Проверка изоляции, срока действия, данных и локальных результатов:
`node scripts/checkPersonalStudentDemo.mjs`.

Для удаления реализации достаточно убрать personalStudentDemo, набор данных,
ветку в studentDataStore, перехват в teacherView и локальное сохранение фото.
