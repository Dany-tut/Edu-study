Статус: концепт 24.11.2026. Направление выбрано Даней: награды (см. ниже). Прототип в ветке `claude/isk4-scratch-1b7b44`, в `main` не выкатывался.
Макет: `design/scratch-reveal/concept.html` (ПК, iPad, iPhone, Android × светлая/тёмная, стирание работает).

## Что есть сейчас
Конструктор заданий — единый реестр `src/data/taskTypes.ts` (33 типа). Скретч-механики нет нигде.
Ближе всего к ней самооценка `flashcard` («помнил / не помнил»).

## Варианты, где это живёт
- **A. Тип задания «Стереть и проверить»** (рекомендую). Вопрос и скрытый ответ (текст или картинка).
  Ученик вспоминает, стирает, отмечает «знал / не знал». На балл не влияет, учитель видит отметку.
  Встраивается по чек-листу реестра: `TaskTypeId`, `TASK_TYPES`, `TYPE_VISUALS`, Editor/Solver, `TASK_TYPE_PREVIEWS`.
- **B. Слой «спрятать под стирание»** у подсказки, ответа или фрагмента конспекта в уроке.
- **C. Сюрприз после сдачи ДЗ**: стереть, чтобы увидеть балл или стикер.

## Поведение (для A)
- Canvas-фольга, `destination-out`. Слой сходит при 55 % стёртого, исчезает за 0,35 с. Лёгкая вибрация на телефонах.
- Кнопка «Открыть» есть всегда: для клавиатуры, для тех, кому неудобно тереть, и потому что на iPad нельзя прятать действие за ховер.
- `touch-action:none` только внутри зоны: страница при стирании не листается, фейды не меняются.
- Состояние «открыто» и самооценка сохраняются в попытке. После F5 фольга не возвращается.

## Что нужно от Дани
Выбрать A, B или C (можно «A сейчас, C позже»). После выбора — согласовать рамки по платформам, затем реализация по `docs/pipeline.md`.

## Прототип для тестовой сборки
- Стенд `src/components/scratchStand/ScratchStand.tsx`, три сценария: подарок учителя, стикер за сданное ДЗ, промокод. Без сервера, без записей в базу, промокод ненастоящий.
- DEV: `npm run dev` → `/#/scratch-stand`.
- Тестовая сборка: `VITE_SCRATCH_PREVIEW=1 npm run build` → прототип открывается сразу при запуске, «В приложение» уводит в обычный кабинет до следующего холодного старта. Без флага (прод) кода стенда в бандле нет.
- Кадры: `impl/`.

## Внедрено в продукт (24.11.2026, ветка `claude/isk4-scratch-1b7b44`, не в `main`)
- **Подарок учителя** (`season/stickers/TeacherGift.tsx`): вместо коробки — фольга. «Подарок от учителя» над ней, стикер и медаль под ней; имя, подпись и ачивка раскрываются плавно после стирания. В подвале до стирания «Потом» (подарок ждёт следующего захода), после — «В альбом» / «Спасибо!». В базу «просмотрен» пишется только после стирания.
- **Новые стикеры за ДЗ и видео** (`StickerAlbum.tsx`, `StickerToast.tsx`): всплывашка «Новый стикер!» показывает фольгу вместо картинки («Какой?»). В альбоме новый стикер запечатан: плитка фольги в сетке, фольга во всю карточку в подробностях (ПК/iPad) или над плашкой (телефон). `seen_at` пишется при стирании, а не при открытии альбома.
- Фольга помечена `data-sheet-nodrag`: стирание не тянет и не закрывает лист на телефоне.
- `markStickersSeen` не пишет в базу DEV-стикеры (`dev-…`); `devFakeSticker` доступен и в тестовой сборке с `VITE_SCRATCH_PREVIEW=1`.
- Стенд `/#/scratch-stand` теперь показывает настоящие окна (подарок, всплывашка, альбом) на стикерах только во вкладке. Промокод — карточка-концепт, отложен.
- Миграций нет: используются существующие `season_stickers.seen_at`.
