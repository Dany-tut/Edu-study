# Искра · новая система виджетов

Предложение для 19 самостоятельных виджетов преподавателя. 54 полезные клеточные компоновки; источники, поля, текущие действия и предлагаемые изменения описаны в `catalog.ts`.

## Открыть

Из корня репозитория: `npm run dev -- --port 5256`, затем `/design/widget-redesign-review/index.html`. Ни авторизация, ни соединение с базой не нужны.

Для автономного HTML, JSON-контрактов и спецификации: `node design/widget-redesign-review/export.mjs /absolute/output/path`. Все рисунки и скрипты вшиты в HTML; CDN не используется.

## Состав

- `catalog.ts` — разрешённые пары размеров и контракт каждого текущего виджета.
- `main.tsx` — концепт компоновок, галерея, матрица, состояния, три базовых стола.
- `style.css` — единые отступы и типографика, темы, референсные карточки.
- `export.mjs` — автономный экспорт + проверки: 19 уникальных известных registry-id, целые клетки, метрики высотой 1, запрет низкого календаря.
- `widget-redesign-spec.md` — полный документ для реализации.
- `QA.md` — фактически выполненная проверка и её границы.

Это отдельный концепт: действия имитируются локально, существующий UI и production не меняются. Предлагаемые переименования, переходы и исправления фильтров явно описаны в контрактах; формулы рабочего приложения не переписываются этим стендом.
