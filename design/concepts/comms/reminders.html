Напоминания ученикуКонцепт 4 · Telegram и пуш · тихие часы

Правила один раз Вариант A

Учитель один раз включает четыре правила, и дальше всё уходит само. Он не видит отдельных сообщений, только правило, превью и долю учеников, подключивших Telegram. Ученик подключается одной кнопкой: ссылка-приглашение открывает бота уже «узнавшим» ученика.

Очередь «что уйдёт» Вариант B

Учитель видит конкретные сообщения: что, кому и когда уйдёт сегодня и завтра. Любое можно снять или поправить. На телефоне очередь встроена в «Мой день», в карточку занятия. Ученик подключается кодом из четырёх цифр и сам решает, что и куда ему присылать.

Итог: правила + «что уйдёт» на главной Выбран

Настраивает учитель один раз, как в A: четыре правила, тихие часы, подключение. А в повседневной работе он видит отправку там, где и так смотрит: строка «В 16:00 напомним 6 ученикам» под занятием в «Моём дне» и в виджете «Расписание» на главной ПК. Главная — настраиваемый стол: «Связь с учениками», «Отчёты родителям» и «Оплаты: ждут вас» — новые виджеты из библиотеки, учитель сам решает, ставить ли их; строки в расписании выключаются одной кнопкой. На телефоне те же блоки включаются и переставляются в «Настроить „Мой день“». Снять одно напоминание можно прямо из занятия. Ученик подключается кнопкой; если Telegram на другом устройстве — кодом.

Пуш — тот же текст короче, тап открывает урок или ДЗ в приложении. Пуш нужен тем, у кого нет Telegram, и в A, и в B.

Доступ. Функция за фича-ключом reminders: админ выдаёт доступ учителю или всем (Администрирование → Функции). Без доступа у учителя нет ни настроек, ни виджетов, ни строк из этого макета. С доступом — тумблер и параметры в «Настройках → Автоматизации». Подробно: Доступ к автоматизациям.

Итог: что взяли из A и B

  • Из A: экран «Напоминания» (ПК: Настройки; телефон: Ещё → Напоминания) — четыре правила, каналы, тихие часы, исключения по группам и ученикам; подключение ученика кнопкой ?start=токен.
  • Из B: строки «В 16:00 напомним 6 ученикам» под занятием в «Моём дне» и в виджете расписания на главной ПК; по нажатию — список получателей с галочками (снять одного = не отправлять ему). Блок «Не дошло» рядом с расписанием. Код из 4 цифр — запасной путь, если Telegram на другом устройстве.
  • Настраивается везде: на ПК — три новых виджета в реестре (comms-today, parent-reports, payments-inbox в widgets/registry.tsx), их не ставим на стол по умолчанию; раскладка хранится как сейчас, в desk_layouts; админ может скрыть их через hidden_widgets. Строки напоминаний в виджете «Расписание» — настройка самого виджета (кнопка «строки»). На телефоне — новый экран «Настроить „Мой день“»: порядок и включение тех же блоков, хранится в настройках учителя (например, my_day_blocks рядом с раскладкой стола).
  • Не берём: отдельный экран очереди на ПК и личный выбор каналов учеником (B). Каналы задаёт учитель; ученик может только расширить тихие часы и отписаться в боте (/stop).
  • Данные: строки под занятием читают comms_outbox по schedule_id (поле в payload или отдельная колонка); снятие галочки ставит строке status='cancelled'.

Зачем и для кого

Ученик пропускает урок или срок не из лени: он забыл. Внутренние уведомления Искры (таблица notifications) видны, только когда ученик уже открыл приложение. Нужен канал, который сам «стучится»: Telegram есть почти у всех, пуш — у тех, кто поставил приложение.

Черновик данных

Общее ядро (контакты, очередь отправки, диспетчер) одно на три концепта и описано в обзоре. Здесь только то, что нужно напоминаниям.

-- Привязка Telegram: одноразовый токен для ?start= (A) или 4-значный код (B)
create table messenger_link_codes (
  code        text primary key,           -- base64url 24 байта (A) или 4 цифры (B)
  student_id  uuid not null references students(id) on delete cascade,
  role        text not null default 'student' check (role in ('student','parent')),
  expires_at  timestamptz not null,       -- A: 7 дней, B: 15 минут
  used_at     timestamptz
);

-- Пуш-токены устройств (сейчас пушей в проекте нет совсем)
create table push_tokens (
  id          uuid primary key default gen_random_uuid(),
  student_id  uuid not null references students(id) on delete cascade,
  platform    text not null check (platform in ('apns','webpush')),
  token       text not null unique,
  created_at  timestamptz default now(),
  last_ok_at  timestamptz
);

-- Правила учителя; group_id/student_id = исключение поверх общего правила
create table reminder_rules (
  id          uuid primary key default gen_random_uuid(),
  teacher_id  uuid not null references auth.users(id),
  kind        text not null check (kind in ('lesson_soon','hw_due','hw_late','schedule_change')),
  group_id    uuid, student_id uuid,
  enabled     boolean not null default true,
  offset_min  int,                         -- lesson_soon: 30/60/120
  at_time     time,                        -- hw_due: 18:00
  repeat_max  int default 3,               -- hw_late
  channels    text[] not null default '{telegram,push}',
  template    text,                        -- null = стандартный текст
  unique (teacher_id, kind, group_id, student_id)
);

-- { "quiet": {"from":"21:00","to":"08:00","tz":"Europe/Moscow"},

Cron (pg_cron → pg_net → edge-функция)

select cron.schedule('comms-plan-lessons', '*/5 * * * *',  $$ select comms_plan_lesson_soon() $$);  -- уроки в окне [now, now+2ч]
select cron.schedule('comms-plan-homework', '*/15 * * * *', $$ select comms_plan_homework() $$);     -- hw_due / hw_late
select cron.schedule('comms-dispatch',     '* * * * *',    $$ select comms_dispatch() $$);          -- общий диспетчер очереди

Какие триггеры переиспользовать

  • _schedule_notify (0121) — его уже зовут schedule_move/_shift/_cancel с флагом p_notify. Добавить в него постановку schedule_change в очередь рядом с вставкой в notifications и снимать из очереди ещё не ушедшие lesson_soon этого занятия.
  • schedule_undo — отзывает неотправленные сообщения по dedupe_key. Отправку переноса держим 30 с (окно тоста «Отменить»).
  • notify_on_homework — при выдаче ДЗ ничего не шлём (это уже делает приложение), но планировщик comms_plan_homework читает те же назначения.
  • notify_on_lesson_progress — при сдаче снимать hw_due/hw_late из очереди.
  • tg-webhook — сейчас ведёт диалоги с лидами (tg_threads). Добавить ветку /start <токен> и 4 цифры → запись в messenger_links; /stop → revoked_at.

Открытые вопросы

  • Пуши: нужен плагин @capacitor/push-notifications, ключ APNs и сборка приложения. Веб-пуш на iPhone работает только из PWA на экране «Домой» (iOS 16.4+). До этого канал — только Telegram.
  • Часовой пояс ученика: сейчас его нигде не храним. Брать из браузера при входе в students.preferences.quiet.tz.
  • Ученик без аккаунта (по ссылке-приглашению) не может открыть настройки. Учитель отправляет ему ссылку на привязку из карточки ученика.
