Подсказки

Телефон. Строка на функцию: тумблер и короткая сводка параметров, нажатие открывает те же параметры, что на ПК. Нет доступа — нет ни строки, ни заголовка «Автоматизации».

Что ещё прячется без доступа
remindersстроки «В 16:00 напомним» в расписании и «Моём дне», виджет «Связь с учениками», экран «Напоминания»
parent_reportвиджет «Отчёты родителям», экран утверждения, «Пригласить родителя» в карточке ученика
payment_reminders«Закрыть месяц», виджет «Оплаты: ждут вас», статус автонапоминаний в «Должниках», текст плательщику в шторке отмены
Доступ есть, но учитель выключил функцию: инструменты на месте, ничего не уходит; в виджетах — строка «Выключено в настройках».

Правило

  1. Админ в админке выдаёт доступ к функции конкретному учителю или сразу всем.
  2. Без доступа учитель не видит ни настройку, ни инструмент. Не рисуем замков, «скоро», серых пунктов.
  3. С доступом в «Настройках → Автоматизации» есть переключатель функции и её параметры. По умолчанию после выдачи доступа функция выключена: учитель включает сам.
  4. В админке на вкладке «Функции» собраны все ручки по всем учителям: доступ, включено ли, ключевые параметры, объём отправки.

Черновик данных

Общий механизм фича-ключей делает основная сессия. Для этих трёх функций нужны ключи reminders, parent_report, payment_reminders. Ниже — что макет ожидает от механизма.

-- Доступ: «всем» = строка с teacher_id is null
feature_access (feature_key text, teacher_id uuid null, granted_by uuid, granted_at timestamptz)

-- Включение и параметры — у учителя (меняет сам, админ видит и может поправить)
teacher_features (teacher_id uuid, feature_key text, enabled boolean default false,
                  params jsonb default '{}', updated_at timestamptz,
                  primary key (teacher_id, feature_key))

-- Права: has_feature(teacher, key) = доступ есть (лично или всем).
-- Планировщики cron и comms_outbox проверяют has_feature AND enabled — иначе ничего не ставят в очередь.
-- Отзыв доступа: снять из очереди всё queued этого учителя по функции.
  • Параметры из концептов уходят в teacher_features.params: напоминания — offset, at_time, repeat_max, quiet, channels; отчёт — время черновиков/отправки, ai, review_all; оплаты — invoice_mode, debt_rule, late_cancel_hours, шаблоны.
  • Флаг ai_parent_reports в app_flags остаётся глобальным рубильником расхода; фича-ключ отвечает только за доступ.
