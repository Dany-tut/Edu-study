Связь с учеником и родителемКонцепты 4–6 · Искра · ноябрь 2026

Три связанные функции, у каждой два варианта UX. В каждом макете: экран учителя на ПК и телефоне, что получает ученик или родитель (Telegram, пуш, страница по ссылке), светлая и тёмная тема. Переключатели вверху каждой страницы; «Обоснование и данные» — сравнение, рекомендация и черновик таблиц, cron и триггеров.

4 · Ученику

Напоминания

Урок через час, ДЗ завтра до 20:00, ДЗ просрочено, перенос или отмена. Telegram и пуш, тихие часы.

AПравила один раз; подключение кнопкой-ссылкой
BОчередь «что уйдёт» в «Моём дне»; код и личные настройки ученика
Итог: правила A + «что уйдёт» под занятием
 5 · Родителю

Недельный отчёт

Посещаемость, ДЗ, баллы и две фразы от ИИ, которые учитель утверждает. Родителю не нужен аккаунт.

AКаждый отчёт по очереди; весь текст в Telegram
B«Утвердить всё, кроме отмеченных»; постоянная ссылка с историей
Итог: утверждение B, текст A, ссылка B
 6 · Плательщику

Оплаты

Напоминание о долге по шаблону, счёт за месяц по проведённым урокам, сообщение при переносе или отмене.

AАвтопилот по шаблонам; сообщение в шторке отмены
B«Закрыть месяц» таблицей; долг в одно касание; тост после отмены
Итог: месяц B, долг A, отмена обоими путями
Доступ к автоматизациямАдмин выдаёт доступ учителю или всем; без доступа функции не видно; с доступом — тумблер и параметры в «Настройках». Админка → «Функции», настройки учителя на ПК и телефоне.

Как всё связано

СобытияРасписание (schedule_*), ДЗ, посещаемость, payments, cron по времени

Всё настраивается: на главной ПК три новых необязательных виджета из библиотеки — «Связь с учениками», «Отчёты родителям», «Оплаты: ждут вас»; на телефоне те же блоки включаются и переставляются в «Настроить „Мой день“».

Порядок сборки: 1) контакты + привязка Telegram + очередь + диспетчер; 2) напоминания (самое простое, проверяет канал); 3) перенос и отмена с условиями оплаты; 4) счёт за месяц; 5) отчёт родителю с ИИ.

Общее ядро для трёх функций

Напоминания, отчёты и оплаты отправляют сообщения одним путём. Ни одна функция не пишет в Telegram напрямую: она ставит строку в comms_outbox, а отправляет единый диспетчер. Так тихие часы, дубли, отзыв по «Отменить» и журнал доставки делаются один раз.

-- Кому писать: ученик или родитель (у родителя нет аккаунта и роли)
create table student_contacts (
  id          uuid primary key default gen_random_uuid(),
  student_id  uuid not null references students(id) on delete cascade,
  role        text not null check (role in ('student','parent')),
  name        text,
  is_payer    boolean not null default false,
  tg_chat_id  bigint,
  tg_username text,
  linked_at   timestamptz,
  revoked_at  timestamptz,             -- /stop или «отвязать» у учителя
  blocked_at  timestamptz              -- Telegram ответил 403: бот заблокирован
);
create unique index on student_contacts (student_id, tg_chat_id) where revoked_at is null;

-- Одна очередь отправки
create table comms_outbox (
  id           uuid primary key default gen_random_uuid(),
  teacher_id   uuid not null,
  student_id   uuid not null,
  contact_id   uuid references student_contacts(id),     -- null = пуш ученику
  channel      text not null check (channel in ('telegram','push')),
  kind         text not null,          -- lesson_soon | hw_due | hw_late | schedule_change |
                                       -- parent_report | invoice | debt | payment_received
  payload      jsonb not null,         -- текст, кнопки, ссылка
  send_at      timestamptz not null,   -- уже сдвинуто тихими часами
  dedupe_key   text not null,
  status       text not null default 'queued'
               check (status in ('queued','sending','sent','failed','cancelled','skipped')),
  attempts     int not null default 0,
  error        text,
  sent_at      timestamptz,
  tg_message_id bigint,
  unique (dedupe_key, channel, contact_id)
);
create index comms_outbox_due on comms_outbox (send_at) where status = 'queued';

alter table comms_outbox enable row level security;
-- Учитель читает только свои строки; вставка — только SECURITY DEFINER функциями.

Диспетчер

-- Раз в минуту: забрать до 200 строк, у которых пришло время, и отдать edge-функции
select cron.schedule('comms-dispatch', '* * * * *', $$
  select net.http_post(
    url     := 'https://<project>.functions.supabase.co/comms-send',
    headers := jsonb_build_object('Authorization', 'Bearer ' || (select secret from vault ...)),
    body    := jsonb_build_object('batch', comms_claim_batch(200))   -- UPDATE … SET status='sending' … RETURNING
  ) $$);
  • comms-send отправляет через Bot API, пишет sent/failed. 403 от Telegram → student_contacts.blocked_at и событие учителю в notifications. 429 → вернуть в очередь с send_at + retry_after.
  • Кнопки сообщений — callback_data c:<outbox_id>:<действие>. Их обрабатывает tg-webhook: «Я оплатила», «Оплачу до…», «Через 2 часа».
  • Тихие часы — при постановке: comms_quiet_shift(student_id, ts) по students.preferences.quiet и часовому поясу.
  • Отзыв — update comms_outbox set status='cancelled' where dedupe_key like … and status='queued' из schedule_undo, при сдаче ДЗ, при оплате.
  • Расход ИИ — только в отчётах родителю, флаг ai_parent_reports в app_flags. Telegram и пуш бесплатны.
