Записи уроков из папки Диска

Учитель один раз даёт модулю ссылку на папку Google или Яндекс Диска. Искра находит ролики, предлагает соответствия «файл → урок», а после подтверждения сама копирует записи в наше хранилище и ставит ссылки. Ниже три состояния: A подключение папки, B подтверждение соответствий, C статус на модуле. Каждое — ПК, iPad, iPhone, Android, светлая и тёмная тема.

A · Подключить папку к модулю

ПК — всплывающее окно из меню модуля «⋯ → Папка с записями». iPad — то же из стеклянной капсулы справа. iPhone — лист с грабером. Android — нижний лист Material с таблетками.

B · Подтвердить соответствия

Каждая пара с меткой: «по номеру», «по названию», «по порядку». Уроки, где уже стоит ссылка, по умолчанию не отмечены — видна текущая ссылка, заменить можно только галочкой. Лишние файлы и дубли — красным, не отмечены.

C · Компактный статус (правка Дани 24.11)

У каждого урока — облачко: зелёное с галочкой — запись в Искре, фиолетовое с кольцом — копируется, жёлтое с часами — ждёт подтверждения. Подпись — при наведении на ПК и по нажатию на iPad/телефонах (в концепте раскрыта у копирующегося урока). В шапке модуля — облачко «3/4» с подписью о папке и кнопка ⟳ «Подтянуть записи». Новые файлы проверяются раз в 3 часа.

Правила, которые держит интерфейс

  • Ручная ссылка учителя никогда не заменяется без явной галочки; при гонке (учитель поменял ссылку во время копирования) — статус «Конфликт», ничего не пишется.
  • У каждой применённой записи в меню урока — «Вернуть прежнюю ссылку».
  • Списки прокручиваются с фейдами сверху/снизу (на Android — фейды SCROLL-01, без стекла).
  • iPad: все действия — в капсуле справа, в лендскейпе без hover-only действий.
  • Подписи внутри полей; лист с грабером — без крестика.
