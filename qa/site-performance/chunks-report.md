# Направление 10: начальные и предметные чанки

База: 940c88563023b79015e593a1d29225e56a7472d9 / 1.0.3539.

Изменения:

- App загружает StickerRevealGate только в ученическом кабинете после согласия. Во время загрузки используется null-Suspense, кабинет остаётся на месте.
- Gate загружает тяжёлую модалку только при наличии новых стикеров. Сохранены props, закрытие, единый экземпляр и стандартный retryImport.
- loadApLessons получает IDs необходимых уроков и запускает только соответствующие AP Chemistry / Cell Biology / Biology Prep чанки. Обычный урок не скачивает и не ждёт эти три чанка. Без аргумента API продолжает загружать все предметы.
- Независимые promises объединяют одновременные запросы по предмету, сохраняя успешно прибывшие соседние предметы и возможность повтора провалившегося импорта.
- Вызов `loadApLessons(want)` в studentDataStore **не включён**: файл занят владельцем multisubject. Однострочное предложение сохранено в chunks-studentDataStore-proposal.patch; пока владелец его не перенёс, обычные уроки сохраняют прежнюю загрузку всех трёх предметов. Optional API протестирован и готов к подключению.

Проверено: `node qa/site-performance/chunks.mjs` PASS. Тест использует актуальный код loader/gate со стабами границы динамического импорта и useStickers: обычный урок/чужой префикс=0 импортов; по одному импорту на предмет; конкурирующие вызовы; ожидание полного ответа; обратный порядок ответов без потери других предметов; ошибка и повтор только одного предмета; совместимость вызова без аргумента. Gate проверен реальным React server renderer: пустой fresh не вызывает import модалки, непустой вызывает один, после ответа передаются исходные items/onClose, после dismiss опять пусто. Интеграция App consent/Suspense дополнительно проверена по исходникам. Caller heavy barrier предлагается владельцу через patch, его интеграция не проверена.

Применён review по vercel:react-best-practices: lazy объявлены на уровне модуля; стабильные правила хуков; cheap fresh check до модального импорта; нет визуальных изменений, новых подписок, эффектов, ресурсов без очистки или изменения авторизации.

Ограничения: не измерял реальные секунды, build bytes или LCP/INP; не выполнял полный build/check:ui (выполняет владелец интеграции). Browser E2E и физические ПК/iPhone/iPad/Android не проверены. Предметные чанки тестировались управляемым network boundary, не реальной сетью. Общие модули используются всеми четырьмя версиями; интерфейс/темы не менялись.
