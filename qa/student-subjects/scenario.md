- База: origin/main 940c88563023b79015e593a1d29225e56a7472d9 + патч; финальный SHA и SHA-256 манифест в results.json после коммита.
- Граница: настоящие AddStudentModal / MobileTeacherStudents / MultiSelectField / useGroups / Supabase query builder; in-memory транспорт с localStorage вместо удалённого REST. Это UI+контракт запросов, не production E2E.
- Синтетические данные: преподаватель teacher-a, Тимур QA, группа Химия, выбранные Химия/Биология/Русский/Литература. Второй пользователь и RLS проверяются отдельно настоящим PostgreSQL/PGlite в scripts/checkStudentSubjectsDb.mjs.
- Комбинации: ПК 1440×900, 1280×720; iPhone 390×844, 320×740; iPad 820×1180 и 1180×820; Android 412×915. Две темы, Chromium с платформенным UA и touch.
- Элементы/ожидания: имя; полный каталог при профиле учителя из двух предметов; выбрать 1→2→3→4; снять/вернуть; поиск; свой предмет; очистить; disable при 0 предметов/пустом имени; ошибка записи не стирает черновик; повтор отправляет один объект с массивом из четырёх предметов; readback/reload сохраняет весь массив без новых групп/курсов. Группа добавляет свой предмет; снятие сбрасывает группу.
- Скролл: dropdown ограничен viewport, фейды начало/середина/конец; плашки не скрывают крестики. Проверить короткое окно и длинный свой предмет. Motion наблюдать от кадра до открытия; reduced motion — отдельная граница.
- До запуска: обязательные клетки NOT TESTED. Факт/ошибки/снимки сохраняются check.mjs в results.json / evidence/.
- Не покрывает: физические устройства/нативный Liquid Glass, настоящее Auth/приглашение, удалённую БД, установку приложений. Полная приёмка движения/контраста/клавиатуры и native iPad chrome отдельно от проверки мультивыбора.
